### 武器レイヤー（今回確定）

- 基本表示：装備枠**武器①**（第1武器）を、機体の右手に重ねて描画する。敵・友軍AIの装備武器も表示する。
- 武器②（第2武器）は、**プレイヤーが戦闘画面で武器②を使う行動を選択した間だけ**右手の武器を差し替えて表示する。
- 移動／待機／武器選択解除／行動終了時は武器①表示へ戻す。戦闘結果・保存状態・現在装備は変えない。
- 同一型フレームおよび敵のA／B／Cモデルは、元画像の形状を変更せずパレット差分で表示する。
- 今回の確定画像と武器の組み合わせは、**カスタマイズおよび戦闘マップの描画処理のみ**が参照する。ゲームCore・AI・HP・EN・CAP・セーブ構造を変更しない。

**注意：本節は正式採用と表示仕様の正本。画像バイナリがGitHubへコミット済みかは別途確認すること。** コード側は画像ファイルが存在するときのみ表示し、欠けている間はSVGフォールバックを使う。

## インポートされる表示ファイル

- 同型フレームの色違いは `.../frames/<frame-id>.png` を優先し、存在しない場合は同一形状の基準画像へフォールバック。

## 装備と表示の関係

- ゲームCoreの武器①・②とフレームIDは**既存セーブ／出撃データの正本**。画像表示はそれらから読み取るのみ。武器系統は `basic-parts.json` の `weaponFamily` に従う。
- 戦闘画面は通常時に武器①、攻撃メニューで武器IDを選択中は**選択された武器系統**の画像を手持ち表示する。武器②はカスタマイズ画面の独立したアイコンで表示し、装備選択によって更新する。
- 装備する武器が同じ系統に属する場合、共通素材を使う（威力・射程・特殊効果を画像によって推測しない）。
- 画像がまだ登録されていない場合や、未対応のフレーム／敵では現在のSVG代替表示へ戻し、操作対象・HP・VFX・被弾判定は維持する。画像そのものには pointer events を付与しない。
- 画像は `?inline` で独立HTML内に埋め込み、外部HTTP画像を参照しない。実機の読み込み時間と配布HTMLサイズはPNG登録後に再測定する。

## 未完了作業の明示

**本体10枚は登録・接続済み。武器PNG6系統は未登録で、手持ち武器の実画像と最終装着調整は保留。** 他の画像生成による再描画シートを、ユーザーの明示的な承認なくこの正式デザインの代替として使用しない。実PNG登録後に、カスタマイズとM01戦闘で本体・手持ち武器の位置を確認する。

確定済みのゲームルール、難易度、セーブ形式、装備2枠およびVFX21種に変更を加えない。


## 本体PNG接続・容量プロファイル

詳細は [接続記録](../../../../../docs/design/robot-tactics/approved-png-integration-2026-11-06.md)。標準版は256px本体10枚を内包し、カスタマイズも同じ画像を使う。`VITE_ROBOT_ART_PORTRAITS=true` の明示ビルドだけ、カスタマイズ可能な5形状の1024pxマスターを追加する。戦闘は常に256px。友軍・敵のマスター5枚は登録を維持し、この画面に用途がないため配布HTMLへ内包しない。

`RobotVisualArt.ts` の `RIGHT_HAND` / `WEAPON_POSE` で機体別の右手位置・縮尺・角度を調整できる。現在の座標は接続用であり、未登録の武器PNGを装着確認済みとは扱わない。画像エラー時はマスター→マップ画像→従来SVG、武器エラー時は本体と装備名を保持する。
