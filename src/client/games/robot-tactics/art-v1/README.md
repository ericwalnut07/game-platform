## インポートされる表示ファイル

**下記PNGを配置すると、自動的に独立ゲームHTMLへ内包される構造を実装した。現時点では、PNG実体は未登録のため、ゲームは従来のSVGフォールバックを表示する。**

- `src/client/games/robot-tactics/art-v1/frames/attack.png`
- `.../frames/defense.png`
- `.../frames/reactor.png`
- `.../frames/mobile.png`
- `.../frames/all-rounder.png`
- `.../frames/friendly-ai.png`
- 同型フレームの色違いは `.../frames/<frame-id>.png` を優先し、存在しない場合は同一形状の基準画像へフォールバック。
- `.../weapons/slash.png`、`blunt.png`、`thrust.png`、`assault.png`、`sniper.png`、`blast.png`（既存の個別武器画像を用いる）。

元画像の透過PNGと対応する武器素材を**新規の作画ではなく、切り出し・局所編集**で作成する。透明背景、右手武器のレイヤー座標、PC/スマートフォン横画面の縮小表示をチェックする。ファイル名は固定だが、サイズやアンカーは見た目検証に応じて微調整可。

## 装備と表示の関係

- ゲームCoreの武器①・②とフレームIDは**既存セーブ／出撃データの正本**。画像表示はそれらから読み取るのみ。武器系統は `basic-parts.json` の `weaponFamily` に従う。
- 戦闘画面は通常時に武器①、攻撃メニューで武器IDを選択中は**選択された武器系統**の画像を手持ち表示する。武器②はカスタマイズ画面の独立したアイコンで表示し、装備選択によって更新する。
- 装備する武器が同じ系統に属する場合、共通素材を使う（威力・射程・特殊効果を画像によって推測しない）。
- 画像がまだ登録されていない場合や、未対応のフレーム／敵では現在のSVG代替表示へ戻し、操作対象・HP・VFX・被弾判定は維持する。画像そのものには pointer events を付与しない。
- 画像は `?inline` で独立HTML内に埋め込み、外部HTTP画像を参照しない。実機の読み込み時間と配布HTMLサイズはPNG登録後に再測定する。
