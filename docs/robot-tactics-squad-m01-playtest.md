# 集団戦版 M01「前線防衛戦」スタンドアロン試遊版

## 目的
2026-10-28に確定した「自機3＋友軍AI2〜3、敵小隊による集団戦」の初期試遊に使用する。旧3対3の M01 試作や本番ゲームサイトは変更しない。

## 開き方
- GitHub: `public/robot-tactics-squad-m01.html` をダウンロードし、PCまたはスマートフォンのブラウザで開く。外部ライブラリやサーバーは不要。
- ブラウザプレビューは GitHub ファイルを HTML として提供する信頼できるプレビューサービスを使用できる（第三者ホストに依存するため、ローカル保存を推奨）。
- 本番 Workers にデプロイしない。正式ゲーム登録もしない。

## 試遊仕様（M01 v0.1、正式ルールとは区別）
- 13×11マス、障害物6マス。中央後方の防衛施設を5ラウンド守る（HP160、DEF18は試遊バランス調整値）。
- 自機3（斬撃、アサルト射撃、狙撃）を直接操作。各機「移動＋1行動」、EN回復・防御・チャージあり。
- 友軍AI2：自由行動／集中攻撃／自機護衛／施設防衛／前進をいつでも切替可能。指示変更に行動/ENは不要。
- 左翼軽量3機は共通手番で行動し、個別ターゲットの攻撃ダメージを同時解決。他の敵機と友軍AIはスピード順に単独行動。右翼に前衛1＋射撃1、R3に軽量3機増援。
- R3終了までに左翼初期軽量3機を撃破した場合のみサブ目標達成。R3以降に全敵撃破なら早期勝利。
- 通常攻撃、斬撃薙ぎ払い、ライン連携、ペア連携、デルタ連携、チャージ、防御。連携を起動できるのは自機のみ。味方支援参加で手番・ENを消費しない。
- ライン／ペアは**試遊用の「隣接味方が必要」仮条件**。デルタは2×2内のL字3機。正式なライン／ペア幾何は未決定。
- 行動順に各AIを1回ずつ実行するボタン、AIを次の自機手番まで進めるボタン、再戦、ログコピー。
- 装備は試作固定。武器の同一ID二重装備禁止という確定ルールに反する装備構成はない（自機は1武器を使用）。

## 前回案からの試遊調整
- 初期提案の施設HP160を維持。試遊用にDEF18を採用。DEF45で試したところ自機が一切攻撃しなくても施設HP95/160で勝利でき、戦術判断の必要性が乏しかったため。
- 便宜上、施設DEFを18にすると、放置操作ではR5施設破壊、一方で簡単な前進＋通常攻撃スクリプトではR5施設HP22で勝利（いずれもシンプルなDOMスタブ操作を通した決定論的な試走）。数値や勝率は未承認。
- 敵のステータス・装備・射程は試作用。キャラクター育成や報酬は変更しない。

## 既知の簡略化・次の検証対象
- 3種の固定武器のみ。CAP/装備6枠/フレーム育成/成長/敵AI細部/全武器/全コンボ/攻撃状態異常/シールド/追加移動/特攻/正規の移動タイプ形状は今回未実装。
- 移動は障害物・ユニットを透過しない上下左右の最大MOV BFS。射線は障害物だけを遮る直線補間の試作仕様。
- 軽量小隊の移動は小隊手番内に個別処理し、攻撃のみ同時解決する。
- デルタの攻撃対象はクリックした敵と距離が近い最大2体を自動選択する仮UI。
- 敵AIは施設攻撃優先、基本的な接敵移動・射程処理。友軍AIの行動位置スコアはごく簡略化。
- 途中で自機3機が全滅しても施設防衛の条件のみで進行する。再出撃は今回未実装。
- スマートフォンでは13×11盤を縮小表示する。実機での可読性と操作性は未検証。
