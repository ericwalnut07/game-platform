## B ボス耐性
ボスタグ: 冷却MOV-1、凍結/拘束MOV-2かつ任意飛行切替禁止（完全移動停止なし）、機械/融合特殊EMP威力70%（04のDEF前）と電子支援/障壁/適応停止、生体特殊/生体進化継続。再生抑制-50%。その他状態は標準、個体別耐性優先。巨大敵タグの一時MOV低下は恒久/部位破壊後MOVが正なら最低1、恒久MOV0を復活させない。凍結/拘束の完全停止は通常敵でのみ優先、巨大非ボスは減衰MOV-2を標準仕様。強制着地は02優先。B01再生8/2/4/1%（通常/抑制/EMP/両方）、B03補完停止と障壁停止等は固有効果優先。個体免疫はデータで明示。
## C 期間と発動
弱体期間nRは対象所属ターンをn回経過した時点で終了。付与が対象ターン中ならその途中のターンを数えず、次の対象ターンから数える。対象ターン開始前の付与は直後のターンを1回目とする。対象ターン終了で減算、燃焼のみラウンド終了でn回DOT後に減算（付与Rから、ラウンド終了処理中に新規付与なら次Rから）。開始時再生はその時点の弱体を参照。防御/障壁/指揮など既存の次発生元所属ターン開始までの効果は別の期限種別。再付与で期限が延びる場合のみ更新、短い期間で上書きしない。状態発生源ID/付与時期/残期間/強度を保存。表示は残り対象ターンまたは燃焼回数を明記。
## D 重複・永久拘束
同一状態は非重複、異属性弱体は属性別、同一属性は最大。外殻/装甲破損は強い外殻優先、弱い装甲で上書き不可、外殻付与で装甲解除。過熱/冷却は後着優先、凍結は冷却を解除して置換、過熱が有効付与されると凍結解除（耐性期間は維持）。凍結中の冷却は置換しない。燃焼は別系統なので冷却と併存可。凍結/拘束は共通強移動制限グループ、同時存在・相互延長不可。終了/解除後、次の対象所属ターン終了まで同グループ再付与無効。EMPも独立グループとして同様に延長不可・終了後1対象ターン耐性を適用。飛行阻害は同様の独立グループ。P30は燃焼/過熱/冷却/帯電/外殻破損/装甲破損/属性弱体化/再生抑制のみ+1、凍結/拘束/EMP/飛行阻害除外。通常のMOV低下同系統は最大値（加算なし）。状態強度は個体別に解決。強制着地/部位永久効果は耐性対象外。
## E 燃焼・固定効果
最大HPに対し1x1=5%、1x2=4%、2x2=3%、3x3=2%、4x4以上=1%（個体サイズ分類、同一実体・両層でも1回）。floor、最低1、燃焼免疫0。DEF/属性/方向/地形/通常防御/障壁を無視する固定本体DOTとする、部位耐久に影響なし。残HPでクランプ、実減少を発生源に帰属（同一燃焼の有効更新時のみ発生源を更新）、発生源撃破後も継続。DOT撃破は通常と同様の撃破/形態判定、勝敗/増援境界は07。HP低下による形態変化は状態を原則維持、個体固有解除のみ例外。
## F 付与・強化
04の全攻撃完了後に生存実体へ状態を1種類につき1回適用。通常攻撃付随状態は本体実HPダメージ>0を条件、完全無効/完全遮断なら不発。状態専用支援は合法性と耐性のみ判定。部位指定弱体は個別指定のみ。確率なし（個別例外は要承認）。P33弱体敵は有効な負状態1種以上（部位破壊・耐性期間のみは除外）。攻撃時点のスナップショットで判定。指揮・解析・障壁は同種最大、別種は04の計算段階で併用。発生元追従/消失条件・寄与配分は06。解除は明示効果のみ、通常修理では解除しない。適応は攻撃完了後の有効属性に反応、同一攻撃で1回、個体別保持数/期間、EMPで停止/解除する個体は定義優先。B04進化の集計は実HP減少のみ、同値は属性ID順、個体仕様の集計窓を優先（原表確認要）。
