# 戦闘Core詳細設計04 — ダメージ計算・部位破壊
2026-11-25。03承認済み bf3594d0b9c78ea1902f8437aea301a0781b1e08。本書の追加詳細は提案。初期数値の変更ではない。個体別効果優先、不明な属性/部位座標等は推測しない。
## A 能力値・補正
- 自軍HP/ATKは採用済みLv式を切捨て後、該当共通功績と同段階装備補正を加算して切捨て。敵HP/ATKは基礎×Lv倍率×難易度倍率を一括切捨て（難易度数値は既存暫定）。形態ATK倍率はその後切捨て、DEFは形態値を使用。固定DEF増減/部位破壊→割合DEF低下→貫通の順。DEF最低0、途中のDEF割合値は丸めず基礎ダメージ時に切捨て。例DEF55、破壊-15、装甲破損25%、貫通20%+15%=19.5。
- 1ヒット・1セルの基礎B=max(1,floor(ATK×武装倍率−実効DEF))。貫通は加算0〜100%。移動後威力80%やEMP特殊70%は武装威力補正としてATK×武装倍率に先に乗算する案（DEF差引前）。通常の功績・装備・指揮等のダメージ増加は基礎Bの後、同段階加算。P32静止攻撃発動時は残移動権放棄、既移動/旋回済みは不発。適用条件は攻撃開始時に確定。
- 属性=個体/形態基礎相性+状態/装備のpt補正、通常25〜200%、完全無効は0固定。P07の125%以上判定は対象計算系（本体または部位）の最終属性相性を使う。部位属性は本体属性に部位補正を加えて別にクランプ（本体クランプ前の合計を使用）。
- 1セル実数ダメージ d=B×(1+同段階増加合計)×属性×方向×地形×防御×障壁×その他別種軽減。軽減率は各0〜100%、同種は個別定義、同一障壁最強のみ、防御P16は30%を45%に置換。方向は攻撃起点（爆風も攻撃起点、連鎖は直前の連鎖起点）から被弾セルへの逆ベクトルを被弾者向きに投影し、03の前方90/側面/後方で分類。距離0・向きなしは中立100%、方向限定軽減不発。地形は被弾セル/レイヤー、航空は地形軽減なし。
## B 複数マスと連射
- 本体は個体/形態DEFと属性を使い、部位固有DEF/属性を混ぜない。各水平座標のdは両層命中なら大きい方のみ。同一実体の全座標dを降順に並べ、最大1セルを100%、残りを30%ずつ加算し、1ヒットごとに最後にfloor。最大同値は固定座標/層順。全座標均一なら従来1+0.3(n−1)。完全無効のみ0、非無効の有効命中は1ヒット最低1。完全無効セルは0寄与。個別の完全遮断効果も0。100%軽減は完全遮断と明記された場合のみ0、それ以外最低1。攻撃回数hなら同一スナップショットのヒット結果をh回合算（各ヒット丸め）。弾薬は主行動1回につき原則1、ヒットごとに消費しない。
- 例セルd=100/80/70/50→160（100+0.3×200）。均一100×4→190。両層同一XY100/70は100。基礎B=200−40=160、攻撃補正30%、属性125%、方向100%、地形なし、防御30%、障壁25%→136.5→136。連射ATK100倍率45%×3 DEF35→10×3=30。
## C 部位
- 部位耐久は初期HPとは別の整数。提案: bodyと同じLv3%およびHP難易度倍率で一括切捨て、最低1。2%案は未採用、実戦で検証。個体別倍率を設定可能。通常修理/再生は部位を回復しない。
- 部位計算は同一攻撃スナップショットで別系統。本体DEFを既定、個別部位DEFがあればそれを使用、共通DEF状態/貫通を適用。部位属性は部位のみ。部位専用増加（P06/精密爆撃功績/解析など）は部位の同段階ダメージ増加に加算（本体には不適用）。本体と同様に方向/地形/防御/障壁を適用する案。個別の部位保護効果のみ例外。部位内のXY重複は最大値採用、異なる部位は別集約。同一層XYに複数部位を重複定義しない。部位なしセルは本体のみ。破壊済み部位の耐久ダメージ0、本体は通常通り。
- 例ATK200倍率190%、DEF55貫通20%→336、相性100%、部位+40%功績+25%装備→554、障壁30%なら本体235/部位388（床関数は最終）。部位ダメージの本体への再加算なし。
## D 適用・イベント
- 攻撃開始時の有効能力、相性、占有、支援、部位状態を固定し、全対象/全ヒットの予定量を算出。HP/耐久それぞれ残量でクランプ、実減少を功績へ。途中破壊/撃破で残りヒットの威力を変更しない、別実体に自動再標的しない。攻撃中の過剰ダメージ/過剰部位ダメージは記録のみ。全命中を反映→部位破壊イベント（固定entityId/partId順、各1回）→本体撃破（各1回）→生存者の形態変化（閾値を飛び越えた場合は最終到達段階、B04分岐は今回破壊反映後）→状態付与/適応更新（生存者、05で詳細）→強制移動/反応/勝敗（06/07で詳細）。撃破された実体は形態移行・追加能力なし、部位破壊の実績は同時成立可。破壊で必要部位を失った予告は取消（弾薬/主行動返還なし）。形態変化でHP/耐久/行動権回復なし。
- DOT/固定ダメージは通常攻撃式に混ぜず効果別計算、部位ダメージなしを既定（05）。支援寄与は同一計算の有無差・過剰分除外、詳細06。
