# MVP試遊後調整（2026-11-26）
ユーザー承認済みの変更範囲。実装・検証は未実施。本書は初回試遊仕様の該当箇所に優先する。基準PR #198、コード基準57e2aeb4b8af0afb60817d22ae366386f53954f7、依存#197、最終統合先main。
## 確定
- ユニット別オート/マニュアル。ミッション開始後の自軍操作可能時に切替。集中攻撃（敵実体指定）、護衛（味方/施設指定）、自由行動。指示は変更まで維持、対象消失時自由行動、全機切替・複数機一括指示、オート実行ボタン、ターン終了時未使用権のオート実行。切替で行動権復活なし。合法性・予測・保存を共通Coreで処理。自軍AI能力は難易度共通。護衛距離3は調整初期値。AI実行中は操作競合防止、保存復帰で重複行動防止。
- 歩兵の耐久と役割を改善。標準歩兵HP100→150、COST6維持。属性順（銃/砲/爆/熱/冷/電/光/衝）100/60/125/125/100/75/75/60%を初期調整値とする。既存の基本DEF・通常銃撃・地形軽減・ダメージ式を維持。対物狙撃兵HP85→125、ATK70/DEF3/MOV2/COST10維持。両モデルに上記歩兵系共通相性を適用。正式版の歩兵系はこの相性を共通基準とし、個別モデル調整は別途。選択枠1・追加枠2維持。歩兵の強みは低基本COSTと状況に応じた武装選択、弱みは純火力・耐久・対空性能。戦車等の専門性を維持。
- 追加選択武装はW45（初期、標準歩兵のみ）、W13（MVP01クリア、標準歩兵のみ）、W26（MVP02クリア、標準歩兵のみ）、W30（MVP02クリア、標準歩兵/対物狙撃兵）。既存武装の適合維持、性能はselectable-weapons-and-balance-06.mdの既存値を参照。W13は地上単体、W26は地上扇、W30の対象層・射線等の未定義項目は実装前に確認（対空専門性を維持）。W45は味方歩兵回復、自己不可、支援資材補給不可。P17軽量機動装備（MOV+1/COST3、歩兵系適合）をMVP01クリアで解禁。合計16選択武装・11追加装備。
- 標準装甲車HP180→220、基本COST12→11。標準攻撃ヘリHP150→200、基本COST19→16。2026-11-26追加承認。その他の能力・武装・装備枠・属性相性・功績・重複率は維持。MVP新規戦闘に適用し、他モデルの数値へ自動波及させない。
- MVP01: K01初期4→8、R3増援2→4、K03初期2維持、計14。必須増援、R12維持。
- MVP03: K11除外、K21×1/K03×2維持、K01初期4とR4末増援2追加、計9。K21撃破勝利、随伴任意、R16維持。MVP02編成維持。新配置/代替位置は合法性検証して決定。
- MVP固有推奨Lv1/2/3・6/7/8を廃止し正式40面式 startLv+floor(9*(M-1)/39) に統一。M01–03はE1/N6、COSTは100+3×推奨Lvにより全3面E103/N118。敵HP/ATKと部位耐久に同一推奨Lvを適用、既存難易度倍率維持、DEF固定。EXP初回E288/N489、再戦E86/N195維持。

一般歩兵0/10→10/15%、狙撃兵・重火器兵・工兵5/10→10/15%（兵種/モデル）。基本COST・二段階加算式・装備費対象外を維持。異なる兵種間に新たな横断重複は設けない。他兵種率は変更しない。MVPでは一般歩兵・狙撃兵に適用し、残り2兵種は正式版拡張時に適用する。標準歩兵同一モデルの装備費なし合計COSTは1/2/4/6/8/10隊で6/14/34/60/92/130。
