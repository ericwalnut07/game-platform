# 第二章マップ接続の検証記録

PR #211 の基準は `f445b52666137cd3b4b4ec7187077db96078336d`。マップ定義は PR #205 の `954a1f6b869fc28ac948567eef88ffdc3440f2e7` を使用する。PR #211 の比較先は第一章検証ブランチ。

| 確認項目 | 結果 |
| --- | --- |
| 初期配置・増援データ | M09～M16の8面。初期87体、増援29体 |
| 出撃・初期占有 | Easyの全8面で戦闘開始。初期占有の同層重複なし |
| 層別の最低出撃数 | M10・M14の不足編成を拒否 |
| 施設 | M12の施設座標とHPを確認。施設優先設定は7体 |
| 短期進行 | M09・M10・M15・M16で既存AIのコマンドをCoreが受理し、3ラウンド進行 |
| 攻略・編成比較 | 0/38戦 |

マップはテスト内で登録する。開始確認では既存モデルと固定武装を使用し、試験用に対空車と攻撃ヘリを解禁した。飛行切替個体の移動でAIが移動先レイヤーを渡していなかったため、Coreが合法な経路を照合できない問題を修正した。層別出撃区画、施設位置、撃破対象、増援の出撃区画回避をミッション定義から指定できるようにした。

全武装・部位・追加装備・功績、正式な解禁順での編成と成長、難易度別編成、個体AI、戦闘記録の出力は引き続き作業が必要。M12のデストロンの大地衝撃波が施設を対象にできるかは確定待ち。短期確認では既存の設定を使い、破砕打撃は施設攻撃可能とした。攻略調整は合法なキャンペーン編成で試行できる段階から評価する。
