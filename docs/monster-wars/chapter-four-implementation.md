# 第四章 Core実装状況

基準は第三章実装PR #213 の b8b50fec95af1d5fbde5d48b000fc4d726d93e4d。設計は [#214の確定索引](https://github.com/ericwalnut07/game-platform/blob/b91db05b4fa0065c5beba00fe1f3dbce2a985dda/docs/monster-wars/chapter-four-design-index.md)。直接の比較先は第三章ブランチ、最終統合先はmain。

- グループA：既存Coreの占有・回転・移動判定に4×4を許可。地上16セルと回転後の空中セルを検証。同一実体・同一XYの両層攻撃は既存処理で1回分に集約されることを確認。
- グループG：二施設の独立したHP・DEF・敗北判定、増援と施設の全セル間距離、実体IDによるAI施設優先の共通処理を追加。M31を出撃一覧に接続する作業は残る。
- 電撃相性：現在の共通カタログに存在するK03（75%）、K12（50%）、K22（75%）に反映。バルフレアとK31は先行章の本体カタログ登録時、残る6件は第四章モデル登録時に反映する。

採用済みの敵性能、マップ、装備、攻略条件は上記設計を参照。第四章の実戦攻略は0/32、各章の通し試遊・旧セーブ復帰・実機・単体HTMLは未検証。第二章はCore検証用、第三章はマップ基盤段階のため、通し試遊にはこれらの章の出撃・報酬・解禁への接続も必要。
