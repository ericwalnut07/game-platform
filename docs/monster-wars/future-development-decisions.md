# 今後の開発方針・確定変更（2026-11-28）
ユーザー採用済み。旧仕様と衝突する場合は本書を優先。具体係数未確定のものは実装しない。
- Hard以上は初回クリア報酬だけで基準育成兵種を推奨Lvに維持できない設計。集中育成・再挑戦の選択を重視。具体EXP/周回数は成長曲線と合わせて検証。Easy/Normalの既存方針維持。
- 高速移動型敵は論理方向のある対象の背後、次いで側面を優先する行動特性を持つ。第一章ヴェルザからPR Bで適用。合法経路・予測ダメージ・加速打撃・後衛・迎撃リスク・作戦目的を評価し、背後を絶対条件としない。モデル別特性として再利用。新たな背面ダメージ倍率は追加しない。具体評価点は実装時に検証。
- HP/ATKの成長は自軍・敵軍とも緩やかな加速成長方式。候補式 S=floor(S0*(1+r*(L-1)+a*(L-1)*(L-2)/2))。DEF/MOV等のレベル固定は維持。共通計算処理を使用。係数・自敵共通化範囲・難易度補正との整合は次の詳細設計で確定。現行線形成長の記述は数値確定まで実装上の基準として保持し、方式の将来変更は確定。
- バルガンド予告レーザーは3×3の体幅に対応する3列。中央高威力、両端同じ低威力。旧1列/2列案を置換。第二章M16で実装。初期比較40/60/75%（中央現行100%、60%を優先検証）、複数マスは最高命中列威力を基準に既存追加命中マス30%補正を適用する案を採用し、具体計算順・倍率は第二章検証で最終確定。予告と実範囲一致、中央/両端を色と濃淡/模様で区別、描画幅連動。同一実体への重複攻撃禁止。
