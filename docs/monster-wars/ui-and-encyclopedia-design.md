# UI・図鑑基本設計（2026-11-26）
ユーザー指定方針: 判断に必要な情報を簡潔に表示、地上/空中の立体表現、攻撃別エフェクト・ダメージ表記・自敵/オブジェクト画像、解禁自軍モデル/撃破経験敵の図鑑。以下の具体方式は提案であり実装前に承認する。
## UI
PC/Android横画面、盤面優先。常時=勝敗条件/残R/陣営/行動権/HP/主要操作、選択時=武装/残弾/合法範囲/予測/作戦指示、詳細=属性相性/部位/能力/功績。編成はCOST内訳と装備前後差、育成は現/次Lvと必要EXP。2.5D表示、論理グリッド/座標/占有は維持。地上スプライト/空中スプライト/影と占有セルを分離、同座標の別層を選択可能、両層/地上/空中表示切替、隠した対象への攻撃時は対象層を明示し自動表示または一覧選択。大型両層は1実体、HP一つ、部位選択と本体攻撃の区別。ズーム/パン、タッチ判定、色だけに依存しない識別。斜視角度・高さは試作比較。
## 素材・演出
安定IDで自軍/敵/地形/施設/武装属性・攻撃形状別エフェクトを参照。画像未登録時は識別可能な代替表示。オフラインHTMLへ内包、外部通信不要。銃/砲/爆/熱/冷/電/光/衝の表現差、単発/連射/範囲/支援/状態/部位破壊等のイベントを再生。実HP減少を本体1実体単位で表示、部位耐久は別ラベル、無効/回復/弱体も識別。演出はCore確定イベントのみ参照、二重適用なし。オート時短縮/高速/演出OFFを提案。演出中断・復帰で重複処理なし。
## 図鑑
自軍は解禁モデルを即時登録、兵種別一覧。基礎Lv1 HP/ATK/DEF/MOV/COST、サイズ/層/方向、属性相性、固定武装/適合武装/装備枠、功績条件・役割を表示（育成済み値と区別）。敵は実体撃破経験のあるモデルを登録、種別一覧。攻撃条件/属性相性/基礎能力/特殊能力/部位を参照。未登録は???（未公開名称や絵を先に出さない）と登録数。戦闘中の既存敵情報公開・予測は図鑑登録に関係なく維持。敵登録は勝利報酬と独立し、敗北/撤退でも自軍が撃破した経験を記録する案。Core撃破イベントと同じ保存トランザクションで安定modelId集合を更新（部位破壊のみ・環境による非自軍撃破は除外、DOT/迎撃/オートも自軍由来なら可）。旧セーブは解禁済み自軍を登録、実撃破履歴が確認できる場合のみ敵を復元、推測しない。図鑑の解禁は育成/報酬に影響しない。図鑑ページは静的定義を参照し数値を重複管理しない。敵登録タイミング/未登録表示/追加詳細は提案。
