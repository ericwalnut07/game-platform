# UI・図鑑基本設計（2026-11-26）
ユーザー指定方針: 判断に必要な情報を簡潔に表示、地上/空中の立体表現、攻撃別エフェクト・ダメージ表記・自敵/オブジェクト画像、解禁自軍モデル/撃破経験敵の図鑑。2026-11-26、ユーザーが以下の具体方式をすべて承認。確定仕様。MVPで戦闘UI、2.5D表示、図鑑と互換性を実装。
## UI
PC/Android横画面、盤面優先。常時=勝敗条件/残R/陣営/行動権/HP/主要操作、選択時=武装/残弾/合法範囲/予測/作戦指示、詳細=属性相性/部位/能力/功績。編成はCOST内訳と装備前後差、育成は現/次Lvと必要EXP。2.5D表示、論理グリッド/座標/占有は維持。地上スプライト/空中スプライト/影と占有セルを分離、同座標の別層を選択可能、両層/地上/空中表示切替、隠した対象への攻撃時は対象層を明示し自動表示または一覧選択。大型両層は1実体、HP一つ、部位選択と本体攻撃の区別。ズーム/パン、タッチ判定、色だけに依存しない識別。斜視角度・高さは試作比較。戦闘と出撃配置の画面構成は下の「横画面の戦闘ワークスペース」を参照。属性相性・部位・特殊能力は詳細画面、攻撃予測は対象選択時に表示。
## 素材・演出
安定IDで自軍/敵/地形/施設/武装属性・攻撃形状別エフェクトを参照。画像未登録時は識別可能な代替表示。オフラインHTMLへ内包、外部通信不要。銃/砲/爆/熱/冷/電/光/衝の表現差、単発/連射/範囲/支援/状態/部位破壊等のイベントを再生。実HP減少を本体1実体単位で表示、部位耐久は別ラベル、無効/回復/弱体も識別。演出はCore確定イベントのみ参照、二重適用なし。演出設定は通常（移動・攻撃再生）/高速（短縮）/簡易（ダメージ・主要結果）/OFF（結果即時反映）の4段階。オート行動時にも利用可能。弱点・無効・回復・状態・部位破壊を文字/記号でも識別。連射・複数マスは本体合計ダメージを実体ごとに表示し、部位耐久減少を区別。背景透過ユニット素材を基本とし、占有範囲に応じた表示サイズを使用。演出中断・復帰で重複処理なし。
## 図鑑
自軍は解禁モデルを即時登録、兵種別一覧。基礎Lv1 HP/ATK/DEF/MOV/COST、サイズ/層/方向、属性相性、固定武装/適合武装/装備枠、功績条件・役割を表示（育成済み値と区別）。敵は実体撃破経験のあるモデルを登録、種別一覧。攻撃条件/属性相性/基礎能力/特殊能力/部位を参照。未登録は???（未公開名称や絵を先に出さない）と登録数。戦闘中の既存敵情報公開・予測は図鑑登録に関係なく維持。敵登録は勝利報酬と独立し、敗北/撤退でも自軍が撃破した経験を記録する。Core撃破イベントと同じ保存トランザクションで安定modelId集合を更新（部位破壊のみ・環境による非自軍撃破は除外、DOT/迎撃/オートも自軍由来なら可）。旧セーブは解禁済み自軍を登録、実撃破履歴が確認できる場合のみ敵を復元、推測しない。図鑑の解禁は育成/報酬に影響しない。図鑑ページは静的定義を参照し数値を重複管理しない。登録タイミング/未登録表示/追加詳細は承認済み。図鑑はセーブに含め、撃破済みモデルIDを重複登録しない。
## 実装順
第2回バランス調整→UI試作/盤面操作検証→2.5D表示→図鑑/保存移行→画像登録→演出登録→PC/Android横画面オフライン検証。まずMVPの素材で表示方式を確立し、全モデル/敵の素材制作は正式版拡張時に順次実施する。確定済み仕様の再承認は不要。具体的な画像意匠・描画方式・実機に応じた配置寸法は試作で調整する。戦闘確定イベント、仮素材、素材IDと描画領域を用意。正式画像・エフェクト・演出設定の実装は後続工程。

## 横画面の戦闘ワークスペース

ユーザー承認済み。作業基準は `feature/monster-wars-mvp` の `8075d52976cc684a939d954a16b1dd4bbf27e01c`。依存は設計PR #197、実装先はPR #198、最終統合先はmain。

- 上部はミッション・ラウンド・陣営・残敵・増援予定数と個別指標を1つの情報バーに集約。勝敗条件は元の条件文を展開して表示する。続けて自軍／敵軍パネルの開閉、俯瞰、縮小、拡大、オプションを配置。書き出し・確認付き撤退と、配置中の編成復帰はオプションから行う。
- 左上は自軍一覧、左下は行動ログ。右上は敵軍一覧、右下は選択情報と操作。両一覧は共通の行・HPゲージ・状態行を使い、独立して縦スクロールする。ログは末尾にいる場合に新着に追従し、遡っている最中は表示位置を保持する。
- 右下の詳細・戦術選択領域は縦スクロール。層切替とオート行動／ターン終了はその下の固定領域。出撃配置時は同じ位置から出撃確定できる。敵軍選択時は既存の公開情報と武装を参照できる。攻撃モード中に一覧からユニットを選ぶ場合は合法な攻撃・支援対象の選択を優先する。
- 中央は投影地形の盤面。俯瞰はアートの張り出し分の余白を含め、利用可能な幅・高さから倍率を算出する。ズームは表示中心、一覧フォーカスは現在倍率を保持する。左右の開閉も倍率、できる限りの表示中心、操作モードと選択、スクロール位置を保持する。
- 実装寸法はPCで左17vw・右22vw、狭い横画面で左16vw・右22vwを基準とし、文字とタッチ領域に合わせて上下限を設けた。中央は残り全幅を使用する。高さは動的な表示領域に追従する。
- 盤面上のラベルはHP・所属記号・行動済み・空中・重要状態を表示。オート設定や詳細の向きは一覧／選択情報を参照する。選択中の向きや大型ボスの部位表示は盤上にも残る。

## 作戦選択・出撃編成・兵種育成

- 作戦選択は一覧と詳細の2列。上の難易度ボタンは定義済みのEasy・Normalを切り替える。クリア状況・推奨Lv・報酬・編成上限・勝敗条件は既存の作戦定義を参照する。地形プレビューは戦場生成と共通の地形配列を使う。
- 出撃編成は追加候補、現在の編成、装備と功績の3列で、列ごとにスクロールする。上部にCOSTゲージ、内訳、残りCOST、作戦・育成・お気に入り・配置への操作を表示する。ユニット追加時は追加前後の編成全体のCOST差分を表示する。上限を超えた場合は現在の編成を維持し、配置への遷移を制限する。
- 装備候補は個々の編成ユニットを対象とし、確定前に能力値、装備の効果と武装の使用回数、編成COSTの差分を表示する。適用で保存し、取消で候補を破棄する。作戦選択・難易度変更・育成・配置の往復は一つの編成データを参照する。
- 作戦選択・出撃編成・戦闘結果から同じ育成画面を開く。レベルアップは確認ダイアログを挟まず、1回で次のレベルに必要なEXPだけを消費する。Lv50と不足時は実行不可。兵種レベルと共通EXPは一回の保存で更新し、保存に失敗した場合は直前に保存済みの値を表示する。成長予測はCoreを使い、モデルごとのHPとATKを表示する。
- v4セーブはルール・コンテンツともv3。v1〜v3からの移行時は、到達レベルまでに使った累積EXPをその兵種に保持し、次レベルに達していない残差だけを共通EXPへ返す。v4の再読み込みでは返還を繰り返さない。開始済み戦闘は元のルール版と進行状態で再開する。

## お気に入り編成

編成画面から全作戦共通の5枠を管理する。名前は前後の空白を除いて最大20文字を目安とし、空欄なら「編成1」などの枠名を使う。識別には枠番号を使う。上書き・削除と、内容が異なる編成への置き換えは確認を表示する。

v4の `campaign.favorites` に枠番号・名前・順番付き編成を保存する。編成要素はモデルID・武装ID・追加装備ID。登録時・呼び出し時に独立したコピーを作り、呼び出す際は解禁・装備条件と現在のCOSTを再判定する。条件違反の項目を含む編成は理由を表示する。上限超過の編成も呼び出せる。能力値・功績・戦闘中の状態は、現在のキャンペーンまたは戦闘データから取得する。旧セーブは5枠とも空で開始する。

対象テストは、レベルアップの境界、旧データのXP保存則と再読込、枠数・複製・上書き・不正装備、オフラインでの作戦・装備・育成の遷移を含む。
