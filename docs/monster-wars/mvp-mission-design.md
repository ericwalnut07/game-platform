# 最小完成版 — ミッション・進行と操作設計

2026-11-25。MVPの規模、進行、自軍・敵データはユーザー承認済み（[データ照合と補完](mvp-data-review.md)）。本書の具体的な座標、施設HP/DEF、任務AI配分は初回試遊用の提案。戦闘ルールは [Core 02](combat-core-02.md)、[Core 03](combat-core-03.md)、[Core 07](combat-core-07.md)、[Core 08](combat-core-08.md) に従う。

## 座標と配置の共通規則

左上を(0,0)とし、xは右、yは下。範囲は両端を含み、無指定セルは平地。座標は1×1なら占有セル、K06の1×2は前方セル、K11・K21の正方形は地上占有の外接矩形左上を指す。南向きのK06の後方セルは(x,y−1)。正方形の回転軸はCore 02に従う。初期配置と地形はEasy/Normal共通。

準備画面の配置では出撃区画内に全占有セルを収める。向き管理モデルは向きを選べる。初期配置候補を自動で提示し、プレイヤーは変更できる。地上・空中は独立し、同層の占有重複を禁止する。区画の前列から南へ、同列では西から順に空き位置を探し、複数マスのモデルを先に配置する。友軍の表示順は固定で、戦闘中の手順は任意。

## 増援の共通規則

枠ごとに第1候補→表の代替候補→第1候補から半径2内の探索を行う。探索順は距離、y、x。層と向きは表の初期定義と同様。候補は他の未出現枠の第1・代替候補の占有範囲を避ける。予約セルは増援枠同士の調停に使い、既存ユニットの移動を妨げない。配置不可枠は次ラウンド末へ延期し、出現済み枠を再生成しない。勝利・敗北が成立した時点で残りの処理は終了する。MVP01の必須枠はR12まで取消なし、未出現のままR12を終えると時間切れ。MVP02の任意枠はR8までに配置を試み、施設防衛に成功すれば未出現でも勝利。

### 防衛施設と任務AI

- 施設は自軍所属、地上2×2、HP600・DEF35を初期調整値とする。Easy/Normal共通。行動なし、強制移動不可、建物破壊移動不可、地上の直接射線を遮断。地形軽減なし。施設の破壊で即時敗北。
- 修理車の固定修理は施設に使用でき、回復量・有効射程はCore 06に従う。選択修理W46の対象は機械ユニット。
- 施設を目標として優先する枠はE02・E04・E06・R3-1・R5-1。残りは自軍ユニットの迎撃を担当する。施設攻撃には対象タグと射程・射線を要求し、施設優先枠でも合法対象に応じて行動を選ぶ。E06とR5-1の突進は施設にダメージを与えるが、位置は動かさない。
- 飛行個体の空中移動と施設上空通過はレイヤー規則に従う。増援の出現時は層に関係なく、施設占有セルから水平マンハッタン距離1以下を除外する。

## 初回試遊の操作設計

| 場面 | 操作と表示 |
|---|---|
| タイトル・セーブ | 続きから、ミッション選択、新規開始、JSON書き出し・読み込み。進行中戦闘があれば復帰先を表示。進行データの置換は確認後に保存 |
| ミッション・編成 | 難易度、推奨Lv、勝敗条件、初回／再戦EXP。編成COST内訳、装備適合、兵種Lv・モデル功績、装備変更前後の性能を表示 |
| 配置・出撃 | 初期配置の自動提示、マスと向き変更、合法性と出撃COSTを検査して開始。戦闘中に装備や育成を変更不可 |
| 戦闘 | 横画面の盤面と操作パネル。ユニット選択→移動または武装選択→マス・最終姿勢／対象層を選択→予測を見て確定。PCクリックとAndroidタッチは同じ操作系列。盤面の拡大・移動と指の精度に頼らない対象リストを用意 |
| 戦闘中の情報 | 残りR、勝敗条件、行動権、HP/弾薬、選択中の射程・射線、占有層、部位効果、状態期限、予告範囲。自軍ターン終了時、権利が残っていれば確認 |
| 結果・経験値配分 | 結果と確定報酬、功績、解禁を表示。配分前後のLv・必要EXPを表示して確定。再編成と再挑戦へ戻る |

戦闘操作はCoreの合法性・予測を使用し、保存成功後に表示を更新。Android実機のボタン寸法・スクロール・保存可否はHTML配布前の検証項目。

## 静的検証と試遊で確認する点

- 3マップの範囲・地形重複、初期敵枠6/6/4、増援枠2/3/0と明示代替10候補の占有・予約・施設との距離を確認。全16枠のうち地上初期敵13枠について、静的地形だけで出撃側または防衛施設近傍へ到達する経路があることを確認。戦闘中の他個体による占有は今後のテスト対象。
- 出撃区画は40/48/52セル。全員に縦2セルを割り当てる場合でも20/24/26枠。MVPの最安モデルで各上限に収まる11〜12体に対し余裕があり、別の出撃数上限を設ける必要はない。
- 施設の単発ダメージ概算。基準HP600・DEF35で、K04急降下はEasy 22／Normal 47、K06突進は103／159。Lv1修理車の固定修理は最大140/行動。これらは単体、無補正、個別行動の値であり、AI選択・集中攻撃・修理位置を入れた攻略確認は未実施。
- MVP01はLv1の初期装備で射線・増援込みの勝利、MVP02はMVP01解禁を使った対空・修理を伴う防衛、MVP03はW11等の弱体・部位・予告回避・範囲攻撃の使い分けを検証。各難易度で編成・育成・所持装備・立ち回りを記録する。
