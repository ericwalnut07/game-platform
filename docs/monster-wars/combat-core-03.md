# 戦闘Core詳細設計03 — 射程・射線・対象・範囲
2026-11-25。02承認済み35e4d2d131975a1668f2758cdb9b106619b180a3。本書の追加詳細は提案、承認前に実装しない。既存武装の数値・個別制約は変更しない。未復元の互換性・対象層等は不明として扱う。
## A 射程と起点
- 射程は起点セル中心から指定着弾セルまでの水平マンハッタン距離、上下限含む。高度差は加算しない。同一XY異層は距離0、最小1なら不可。距離0を許す武装のみ例外。射撃起点は前列（複数可）、後列、全占有、指定部位セルからデータ定義。方向なしは全占有を標準。破壊で使用不能な起点は除外。起点と指定セルの組が射程・方向・射線を同時に満たす必要。別起点間で条件を混ぜない。最短の合法起点を優先、同距離は層・y・x固定順。直線・扇など起点で効果範囲が変化する武装は起点を明示選択可能、予測と実行で固定。複数起点から同時発射する個別武装を除き一攻撃一起点。
- 単体は対象実体の合法セルを選ぶ。部位指定は該当セル/層を選択。最小射程内の別セルを持つ敵でも、選択セルが合法なら攻撃可。自己占有セルは通常攻撃対象外、同XY異層の他実体は距離条件に従う。
## B 方向
起点から対象へ向かうベクトルを前方成分f、右方成分sに変換。全方向制限なし、前方半面 f>=0、前方90度 f>0かつabs(s)<=f、前方直線 f>0かつs=0、側面 abs(s)>abs(f)、後方 f<0かつabs(s)<=-f。半面は真横を含む。90度境界は前/後に含める。距離0は全方向か個別許可のみ。方向制限なしのユニットに方向必須武装は装備不可またはデータで方向指定方式を明示。被弾方向は04で確定。
## C 射線
- 直接射撃はセル中心間の線分。地上遮蔽物を参照する武装は途中の建物・重要施設の遮蔽タグで遮断。線が格子頂点を通るとき、両側の隣接セルがともに遮蔽物なら遮断、片側だけなら通過。端点の対象施設そのものは遮断しない。起点セルは除外。瓦礫は遮断しない。通常の味方・敵ユニットは遮断しない（個別の遮蔽タグは将来定義）。山岳/森林は初期LOS遮断なし。
- 間接射撃・航空攻撃は原則地上建物を無視。空中への直接射撃は地上建物を無視する標準案、地上/空中の組合せに応じて武装にLOS方式を明示（無視/地上遮蔽）。立体敵も通常ユニット同様、移動占有と射線遮断は独立。
- 直線貫通攻撃は建物遮断型なら最初の遮蔽物まで。対象施設が遮蔽物なら施設には命中しその先は遮断。敵は貫通し複数実体に命中可能。発射点と着弾点のLOSと、範囲内の各セルの到達条件は区別。
## D 範囲
- 単体1指定セル。着弾中心型: 十字5(中心＋上下左右)、正方形3x3/5x5(中心からチェビシェフ半径1/2)、絨毯5x3(着弾中心前後2・左右1、発射方向ではなく機体方向基準)、周囲r(使用者占有セル集合からマンハッタン距離<=r、自己除外)。扇は起点から前方90度かつ武装最小〜最大マンハッタン距離、軸方向を武装制約内の四方から選択。扇の各セルはLOS個別確認。直線は四方の1方向、最小射程〜最大射程まで、最小未満のセルに命中しないが遮蔽は確認。個別定義の固定長・幅・部位起点は優先。
- 着弾中心型は中心が射程/方向/LOS条件を満たせば、効果範囲が射程外へ及んでも有効。爆風の二次LOSは原則なし（個別指定可）。マップ外セル除外。範囲攻撃は空きセル中心も選択可、少なくとも合法な敵対象が命中範囲にいる必要（予告/地形攻撃は個別例外）。単体攻撃は空きセル不可。
- 自軍/敵軍とも通常攻撃・範囲攻撃は敵対実体のみ命中、味方誤射なしを推奨。中立/防衛施設は陣営と武装対象タグで決定。通常建物は武装に地形破壊タグがある場合のみ破壊。味方の通過不可とは別。
## E レイヤー・巨大敵・連鎖
- 地上のみ/空中のみ/両層から一方選択/両層同時を区別。通常の両層対応は一方選択、W25/W41等は両層同時。指定層のセル集合から敵実体IDで集約、本体の追加命中数はXY重複除去、部位は該当層セル別に集約。破壊済み部位は本体命中可。単体両層同時は個別定義のみ。
- W36 連鎖放電弾は初撃合法セル選択、次は直前対象の占有セルから水平最短距離2以内の未命中合法敵実体、最大3実体、100/75/50%。初撃と同じ対象層、跳躍は初撃の射程・方向を再要求しない、地上遮蔽型なら跳躍LOS確認。距離同値はentityId固定順、同一実体再命中不可。初撃から連鎖先まで確定して予測表示、ダメージ順序は04。
