# 戦闘Core詳細設計 02 — マップ・移動・方向・レイヤー
2026-11-25。01承認済み（6afb6711fc20da7ace78179503c12ad163cfe2fb）。ユーザー承認済み（2026-11-25）。本書は確定仕様。
## 採用済み
正方グリッド、上下左右、マンハッタン距離、16×16〜24×24目安、1×1/1×2/2×2/3×3/4×4、地上・空中独立、同層重複不可。地上大型前後移動・横移動不可、90度MOV1、180度MOV2、1×2前方セル軸、回転後占有のみ確認。航空は上下左右移動可、方向管理機のみ旋回。移動1回、経路一括確定。飛行切替MOV2、1R1回、同座標・方向、HP状態維持。
## 確定 A 占有と方向
- 座標x右/y下、N/E/S/W。向きなしは全方向移動。1×1方向あり地上機は四方向平行移動可、向き変更は明示旋回（自動旋回なし）。大型地上の前後制限は個体タグで管理、地上大型は原則制限。
- 1×2は前方セルを固定軸、奇数正方形は中央セル、偶数正方形は幾何中心を固定（2×2/4×4の外接矩形不変）。不整形は個体ごと回転軸と層別占有offsetを明示。部位offsetも同一変換。回転は90/180を選べ、180は直接最終姿勢のみ判定。旋回途中の掃引判定なし。P20最初の90度分のみ無料、180は1消費、無料使用権は経路状態に含む。旋回のみでも移動権消費。
- 同層の他実体は敵味方とも通過・停止不可、自己の旧占有は除外。地上のみの敵の上空通過/停止可。立体占有は両層全セル同時合法。通常の地形や他者の存在だけで斜め移動を許可しない。
## 確定 B 地形と経路
|地形|歩兵MOV|車両MOV|航空MOV|防御軽減|
|---|---:|---:|---:|---|
|平地/道路|1|1|1|なし|
|森林/瓦礫|1|2|1|歩兵20%|
|山岳|2|不可|1|歩兵30%|
|水域|不可|不可|1|なし|
|建物|不可|不可|1|なし|
|防御陣地|1|1|1|地上30%|
- 地上怪獣は個体別移動プロファイル、標準案は車両と同じ。複数マス平行移動の1ステップ費用は移動先全占有セルの最大地形費（合算なし）。立体は地上費優先、空中のみは1。旋回は固定費のみ、進入可否は全セル。P19は対象地形費-1、最低1、進入不可解除なし。
- 地形防御は命中した各水平座標の対象レイヤーに従う（航空はなし）。複数マス攻撃の集約順は04で確定。
- ダイクストラ探索、状態は位置・向き・レイヤー・切替済み・無料旋回残・経路内破壊建物。最短費用優先、同値は切替なし→旋回少→座標/向き/経路の固定順。最終姿勢選択、経路プレビュー。MOV内のみ、一括確定。無効経路は状態不変。経路途中の迎撃等は06で確定し、発生時は停止/撃破を原子的に処理。移動後特効の距離は自発移動開始/終了anchorのマンハッタン距離（旋回・強制移動除外）。
## 確定 C 飛行切替
- 移動開始時の現在レイヤー有効MOVを全経路の上限とする。切替費2込み、切替後も残り予算で移動可能、着地によるMOV低下で既消費分を取り消さない。次回移動から新レイヤーMOV。例地上3/空中7、離陸2＋空中1、着地2＋移動費5以内。全経路で1回まで、主行動は最終レイヤーに従う。切替禁止中は不可。
- 強制着地は通常移動権とは独立し、同座標のみ試行。着地不能時は空中維持・飛行不能保留、次の所属ターン開始に再試行。保留中は通常の空中移動で合法着地位置へ移動可能、着地可能なら移動終了時に強制着地（任意切替費不要、追加移動なし）。個体固有攻撃制限は個体定義。HP/状態/方向維持、強制着地で移動後特効は発動しない。翼破壊で即死させない。地形/占有による着地不可をUI表示。
## 確定 D 建物破壊
- 通常建物のみ、破壊移動タグの巨大怪獣が地上占有を新たに重ねる際に瓦礫化。進入先の全セル合法を確認してから処理。破壊ステップ費は瓦礫費、任意の回転で新規占有した建物も同様に破壊可能、旋回固定費。経路プレビューでは仮想破壊のみ、実行経路上のみ確定。途中停止なら未到達建物は破壊しない。防衛施設・重要建物は破壊移動不可、HP実体として攻撃のみ、撃破後地形はミッション定義。ユニットを押し潰す移動なし。
## 確定 E 強制移動
- 武装指定方向へ1マスずつ全占有チェック、向き維持、通常移動権/MOV消費なし。障害・他実体・マップ外で停止、押し出し連鎖なし、地形費不要だが進入禁止は遵守。建物破壊移動タグは強制移動では不発。衝突ダメージは武装個別定義（未指定はなし）、反撃/迎撃や勝敗境界は後段。立体は両層合法。
