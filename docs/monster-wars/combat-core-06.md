# 戦闘Core詳細設計06 — 支援・弾薬・迎撃・予告攻撃

## A 支援
修理/救護は主行動1、射程・対象層・対象タグ・機能停止を確認。自己修理不可を標準、個別許可のみ例外。回復=floor(実効ATK×回復倍率×(1+共通/固有/P35補正合計)×再生抑制倍率)、残HP不足分まで、最低1（完全回復禁止は0）。撃破/部位回復なし、満HP対象は不可。固定修理車350%無制限、総合支援車/支援ドローン250%無制限（ドローンの修理回数原表要確認）、W45歩兵250%5回、W46機械150%4回。地上修理は地上機械、航空支援は航空、施設は個別許可。支援射程は水平最短合法セル組、原則建物無視、P37対象支援最大射程+1。支援専用行動は実効効果が発生する合法対象を必要とする（予防障壁/指揮等は将来効果が有効なら可）。築城は暫定: 自軍隣接空き平地1セルを防御陣地化、重要/出撃/増援予約セル不可、戦闘中永続、重複不可、使用回数と固有工兵原表未確認のため実装前要復元。
## B 弾薬・補給
攻撃弾薬と有限支援使用回数は別資源。固定/選択武装ごと独立、無限は数値残量なし。初期弾薬にP23-26排他補正、P27は有限支援のみ、最大使用功績は個別定義、戦闘開始時確定。使用1主行動につき原則1、空振り許可の予告等も消費、無効操作無消費。補給車2点/5回、総合1点/6回、支援ドローン1点/4回、W47携行1点/3回、P36+1点。補給対象は1味方の1有限攻撃武装を指定、自己不可、最大弾薬まで、点数余り消滅。支援資材（補給/修理/救護/解析/障壁/拘束/飛行阻害等）補給不可、攻撃付随状態を持つ攻撃武装は補給可。武装データに supplyCost=1/2/3 を提案、通常1、大型高威力2、超大型ミサイル固定武装3（他の2/3対象は個別性能表と実戦比較後に確定、未分類は1）。回復弾数=min(不足,floor(補給点/supplyCost))、0なら不合法・使用回数消費なし。例2点では3点武装補給不可、P36付き3点で1発。補給功績は実回復弾数（点数ではない）。この新制約は承認待ち。20Rの定点比較で初期3発、毎R攻撃後補給可能、補給最大7回、1補給3点なら費用1で20発、費用3で10発（残弾がないとき補給、最終R不要）、最大14回なら17発。実戦勝率ではない。旧08の42発は供給可能総量の理論値で単一武装の実発射保証ではない。
## C 指揮・解析・障壁
指揮車: 基本15%、最大3味方、射程1-3、自己除外、選択対象に付与、次発生元ターン開始まで、発生元撃破/機能停止で消失、選択後の距離維持不要。P38距離2他味方+5%追従、同一P38最大、主行動指揮とは別カテゴリ加算。指揮は04の基礎B後の火力増加、共通/固有pt加算。偵察ドローン15%/W48 20%、射程1-5、1対象実体または1部位、次発生元ターン開始まで、解析は通常敵本体/部位指定時部位のみ、同じ対象系の解析最大、発生元撃破/電子停止で解除。障壁車25%距離2（占有集合最短）、両層/self含む、追従、5回、次発生元ターン開始まで、最強のみ、EMP/撃破で解除。W49局所防護25%は1味方指定（自己不可、射程1–3）、同じ障壁カテゴリ、位置追従不要、発生元撃破/機能停止で解除。対象が障壁車範囲に一部でも入れば実体全体保護。P39+10pt、P40+10pt（対象支援のみ）、個別功績加算。支援の発動・解除は次の攻撃から、同一攻撃スナップショット内不変。
## D 迎撃
提案: 主行動1と残移動権を放棄、迎撃可能タグの攻撃武装を1つ指定（通常武装中心、有限弾薬対応は個別指定）、次自陣営ターン開始まで1回だけ反応。威力標準80%（04のDEF前）、P29迎撃ダメージ+20%は基礎後加算、個別定義優先。セット時弾薬消費なし、発動時通常1消費。敵の自発移動の各合法ステップ（旋回/飛行切替含む）完了後、迎撃者が生存・機能有効、移動者が射程/方向/LOS/対象層を満たすと自動発動。初期から範囲内で動かない敵の攻撃には反応しない。強制移動/増援/反応攻撃では発動しない。迎撃武装は単体限定を標準、範囲は個別許可。複数迎撃はentityId固定順、各発動前再合法判定、撃破後残りは未消費。迎撃は追加主行動を消費しない、反撃/再迎撃連鎖なし。移動者撃破で経路中断、状態変化で残経路が不合法なら現在位置停止、移動権消費済み、未到達建物は破壊しない。移動開始時MOV予算から消費済み分を引き、新状態がMOV低下なら上限のみ下方修正（既消費を取消さない）。旋回禁止等は以後の経路判定へ。移動経路予測は既知迎撃を同じCoreで試算。予測で停止見込みでも合法開始なら実行可能。通常の攻撃に対する自動反撃は導入しない。
## E 予告・CD
予告準備/発動各主行動1、同時1件、個別1戦1回制限。通常は次の敵ターン（自軍1ターン経過後）、B04最終融合は自軍2ターン経過後。準備時に固定座標/方向/層/範囲を保存、移動追尾なし。発動まで準備者移動/旋回/任意切替不可を標準（個別仕様優先）。攻撃対象が範囲外に退避しても発動、空範囲でも消費。準備時使用予約、有限弾薬は準備時消費、発動時二重消費なし。必要部位破壊/撃破/形態で武装喪失/機械通常敵EMPで予告取消、ボスEMPは70%で発動可能なら取消せず、個別停止優先。強制移動/着地で射撃起点または層が変わった場合取消（警告範囲を追尾させない）。発動時に固定範囲と現占有/遮蔽を照合し、現在能力で計算。発動可能ターンに主行動不足の場合は次所属ターンまで延期、最大1回、再延期不可で取消。CD nRは発動/取消R+nの所属ターンから再使用可、通常特殊CD2/広域3/予告4の既存個別値優先。同一特殊1/RはCDとは独立、形態変化でリセットなし。B04等の予告・発動最後の主行動制約は維持。予告中の他主行動は個別制限に従う。UIに発動までの対象ターン、範囲、層、中断条件を表示。
## F 功績とCore
実回復・実補給・有効支援のみ集計。支援寄与は攻撃スナップショットで採用された効果について、支援なし→指揮→P38→解析の固定順で同一計算を行い、各段階の実HP/耐久減少差を帰属、同種同値はsourceId順、合計が実ダメージを超えない。障壁/陣地軽減は最終の実HP減少を上限比較し、陣地→障壁の固定順で差分帰属、過剰分除外（残HP100で軽減前1000/後500は実HP差0、撃破回避の別評価は未定）。有効防護回数は1展開で実軽減が初めて発生した時に1回。移動阻害功績は状態による有効MOV予算減少を対象ターン開始時1回集計、実移動距離ではない、部位永久低下を除外。同一状態/複数発生源の二重集計なし。resolveSupport/resolveSupply/resolveOverwatch/advanceTelegraph/resolveCooldownを共通Coreに分離、反応と移動は原子的イベント列。テスト候補: 満HP、余剰回復、補給不足、支援資材除外、期限、最強同値、迎撃複数/撃破/移動中断/射線/レイヤー/再送、予告退避/取消/EMP/2ターン/CD境界、功績差分。実装未着手、原表欠損継続。
