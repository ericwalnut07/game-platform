## 相場と商機

通常5種類を袋で抽選、全種を消費するまで重複なし。補充境界の連続は可。公開するのは使用済み・残候補で、次の順序は秘匿。開業と特別は袋を消費しない。

| 相場 | 切札 | 商業/工業/調達/行政 |
|---|---|---|
| 安定成長 | NT | 1/1/2/1 |
| 建設特需 | 工業 | 1/2/1/1 |
| 信用収縮 | NT | 1/1/1/2 |
| 交通革命 | 調達 | 1/1/2/1 |
| 消費ブーム | 商業 | 2/1/1/1 |

すべて5トリック。信用収縮は報酬だけ4位→1位/3位→2位/2位→3位/1位→4位。通常商機は各系統2種類、登場1回なら累計が少ない方（同数ランダム）、2回なら各1回。選出後シャッフル。特殊資材は累計に数えない。

| 商機 | 報酬1位 / 2位 |
|---|---|
| 販売 | 最大商品2 / 商品1を、1個資金3で即時売却 |
| 販促 | 各商業建物の販売1行動で資金+2 / +1 |
| 加工 | 資材1→商品3 / 商品2を即時変換 |
| 増産 | 各工業建物の生産に商品+2 / +1 |
| 仕入れ | 資金1 / 資金2→資材1を即時購入 |
| 大量仕入れ | 通常購入2回使用後に資金2→資材1を追加2回 / 1回 |
| 開発 | 建設または上位化1回の資金−2 / −1 |
| 公共事業 | 投資1手を使い無料1枠 / 通常拠出後に資金1 |

直接効果は使用任意・トリック直後のみ・輸送費なし。R限定権利は繰り越さない。公共事業報酬は通常拠出を選ぶことで温存可、使用時にFREE/REBATEを明示。空き枠がない場合は利用できず、代替資源は付けない。

## 同時フェーズ

仕入では市場・在庫処分・交渉を任意順で使用。通常資材購入は資金3→資材1を2回まで。倉庫1回/物流センター2回の各棟割引容量、1購入への割引は最大1。追加の大量仕入れは割引不可。在庫処分はLv3翌R以降、商品1→資金1を2回（購入回数と別）。

提案は各社1R1回、相手1人、送信時に権利消費。受信は無制限。資金/資材/商品を双方1つ以上渡す。所持・赤字制約を提示時と成立時に検査、両側一括交換。対案・贈与・将来契約なし。自分の仕入完了後は新しい提案・市場を使えないが、フェーズが続く間は受信提案へ回答可能。全員完了で未回答は失効。

生産販売は任意順、各棟1R1回。工房1材→2商品、工場1材→3商品（資金獲得なし）。店舗1商品→資金3、商館最大2商品→各資金3。増産/販促は各棟、商館2個販売でも販促は1回。完了不可逆。建物建設はこの後なので能力使用は次Rから。

## 投資・地区・輸送

投資2周、建設/上位化/輸送路/公共事業/パスから1手。1周ごとに開始者+1席（次Rは合計+2席）。最新共有Stateで判定。基本建設/上位化は資金5。上位化は枠追加なし。総6棟/同系統3棟/同地区自社1棟まで。

| 内周 / 外周（Lv2翌Rから） | 枠 | 対応系統・割引 |
|---|---:|---|
| 市場 / ビジネス街 | 各2 | 商業、内周建設−1 / 外周上位化−2 |
| 工房地区 / 工業団地 | 各2 | 工業、同上 |
| 倉庫地区 / 港湾 | 各2 | 調達、同上 |
| 再開発地区 / 新市街 | 2 / 3 | 3系統可・割引なし |

系統指定地区は対応する建物のみ。外周の地区接続も解放後に選択可能。地区割引と開発は重複。費用と輸送選択を確定前に表示。

輸送路は各地区に各社1本（計最大8）。敷設は資材1＋資金2。グラフ・独占・スポーク制限なし。建設/上位化/生産/販売ごとに自社0、選択した他社へ1、公共へ2。自社があっても他を選べる。最初の建物建設の公共輸送のみ無料。

料金はtransportChargesへ記録し、R末で一括精算。未精算収入は使えず、料金上限なし。精算による赤字可。赤字中は正の資金支払いを禁止。販売・在庫処分・資金獲得・資金不要行動は継続可。「余剰資金」の点はmax(資金,0)÷4の切り捨てと解釈し、赤字の資金点は0。順位の赤字区分は別途適用する。

## 公共事業・発展・終了

全3件を最初から公開。中央市場=商品3/資金2/資材1、中央駅=各2、市庁舎=資金3/商品2/資材1。1枠は商品1/資材1/資金2。6枠目で即時完成、各社へ自分の枠数だけ資金還元・発展+5。同R後続投資で還元金を使用可能。

発展は建設+2、上位化+1、輸送路+1、公共完成+5。R末で輸送精算→発展確認→Lv判定（14/28/44、1R最大1Lv、余剰保持）。Lv3翌Rは一度だけ特別消費ブーム：商業切札、商業2/工業1/調達2/行政1の6回。調達1回は特殊資材（2/1/1/0）、もう1回は偏り補正通常商機。在庫処分も同R解放。

Lv4翌Rが最終。R9までに予約、遅くともR10終了。25点トリガーなし。

企業価値：基本棟3・上位棟5、路線各1（最大8）、完成事業の枠各1＋単独最多1（同率0）、余剰資金4ごと1、資材商品合計3ごと1。最終順位は非赤字群優先、各群で企業価値→事業資産（建物/路線/事業）→建物→事業、同じなら同順位。

## 接続・サーバー・秘匿

ユーザー回答でBOTを60秒・簡易運用に確定。同じ席の全接続が切れた時点から計時。DOの永続alarmで切替、4人へ「BOT代行中」。低い合法カード、最大の即時報酬、既存建物利用を選択。輸送費が低い手段を優先。同額なら生産を優先し、商館は可能な最大個数。市場・交渉提案・新規投資はパス、受信交渉は拒否。4人確認も代行。本人再接続時に返還してログ記録、確定済み操作は保持する。

GameModuleに任意の接続hookと自動進行の時刻contextを追加。RoomObjectはHubと迷宮のイベントを直列化。Hubの同時フェーズはphaseVersionを操作ごとに変えず、手番・フェーズ変更時だけ更新。試合内のrequestIdを保持し再送を冪等化、正常な次試合開始時だけ初期化。セッションから行為者を注入し、BOT等の内部actionはクライアントschemaで拒否。

共通RoomSocketは接続確立前の画面破棄・再接続時に、upgrade完了後に旧接続を閉じる。途中で中止したupgradeがサーバー上に残って切断判定を妨げる不具合を、StrictModeと再接続の回帰テストで防ぐ。

Player Viewは明示allowlist。本人の手札・企業価値・操作候補、当事者の交渉だけを送る。他人の手札、企業価値集計、未成立条件、相場袋の順序は送らない。公開行動ログは受理済みイベントから生成・DOに保存・reload後復元。交渉条件は成立イベントだけ公開。最終結果では全員の内訳を公開する。
