## 進行・商機

4席、人間1〜4人＋NPC。初期資金2・資材1・商品0。32枚4スート×1〜8、Must Follow、時計回りリードを維持。

1. 情勢・商機・本人の手札公開、任意ビッド同時非公開→一斉公開。
2. 全トリック→ビッド結果→R2以降の監査官配置。
3. 大型投資の経済前効果→市場/交渉→調達・工業・商業を任意順に建物稼働。
4. 大型投資の投資前効果→投資2巡→輸送費精算→発展/終了判定。

開業6T（3位資金1）、通常5T。序盤の商機構成/支援優先/出現補正はtrial 4と同じ。Lv3到達翌Rに一度だけ8T・8枚×4席・全32枚を使用。商業切札、各席2回リード。販売・販促/加工・増産/仕入れ・大量仕入れ/開発・公共事業を各1回、順序はshuffle。特別資材なし。通常情勢の袋を消費しない。

## 地区・建物・支払い

通常21枠（市場/工房/倉庫各2、再開発/ビジネス街/工業団地/港湾/新市街各3）。外周はLv2到達翌Rから。

全8地区へ異系統建設可。同商会の同地区・同系統だけ重複不可。他社同系統は許可。通常6棟、専用地区1棟、専用含め同系統合計3棟。建物ID単位で稼働/上位化。

建設/上位化は必須資金3＋自由2。自由枠は資金/資材/商品1個で1枠。内周同系統建設は必須資金2、異系統建設は4、外周同系統上位化は2。開発商機は必須資金を軽減。建設は監査・輸送なし、上位化・稼働の監査は即時、輸送はR末払い。専用地区は地区補正・監査・輸送なし。

倉庫は資金1→資材2、物流センターは資金2→資材3または資金1→資材2。工房は資材1→商品2、工場は資材1→商品3。店舗は商品1→資金3、商館は商品2→資金5または商品1→資金3。各棟1回/R、追加稼働効果は別。少量でも1回消費。
