# 大石のテリトリー2 — Web版 ルール v1.0

## 対応モード

- gameId: `ooishi-territory-2`
- rulesVersion: `1.0`
- 1人用：1台で2〜4人の全席を操作するホットシート。AI対戦ではない。「1手戻す」「同じ設定で再戦」「設定変更」に対応。
- オンライン：2〜4人の別端末対戦。人数と「大石1個／2個まで」を部屋作成時に選択し、全員が揃うと開始。
- 一人用の設定画面でも、オンラインの部屋作成と同様にゲームタイトルをプルダウンで切り替えられる。
- アプリ版：0.12.0。

## 人数別の固定設定

| 人数 | 盤面 | 1人の手数 | 手番順 |
| --- | --- | --- | --- |
| 2人 | 8×8 | 12手 | 各ラウンドの開始プレイヤーを交替 |
| 3人 | 9×9 | 9手 | 各ラウンドの開始プレイヤーを1席ずつ順送り |
| 4人 | 10×10 | 8手 | 各ラウンドの開始プレイヤーを1席ずつ順送り |

全員が同じ手数を行い、1手番に石を1個配置する。盤面に十分な空きがあるため通常はパスしないが、合法配置が0件の場合のみパスを許可する。

## 石

石は「小石」と「大石」の2種類。どちらも1×1マス。

- 小石：任意の空きマスへ配置できる。
- 大石：自分の3手目から最終手の1手前まで、任意の空きマスへ配置できる。
- 1・2手目は小石のみ。
- 最終手は小石のみ。
- 大石は使用必須ではない。
- 開始時オプションで、全員の大石上限を「1個」または「2個まで」にする。
- 2個モードでは、大石を2手連続で配置してもよい。

## ゴールデンペア

同じプレイヤーの石2個が、縦・横・45度斜めのいずれかで一直線に並び、距離が2〜5マスなら接続判定を行う。

通常のゴールデンペア成立条件：

1. 2石の間に自分の石がない。
2. 2石の間に相手の石がない。

成立したゴールデンペアは、2石の間にある各空きマスへ影響力1を与える。1つの空きマスに自分の複数ラインが通れば影響力は加算する。

途中に自分の石が置かれた場合、古い長いラインは成立しなくなり、その石を含む新しい組み合わせを改めて判定する。

## 支配と得点

- 石が置かれているマスは、その石の持ち主が確定支配する。
- 空きマスは、各プレイヤーのゴールデンペア／シンクロラインから受ける影響力を合算する。
- 最大値が1人だけなら、そのプレイヤーの支配。
- 最大値同点、または全員0なら中立。
- ゲーム終了時の支配マス数が得点。最多得点者が勝利。同点首位は共同勝利。

## シンクロ

大石ごとに独立して判定する。

### 接続候補

大石と自分の別の石が、通常のゴールデンペアと同じく縦・横・45度斜めで距離2〜5マスの場合、次を満たせば「接続候補」とする。

- 途中に自分の石がない。
- 途中の相手石は0〜1個。

相手石が1個入っている接続候補も、シンクロ成立前の方向数に数える。

### 成立

1つの大石から、異なる方向へ2本以上の接続候補があれば、その大石はシンクロ状態になる。

上下、左右、各斜めはそれぞれ別方向として数えるため、正反対の2方向も異なる方向である。

### 効果

シンクロ中の大石を端点に含む接続候補は「シンクロライン」になる。

- 途中の相手石が0個：通常どおり成立。
- 途中の相手石が1個：その石を貫通してラインを維持する。
- 途中の相手石が2個以上：そのラインは遮断される。
- 貫通される相手石のマスは相手の支配のまま。
- 貫通した先の空きマスへは影響力1を与える。
- シンクロによって影響力の強度自体は上がらない。

2個目の相手石によって有効な接続方向が1方向以下になれば、該当大石のシンクロも解除される。

## 大石2個モード

- 2個の大石は独立してシンクロを判定する。
- 大石同士の距離が2〜5で直線条件を満たす場合、そのラインは双方の大石にとって接続候補1本として数える。
- 大石同士を結ぶラインは、片方だけがシンクロしていてもシンクロラインとして扱う。
- 両方の大石がシンクロしていても効果は重複しない。ラインの影響力は1、貫通できる相手石も1個まで。

## UI

既存『大石のテリトリー』の基本構成に準拠する。

- 現在手番を上部の大きな帯・得点カード・操作欄で表示。
- 盤面の各マスに全プレイヤーの影響力を四隅表示。
- 通常ゴールデンペアは細い破線、シンクロラインは太線。
- シンクロ中の大石には強調表示。
- 「全ライン表示」のON/OFFが可能。OFF時は選択／確認中のマスに関係するラインだけ表示する。
- 配置前プレビューで各プレイヤーの得点差とシンクロ大石数の変化を表示。
- PC／スマートフォン双方で横幅に収め、盤面拡大時のみ盤面領域内で横スクロールできる。

## 通信・サーバー

オンラインではDurable Objectが正しい盤面・手番・合法手を管理する。クライアントが送るplayerIdは信用せず、認証済みWebSocket接続からサーバー側で注入する。

共通基盤の以下を利用する。

- requestIdによる二重処理防止
- WebSocket自動再接続
- スマートフォンのスリープ復帰
- 再読み込み後のセッション復帰
- 部屋期限切れ
- ホスト移譲
- 同室再戦

## D1ログ

既存の共通 `playtest_matches` / `playtest_events` を使用し、新規migrationは追加しない。

記録対象：

- rulesVersion
- 人数、盤面、手数、大石上限
- 全配置
- 最終得点・中立マス
- 大石使用数
- 終局時シンクロ大石数
- 終局時シンクロライン数
- 終局時貫通ライン数

`game_id = ooishi-territory-2` と `app_version = 0.12.0` で既存作品と区別する。
