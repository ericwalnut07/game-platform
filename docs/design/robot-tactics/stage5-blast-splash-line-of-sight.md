# ターン制タクティクス：第3段階 爆風対象と射線の分離（2026-11-09採用）

## 正式ルール

1. **直撃対象／着弾中心**：攻撃者からの武器射程・射線チェックは従来どおり必須。壁などで射線が通らない中心マスや敵は選択できない。
2. **着弾後の爆風対象**：中心の選択が合法であれば、各武器で規定された爆風範囲内の敵は**攻撃者からの射線が遮られていても**選択・命中できる。爆風先へ武器の射程を再適用しない。壁は爆風範囲を削除しない。
3. 対象マスは盤面の範囲内に限定し、既存の中心／周囲4または8マスの形状、敵味方の区別、対象数上限、EN、ダメージ、同一対象の重複適用防止、行動確定／取消の挙動を維持する。
4. 基本の通常攻撃、時限爆弾の**付着時**、その他爆風のない攻撃の射線は変更しない。

## 攻撃ごとの適用

- **通常爆撃**：射線の通る敵中心を指定し、範囲内の周囲敵を手動選択（0〜2体、拡張パーツがあれば既存上限）。壁裏の周囲敵も含む。
- **拡散射撃（射撃系コンボ）**：射線の通る敵中心を一度タップ。周囲8マスの敵を壁裏かどうかに関係なく**自動選択**。確認ボタンは追加しない。
- **二点起爆**：双方の着弾中心の射線は必要。各中心の周囲には射線不要。既存の合算EN・役割優先・重複排除を維持。
- **空地点照準・爆風拡張**：着弾中心を空マスにする場合でも、中心マス自体には射線が必要。各周囲敵と敵対施設は爆風形状で選択。
- **残留爆炎（fire）、継続燃焼弾（burning-round）**：中心には射線、爆風対象には不要。継続ダメージのタイミングや倍率は変更しない。
- **補給施設などの敵対オブジェクト**：中心の占有マスは射線必須、爆風の周囲で重なる占有マスは射線不要。同一施設へのダメージは既存の共有HPプールに1回だけ適用。
- **遅延起爆信管**：爆弾の初期付着のみ従来の射線を必要とする。付着後の起爆・連鎖は既に中心／周囲形状のみで判定し射線の再チェックがないため、従来どおり（変更不要）。

## 実装境界と検証

- Coreの中心候補／隣接候補と最終ダメージPacketの両経路で同じ判定を使う。直撃の検証は通常の `checkRobotAttackSpatial`、周囲は中心からの範囲幾何だけを検証する。
- PC/スマホの候補・選択はCoreの合法対象一覧を使用。クライアントだけで「壁裏OK」を特例追加しない。
- ダメージ計算と攻撃確定はCoreに委譲し、状態保存・リプレイ・敵味方・対象数・壁の半透明表示・補給施設／輸送車画像を変更しない。
- 回帰：壁裏の周囲敵ヒット、直撃中心の射線不可、一般通常攻撃の射線維持、二点起爆、残留爆炎、拡散自動巻き込み、PC/スマホ実操作、リロードで状態一致。
- 共通Webサイトへ統合しない独立ゲーム。対象外のゲーム、クラウド通信、DB migration、deployは作業対象外。
