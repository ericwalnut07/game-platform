# M27〜M29 複合勝利条件の正式採用仕様（2026-11-10）

参照: `late-m25-m27-candidates.json`, `late-m28-m30-candidates.json`。既存設計の勝利条件を変更せず、ユーザーが2026-11-10にM27〜M29の複合勝利条件を正式採用した。既存候補資料の未採用表示より本決定を優先する。

## M27 情報庫の最終突破
- R15までにボス `archive-command-unit` を撃破 **AND** L3端末のデータをJ14へ運搬・送信。達成順序は自由。
- データ取得後、次の適格ラウンド開始時に `encrypted-data-pursuit` 増援。
- 運搬機撃破時はデータを落とし再取得可能。

## M28 三拠点連動防衛
- 中央中継施設 `central-relay` をR12終了まで維持 **AND** E6/J4/O6の3拠点中2拠点以上を2ラウンド連続（ラウンド終了時判定）で制圧。
- 中継施設破壊は即敗北。R7開始時に `r7-support-fire` 増援。
- 施設のHP/DEFは既存資料の難易度別値を使用。

## M29 敵補給区への強襲
- 西東の補給施設 `west-cache`/`east-cache` を両方破壊 **AND** J3の暗号化データをI14へ運搬・送信。R14まで。
- データ取得後、次の適格ラウンド開始時に `data-recovery-hunters` 増援。
- 運搬機撃破時はデータを落とし再取得可能。施設HP/DEFは既存難易度別値。

共通: 部分達成では勝利しない。敵配置、報酬、副目標、難易度、保存互換性は既存正本を維持。ゲームコード変更・テストは本資料に含まない。
