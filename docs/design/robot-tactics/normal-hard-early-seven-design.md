# M01〜M07 Normal / Hard 設計計画（2026-10-29）

> **採用済みの基本方針・敵レベル案**と、**未採用の個別ミッション具体案**を分けて記録する。採用済みEasy M01〜M07のマップ・勝利条件・ラウンド・初期位置・増援・報酬は変更しない。試遊HTMLは正式仕様ではない。

## 1. 採用済み：Normal / Hardの共通方針

- Easyの主要目標・即時敗北条件・マップ寸法・壁・目的物・味方／敵初期配置・小隊数・増援位置とトリガー・ラウンド上限を継承する。
- 難易度差は、まず敵の**基準コアレベル、軽量機のモデル／武器、合法手の判断品質**で実現する。敵数の機械的増加、追加手番、ルール外攻撃、旧ステータス倍率は用いない。
- **Normal：A/B、Hard：B/C**のモデル規則を守る。各軽量3機小隊は同タイプ・同モデル・同レベルとし、個体ごとの武器1個・小隊の4×4まとまり制約を維持する。機動／防御モデルB・Cの武器例のうち未確定なものは**未確定**として扱い、正式採用しない。
- Normal AIは今手番の合法な移動＋攻撃・行動候補を比較。Hard AIは次のプレイヤーの合法的な応手も限定的に予測する。どちらも現在の盤面とゲームで公開されている状態だけを使用し、未来の乱数、未入力の操作を参照しない。
- M01〜M07は推奨コアレベルの既存範囲を継承（Normal Lv5〜11／Hard Lv17〜25）。既存のEXP・アンロック・報酬は変更しない。レベルは推奨基準値で、プレイヤー側への強制レベル制限ではない。
- M02の全難易度8Rは採用済み。M01の正式設計は5Rであり、試遊版のみ6R。試遊版M02ボスHP150／DEF55も正式採用していない。

### ミッションごとの戦術的差別化（採用済みの設計方向）

| Mission | Normalの判断傾向 | Hardの判断傾向 |
|---|---|---|
| M01 施設防衛 | 接近／施設攻撃を優先 | 左右の接近部隊とR3射撃増援が役割分担 |
| M02 指揮機撃破 | 護衛が指揮機への経路を守る | 護衛と指揮機が連携し、接近や集中攻撃を妨害 |
| M03 敵陣突破 | 突破地点の進路を妨害 | 異なる2機の進路を予測して迎撃 |
| M04 補給線遮断 | 左右の拠点を防衛 | 自機の戦力分散を判断して弱い側を迎撃 |
| M05 輸送護衛 | 輸送ルート封鎖を優先 | 車両への攻撃と進路封鎖を組み合わせる |
| M06 複数拠点争奪 | 重要拠点を確保・防衛 | 2拠点2R連続支配の成立阻止を優先 |
| M07 データ回収・脱出 | 回収地点防衛→運搬機追跡 | 回収後の合法的帰還経路を予測して迎撃 |

上表は**AIの設計方向**であり、詳細な重み・経路評価式・装備の効果を確定するものではない。

## 2. M01施設防衛：Normal/Hardの具体案（未採用、次の検討対象）

**継承して変更しない内容：** 13×11、5R、施設 F9/G9、HP160・DEF18、壁 D5/E5/I5/J5、自機 F10/G11/H10、友軍AI E10/F11。初期敵6機（近接3＋機動3）、R3開始時に射撃3が1回増援。5R終了時の施設HPが1以上なら勝利。施設HP0または同一Rで操作自機3機撃破なら即時敗北。

| 役割／座標 | Easy固定 | Normal候補（敵Lv5・武器Lv1） | Hard候補（敵Lv17・武器Lv4） |
|---|---|---|---|
| 左翼近接3：B2/C2/D2 | 近接A | **近接B**：スタンダードソード | **近接B**：スタンダードソード |
| 右翼機動3：J2/K2/L2 | 機動A | **機動A**：ライトブレード | **機動B**：スタンダードソード（武器割当は未確定） |
| R3射撃3：F2/G2/H2 | 射撃A | **射撃B**：アサルトライフル | **射撃C**：スナイパーライフル |

※Hardの機動Bの武器例は現行JSONで**仮案**。承認前に武器の対応・射程・効果を確定する。その他は現行のモデル例に準拠するが、各難易度への割当はまだ正式採用ではない。

**Normal候補AI：** 左翼は遮蔽物を迂回して施設へ接近。右翼は移動力を活かして施設への近い合法経路を選ぶ。射撃増援は出現後に施設射線を取り、撃破可能な自機・友軍との比較も行う。施設を攻撃できるときは意味のない追跡を避ける。

**Hard候補AI：** 右翼機動が施設への早い到達経路を探し、左翼近接が前進を妨害する自機に対応。R3射撃は施設と防衛側の迎撃脅威を評価して射撃地点を取る。各小隊は既存行動順・4×4隊列制約・合法射程を守り、AIの判断向上だけで連携を表現する。**同時攻撃への無条件ボーナスは付けない**。

**必要な検証：** ①低めの推奨Lv装備を持つ自機3機が施設を守る合法手を持つか、②R3増援の射程と5Rまでの実効攻撃機会、③Hardの高Lv武器で施設HP160/DEF18が一気に破壊されないか、④3機小隊隊列制約と壁で行動不能にならないか。これらを確認するまで、M01のモデル割当は**検討案のまま**にする。

M01の3小隊モデル選択・武器（特に機動B）を確定し、必要なら戦術判断を微調整。その後M02〜M07を順に同じ方法で具体化する。M04/M05耐久、M06制圧、M07回収行動など未確定事項は別途確定する。Easyの凍結範囲は変更しない。
