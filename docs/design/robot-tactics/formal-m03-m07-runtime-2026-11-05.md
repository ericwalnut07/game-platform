増援は正本の候補順と4×4小隊配置を利用する。3機分の合法配置がなければ一括延期し、重複出現しない。M03/M04/M07のイベント予約、M05輸送進捗、M06占有・連続値、M07所有者・落下地点を保存し、再挑戦では初期化する。勝利と時間切れが同じラウンド末の場合は正規目標達成を先に評価し、同ラウンド操作3機全滅の敗北を維持する。

Easy中量／重装甲モデルは、配置JSONの旧省略値から `medium-heavy-models.json/policy/appearance/easy` の既採用Aを参照する。新しいモデル値は作っていない。M04/M06で必要な防御Aの制圧メイスは、`basic-parts.json` に既定の通常命中後・次の対象手番終了までの反応攻撃抑制を接続した。即時反撃にも適用し、迎撃／迎え突きも抑制する。通常命中専用のため反応からは再付与しない。状態は保存し、期限・撃破で解除する。

画面には突破線、輸送先、拠点、取得／送信地点と進捗を表示する。HP・機体・選択枠の下へ目標マーカーを配置し、ダメージ／破壊／取得／送信VFXは既存素材を利用する。M06の所有表示は直近ラウンド末の判定結果。正式対象はPC横画面1280×800、タッチ操作のスマートフォン横画面844×390。
