# ターン制タクティクス 第5段階：行動枠・機体確認・副目標リザルトの統合

2026-11-08 試遊後の確定仕様（Stage5 追加UI改善）。土台は Draft PR #126〜#132（最新 #132 の機体画像フラッシュ修正を含む）。**独立・完全オフライン・PC/スマホ横画面のみ**。共通Webゲームサイトへ統合しない。本番deploy・D1 migrationは行わない。

## 1. 行動枠のひし形化（表示のみ）
- 現在手番の機体がいる **床タイルに沿ったひし形** を黄色の枠で表示。論理マス内の `rect` を床レイヤーへ配置し、既存の `robotIsoWorldMatrix` により床と同じひし形へ投影する。
- 旧機体スプライトに重なる黄色い正方形アウトラインとSVGフォールバックの黄色枠を除く。黄色は機体・武器・VFXより背面、施設・マス操作の当たり判定にも影響しない。
- スポットライト（味方水色/敵赤）との役割を区別する。行動機体・確認対象が同じでも、黄色は静的な床枠で点滅しない。シールド表示は従来どおり残す。

## 2. マップ強調と左サマリーを一元化
- 戦闘画面内の一時的な `inspected`（機体または施設のID）に統一。旧 `focusedUnitId` を撤廃し、**独立した2つの選択状態を保持しない**。
- 左の味方一覧・右の生存敵一覧・マップ上の機体タップは同じIDに書き込み、対象マスの水色／赤の発光、名前とHPバー、左サマリー（HP/EN、武器、状態）を**同時表示**。
- 同じ機体の再タップ、左サマリーの「閉じる」、空きマス、カメラ操作、戦闘操作開始で一緒に解除。別の機体をタップすれば両方切り替える。施設は従来のサマリー表示に対応するが、機体スポットライトは出さない。
- 実行中の攻撃対象・移動先・爆撃対象・友軍AI指示の選択は**従来操作を優先**し、機体確認に入力を奪われない。手番・行動・ENの変更、セーブへの記録はしない。
- モデル更新時はHP/ENの最新値で描き直し、撃破/消失した機体IDを解除。新しい行動/手番でも解除。マップ上の通常名/HPは引き続き非表示。

## 3. リザルトの正式条件と報酬内訳（表示のみ）
- 正式採用 `all-90-subobjectives-final-2026-11-07.json` に登録済みの難易度別副目標条件を `getRobotSubobjectiveText` から表示。実際の現行カタログでは **1ミッション・1難易度につき1副目標**。未達成でも条件全文を表示し「未達成・+0 EXP・獲得なし」とする。
- `missions.json` の `firstClear`/`repeatClear`/`firstSubobjective` のEXPと、既に**保存・確定済みの `RobotOfflineResult.expGained`** とを照合。初クリア、繰返し、再挑戦で初めて副目標達成した場合、再度達成したが受取済みの場合を区別する。合計は `expGained` を正本とし、報酬付与ロジックを再実行しない。
- 例外的にEasy M20は「初回クリアのみ」と「再クリア＋初副目標」のEXP合計が同じため、確定済みの初回クリア装備解放 `equipmentUnlocked` で区別する。曖昧・不整合な保存済み結果を推測した値で表示せず、合計を正本として内訳確認不可の注意を表示する。
- 初回だけの追加パーツは、実際に `equipmentUnlocked` にあるIDから正式名称へ変換して表示。受取済みなら「達成・報酬受取済み」「今回+0 EXP」「追加報酬：受取済み」。メイン解放報酬はメイン欄、別途既存の解放一覧表示は保持。
- 上から「結果（ミッション名/難易度/終了R）→メイン報酬→正式条件と副目標報酬→**合計獲得EXP**」とする。既存の再プレイ/ミッション選択/カスタマイズボタン維持。
- セーブv2、既存ローカル進捗、勝敗・副目標判定・EXP/パーツ付与・二重精算防止を変えない。
