# 戦闘共通機能の実装状況（2026-11-03）

PR #95 の VFX と、その依存元 #94 の正式 M01 / 共通Coreを継承した差分。戦闘共通機能の全完成ではない。確定した数値・武器性能・連携条件・得点・勝敗・育成JSONを変更しない。未接続の追加パーツを装備した出撃は既存の拒否を維持する。

## 正本・検証の範囲

- 正本: [rules.json](rules.json)、[offline-formation-policy.json](offline-formation-policy.json)（特に unresolvedNotApproved）、[addons.json](addons.json)、[武装コンボ21組の正本](weapon-combo-21-pairs-2026-10-31.md)、[basic-parts.json](basic-parts.json)、関連PR #79 / #94 / #95。
- 正式M01のブラウザ検証は、初期進行状態の通常移動→追加移動と、通常のバックアップ読込を使った明示的な高Lv/解禁済みテスト進行状態のデルタを分ける。後者は初期状態での解禁やM02〜M30の正式攻略を証明しない。敵HP/EN/位置や本番AI/ランタイムの注入は行わない。
- 型チェック・対象Unit・独立HTML/Nodeコントローラービルド、PC/スマートフォン横画面（既存縦画面回帰も維持）の対象ブラウザテストを実施。実際の結果・対象コミットはDraft PR本文へ記録する。
- 新画像やゲームロジックを持つVFXは追加しない。PR #95のイベント投影・表示専用レイヤーを再利用し、HP/ユニット/選択表示を維持する。
- 共通Webサイト統合・マージ・本番公開/デプロイなし。
