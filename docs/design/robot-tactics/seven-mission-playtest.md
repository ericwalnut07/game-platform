# ロボット戦術：序盤7ミッション試遊版（2026-10-28）

## 起動方法

**スタンドアロンのブラウザ試遊**です。ゲームサイトの既存ルーティング・既存ゲーム・Workers/D1は変更しません。

- 1ファイル版：[public/robot-tactics-seven-missions.html](../../public/robot-tactics-seven-missions.html) をGitHubからダウンロードしてPCまたはスマートフォンのブラウザで開く。ネット接続は不要です。HTMLに設計マップデータと実行コアを埋め込んでいるため、追加ファイルのダウンロードも不要です。
- Vite開発サーバーで確認する場合は、`/robot-tactics-seven-missions.html` で開けます（ただし本番Workersには未デプロイ）。
- 上部セレクタで M01〜M07、Easy/Normal/Hardを切り替えられます。マップはタップ/クリック操作。自機の手番では、移動後に攻撃・連携・チャージ・防御・待機を選びます。
- 敵・友軍AIの行動は「次のAI行動」または「AIを次の自機まで」で進めます。友軍AIだけ自動に切り替え可能です。
- スマートフォンは盤面スクロール・ズーム・全体表示が使用できます。表示領域は仮UIで、正式版の最適化は別途。
- 詳細データは [early-seven-layouts.json](early-seven-layouts.json)、完成形の設計資料は [current-group-combat.json](current-group-combat.json)・[rules.json](rules.json) を参照。

## 試遊版に実装した要素

- 設計済みM01〜M07の全ての初期座標、壁、敵小隊、中量/重量/ボス、味方3機＋友軍AI2機。
- 7つの勝利条件：5R施設防衛、指揮機撃破、別々の自機2機突破、補給拠点2つ破壊、輸送車護衛、2拠点2R連続支配、データ回収・自陣送信。
- 各ミッションで採用された1回限りの敵増援（M02なし）、軽量機3機の同型小隊、共同イニシアチブ・攻撃ダメージのバッチ処理、敵再出撃なし。
- SPD順の手番、自機の移動＋1行動、通常攻撃、簡略薙ぎ払い、防御、チャージ、ライン・ペア・デルタ・挟撃・防護陣。連携補助者はEN/行動を消費せず、同じ連携技は自軍1ラウンド1回。
- 自機/友軍AIのR+2再出撃、共有された施設HP/DEF、施設の両占有マスへの攻撃と同時命中の重複防止。
- 敵は目標優先・防衛/遊撃などの簡略AI。味方AIの指示5種類とAI行動の一部予告、戦闘ログ、操作ログのコピー。

## 必ず守る「試作限定」の境界

**この試遊版は最終ゲームロジックではありません。** 次の未実装や仮設定を正式ルールへ持ち込まないこと。

| 項目 | 試作上の実装・仮値 |
| --- | --- |
| MOV | 壁/他ユニットを避ける**上下左右BFS**での移動。確定済み4種類の移動タイプ固有の座標集合・MOV6/7はこの版では未実装。試遊の所要Rは参考値にとどめる |
| プレイヤー育成 | 自機3機を簡略固定能力値で使用。CAP・装備6枠・パーツレベル・装備変更画面は未実装 |
| 敵能力値 | 軽量機は設計のLv1/Lv5/Lv11参照値。中量・重量・ボスは基礎能力値を暫定使用。**旧Normal/Hardの一律ステータス倍率を適用しない**。武器倍率や敵Lv成長は正式未実装 |
| 目標耐久 | M01施設のみ採用値HP160/DEF18。M04補給拠点は各**仮HP100・仮DEF45**。M05輸送車は**仮HP180・仮DEF30** |
| M05輸送 | 各ラウンド終了時に、次のルートマスが空いていれば1マス進行。通行判定やルートの細部は試作ルール |
| M06制圧 | **仮ルール**：拠点からマンハッタン距離1以内の味方数が敵より多い場合、そのR終了時に味方支配。2拠点×2R連続が正式の勝利条件 |
| M07回収 | **仮ルール**：直接操作する自機が端末/ドロップ地点に入ると自動回収。正式な回収アクションの消費行動は未決定 |
| 連携幾何 | ライン・ペアは暫定の隣接1機。デルタ/防護陣は2×2のL字。挟撃は敵を直交する両側から挟む。公式の各技の範囲/射線細部は追加検討 |
| 装備解放 | 挟撃・防護陣を試すためのスイッチのみ用意。「連携技拡張」等の実物装備管理・追加パーツ60種は未実装 |
| EN/特殊技 | 試作用に基本回復と攻撃・5連携を先行。シールド、追加移動、迎撃、各武器の固有効果と全コンボは未実装 |
| AI・射線 | 敵行動の比較評価は単純化。正確な射線角・相手の次手番予測・AIスコア・武器別エフェクトは未完成 |
| バランス | 7面の自動「待機」スモークは勝率評価ではない。HPやR上限を都合で変えず、実際に自機を操作した試遊をもとに別途調整する |

## 検証

```sh
npm.cmd run test:robot-seven
```
