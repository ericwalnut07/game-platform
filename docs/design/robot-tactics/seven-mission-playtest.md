# ロボット戦術：序盤7ミッション試遊版（2026-10-28）

## 起動方法

**スタンドアロンのブラウザ試遊**です。ゲームサイトの既存ルーティング・既存ゲーム・Workers/D1は変更しません。

- 1ファイル版：[public/robot-tactics-seven-missions.html](../../public/robot-tactics-seven-missions.html) をGitHubからダウンロードしてPCまたはスマートフォンのブラウザで開く。ネット接続は不要です。HTMLに設計マップデータと実行コアを埋め込んでいるため、追加ファイルのダウンロードも不要です。
- Vite開発サーバーで確認する場合は、`/robot-tactics-seven-missions.html` で開けます（ただし本番Workersには未デプロイ）。
- 上部セレクタで M01〜M07、Easy/Normal/Hardを切り替えられます。マップはタップ/クリック操作。自機の手番では、移動後に攻撃・連携・チャージ・防御・待機を選びます。
- 敵・友軍AIの行動は「次のAI行動」または「AIを次の自機まで」で進めます。友軍AIだけ自動に切り替え可能です。
- スマートフォンは盤面スクロール・ズーム・全体表示が使用できます。表示領域は仮UIで、正式版の最適化は別途。
- 詳細データは [early-seven-layouts.json](early-seven-layouts.json)、完成形の設計資料は [current-group-combat.json](current-group-combat.json)・[rules.json](rules.json) を参照。

## 試遊版に実装した要素

- 設計済みM01〜M07の全ての初期座標、壁、敵小隊、中量/重量/ボス、味方3機＋友軍AI2機。
- 7つの勝利条件：**6R施設防衛（今回の比較試遊値）**、指揮機撃破、別々の自機2機突破、補給拠点2つ破壊、輸送車護衛、2拠点2R連続支配、データ回収・自陣送信。
- 各ミッションで採用された1回限りの敵増援（M02なし）、軽量機3機の同型小隊、共同イニシアチブ・攻撃ダメージのバッチ処理、敵再出撃なし。
- SPD順の手番、自機の移動＋1行動、通常攻撃、**特攻（最大射程1の近接武器のみ、距離2から追加1歩踏み込んで単体攻撃、EN0）**、薙ぎ払い（**自機に隣接する直線3マスのうち最大2体、各70%**、上下左右の方向を選択）、防御、チャージ、ライン・ペア・デルタ・挟撃・防護陣。連携補助者はEN/行動を消費せず、同じ連携技は自軍1ラウンド1回。
- 自機/友軍AIのR+2再出撃、共有された施設HP/DEF、施設の両占有マスへの攻撃と同時命中の重複防止。
- 敵は目標優先・防衛/遊撃などの簡略AI。味方AIの指示5種類とAI行動の一部予告、戦闘ログ、操作ログのコピー。

## 2026-10-28 プレイテストの指摘と調査（比較試遊の調整を承認・反映）

ユーザーが実際にM01/M02を試遊した結果、次の内容を報告。**M01=6R、M02指揮機HP150・DEF55はユーザー承認済みの比較試遊値であり、試遊版へ反映した。設計正本の既存値（M01=5R、指揮機例HP210・DEF70）は正式変更の採用前のため維持する。**

1. **斬撃の特攻が使えない**：`rules.json/combat/chargeAttack`に確定済みだが試遊版に未実装だったため、距離2から追加1歩→射程1通常攻撃（EN0）を追加。通常移動後にも使用可。範囲攻撃とは併用しない。
2. **薙ぎ払いが実質1体しか当たらない**：旧実装は「攻撃者と第2対象が距離1」かつ「第1対象と第2対象が距離1」を要求。四角格子でこの3者は成立しないためバグ。以前の修正は「自身の射程内2体」に過ぎず、確定仕様の3マス帯と一致していなかった。**方向を選択した先の直線3マス（上下は横3マス、左右は縦3マス）の敵最大2体だけ**を各70%で攻撃するよう再修正。端の斜め隣接マスを含む。
3. **M02指揮機が強すぎて7Rに約HP100残る**：試遊版のボスHP210/DEF70（`current-group-combat.json`のLv1指揮機例をそのまま使用）に対し、固定自機の通常ダメージは1発約14/13/12。3機全員で1R39ダメージ相当だが護衛・移動に数R要する。**装備育成/武器コンボ/連携発動の容易さが未完成**なので、完成版の能力不足とは断定しない。比較試験の候補から**ボスHP150/DEF55をユーザーが試遊用として承認し、実装済み**。簡易追試ではボス優先の固定方針（自機が最寄りへ移動して攻撃、連携技なし）で現行210/70はR7終了時HP76、160/60はHP6残り、150/55はR7勝利。戦術・AI・移動が簡略化された**各1ケースだけ**の結果で、勝率や適正値の根拠にはしない。
4. **M01施設防衛が容易**：敵の初期位置が上段R2、施設F9/G9で離れており、5R中の実効攻防時間が短い。プレイテスターの提案は防衛期間の延長。**6Rの比較試遊案をユーザーが承認し、試遊版では6Rに変更**。7Rや敵初期位置の前進は未採用で、設計正本の旧値5Rは追試後の判断まで維持。

テストで特攻/薙ぎ払いの回帰ケースと**M01=6R、M02ボスHP150・DEF55の全難易度・画面表示テスト**を追加。**今回変更したのは試遊版のM01制限RとM02ボス耐久のみ**。初期座標・増援条件・他ミッション・設計正本は不変。追試後に正式採用するか判断する。

## 2026-10-28 M01〜M07実試遊レビュー・追補

ユーザーが7ミッションまで実際に試遊し、M01の6R化とM02ボスHP150/DEF55は「改善は良かった」と評価。

### 薙ぎ払いの確定仕様に合わせた修正

- **射程1の斬撃武器専用**。自身の上下左右いずれかを選び、その方向の**1マス先に位置する連続3マス帯**を攻撃範囲とする。例えば自機G5の上方向なら **F4/G4/H4**、左方向なら**F4/F5/F6**。中心マスが空でも両端の敵に当たる。
- その帯にいる敵**最大2体**へ、それぞれ「通常攻撃×0.7」（既存の切り捨て）のダメージを与える。帯外の敵は対象にならない。EN0、通常攻撃の代替行動。特攻と同時発動不可。
- UIは**薙ぎ払い→方向選択→金色の3マス帯を確認→実行**。3マス全部に敵がいた場合の選択は正式UIで未決定。試作版は座標順（左から／上から）先頭2体に自動的に攻撃する。
- 汎用射程1斬撃以外（射程延長、特殊3体攻撃武器など）の細部は対応武器実装時に別途確認。正式仕様の方向別マス集合は `rules.json` を参照。

### M04・M07の移動時間が長い

**実試遊結果：** M04は両拠点到達と破壊に時間がかかり、M07は敵端末への往復に時間がかかって、双方ともラウンド切れで失敗。

**原因の切り分け：** この試作版の `moveOptions()` は上下左右に各1マスずつのBFS（移動3なら合計3歩）であり、確定済みの「直線・斜め・全方向・前進」の4タイプごとの**特殊な到達マス集合**は未実装。公式移動仕様と一致した状態で7面を再試遊するまで、M04/M07のラウンド延長や目標移動を正式決定しない。

| ミッション | 現状の最低限の移動見積り（障害物と敵機なし） | 検討順序 |
| --- | --- | --- |
| **M04** | 自機H14から左補給拠点E3に隣接するE4までマンハッタン13マス。MOV3のBFSだと**最短5回の移動機会**が必要。その後HP100/DEF45（試作用）の拠点破壊が残る。左右2拠点。制限8R | ①正式MOVタイプ適用 ②破壊の行動回数とNPCの妨害状況確認 ③なお厳しければ拠点位置や制限Rを検討 |
| **M07** | 機動自機J14→端末J3は11マス、端末→送信I13は11マス。MOV4のBFSなら**最短3回+3回=6回の移動機会**が必要。敵・壁・前方への制約を除いた下限。制限10R | ①正式MOVタイプ適用 ②移動特化機体と帰路の妨害を検証 ③なお厳しければ端末の位置や制限Rを検討 |

今回の作業では**M04/M07の配置・勝利条件・制限ラウンド・敵性能は変更しない**。移動タイプの再実装とマップ難易度調整は独立した後続タスクとする。
