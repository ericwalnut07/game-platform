# 戦闘システム改善 第1段階：特殊攻撃で敵対施設を攻撃

## 基準と対象
- Draft PR #142 の全実装を継承する依存ブランチ。
- 第1段階のみ。第2段階「斜めライン連携」、第3段階「防御系行動による敵AI優先度」は**未着手**。
- 単体オフライン『ターン制タクティクス』のみ。共通Webサイト・本番Cloudflareは対象外。

## 実装設計
- `specialFacilityTargets.ts` で、敵味方判定 `isRobotBattleHostileObject`、生存施設、占有マス、射程、壁による射線を再利用し、合法な施設マスを列挙する。
- 施設のHP/DEFは施設オブジェクトの正本を使用し、機体への偽装をしない。施設ダメージは既存の `commitRobotBattleBatch` → `settleRobotBattleConsequences` を使用し、複数マス施設は一つのHPプールに一度だけ適用する。
- `activeCombat.ts`: 特攻・超特攻の施設踏み込み候補と合法な隣接着地、継続燃焼弾・震央反響・引戻し槍撃の施設ダメージ。施設には押出・引戻し・燃焼状態を付与しない。
- `remainingCombat.ts`: 単体のダメージ型特殊射撃（対物集中、粉砕拘束、機能停止）を施設へ適用。機体専用の行動制限を付与しない。対物集中のDEF補正は施設のDEFに適用する。
- `commonCombat.ts`: 近接狙撃の施設へのダメージ。刃渡りは敵機体を越える着地を伴うため、対象拡張の際には別途合法着地が必要。
- `adoptedEffects.ts`: 戦術標定攻撃は施設へのダメージのみ。施設に機体専用のマークを付与しない。
- 従来の通常攻撃・爆撃攻撃・施設攻撃・武器性能・EN消費・射程・射線・セーブ形式は変更しない。
- UIは `FormalBattleAdapter` がCoreの `targetIds` を選択肢として表示する仕組みを継続利用する。新しいUI専用の合法判定は持たない。

## 対象外とする効果
- 回復、味方支援、状態異常のみの攻撃、施設への引き寄せ・押出・機体状態異常。
- 遅延起爆信管の付着は機体専用の時限爆弾状態を保持するため、施設への付着・連鎖は今回追加しない。
- 特殊攻撃の射線を無視する例外は新設しない。

## テスト
- M04 の2マス施設に対する合法射程・射線・敵味方、施設HP減少、特攻の踏み込みと占有マス回避、戦術標定の機体専用マーク非付与、Production Adapterの施設候補。
- 既存の早期ミッション、爆撃、追加パーツ等の対象Unitを回帰確認。
- PC・スマホ横画面の対象操作確認。未実施の項目はPRに明記する。
