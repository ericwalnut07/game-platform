# M01〜M07本格試遊版 v0.1：実装・検証状況（2026-10-29）

## 狙い
- `public/robot-tactics-full-playtest.html`：**単体HTMLの開発用試遊ページ**（本番Webサイト未接続、デプロイなし）。
- M01〜M07 × Easy/Normal/Hard＝21設定、固定レイアウト・増援・勝利条件を流用。今回の確定済みフレーム/HP B、友軍AI成長、中量/重量/軽量モデルと武器Lvの算術を反映して比較を可能にする。
- M01は正式の**5R**、M02は全難易度8R。旧試遊ページ`robot-tactics-seven-missions.html`はM01試用6R等の比較用に残し、別物として運用。

## 現時点で追加した機能
- 自機3機の各機体で、初期フレーム**4モデル**（攻撃型Ⅰ／反応炉型Ⅰ／防御型Ⅰ／機動型Ⅰ）、初期パーツ**18種類**を選択可能。
- コアLv1〜41／各装備枠6枠（武器2枠）のパーツLv1〜10を設定。Lvと装備を変更して即時にHP/DEF/MOV/SPD/CAPを表示。CAP上限100＋5×(Lv−1)と同一機体2武器のID重複禁止を検証。
- コアHP B・フレームLv21のMOV/攻撃力強化・装備チェックポイントを計算。武器は採用済みのLv1/5/8/10線形補間、**非武器パーツの中間Lvは試作用線形補間**。
- 敵はNormal/Hardの正本14編成から敵基準Lv・軽量A/B・中量／重量A/Bのモデル・武器Lv1〜8・ステータスを反映。**Easyの正確な敵コアLvは未確定のため、当面は推奨範囲の下限Lv1を使用する仮設定**。Easy固定の敵数・配置・敵出現条件は変更しない。
- 友軍AI（2機）は配置指定に対応した前衛/射撃プリセットを読み込み、敵基準コアLvで成長、全装備Lvは共通敵武器帯、HP B適用。装備は変更不可。AI手番の武器選択を改善。
- 操作できる戦闘：選択武器を切り替えた通常攻撃、特攻、薙ぎ払い、防御、チャージ、近接2武器コンボ（EN50）、同系統強化（EN40）、追加移動（EN40・追加3マスの試用移動）、迎撃態勢（EN25）、ライン／ペア／デルタ／挟撃／防護陣連携。
- 既存試遊エンジンの手番順・軽量3機小隊の同時攻撃・友軍戦術指示・再出撃R+2・単独の初期／イベント増援などを再利用。

## 正式仕様と未解決部分を混同しないための注意
本版は**動作・編成UIを先に試す統合第一段階**で、まだ正式戦闘バランスの検証版として完成していない。

1. 4移動タイプ（直線/斜め/全方向/前進）の正式なMOV1〜7到達座標は**未実装**。現行版の移動は旧試遊用の上下左右BFSであり、実際の目標到達R・防御陣形を検証する根拠にしない。
2. 武器種ごとの全固有効果（EN妨害、SPD/DEF低下、押し出し、重火器の追加EN消費、複数対象範囲など）と未確定の特殊技は全てを再現できていない。戦闘難易度/勝率の確定判定は不可。
3. M02指揮機の独立HP/DEF、固有技・武器は未正式採用。試遊値HP150/DEF55を使用。M04補給拠点HP100/DEF45、M05輸送車HP180/DEF30、M06制圧、M07データ回収の細部も既存試作用の仮設定。
4. 軽量機の防御Aや機動Bの武器割当は候補のまま。Normal/Hard敵の装備Lvは採用値だが、未確定武器を正式決定したことにはならない。
5. 友軍AIは正規の5指示・基本的な武器選択を扱うが、難易度別の完全AI探索や、敵の戦術判断は未実装。現時点で友軍は各面2機（3機目の編成指定は未実装）。
6. PC/スマホ画面、21ケースの進行、CAP、攻撃式の専用テストを追加したが、**勝率・到達可能性・AIや連携の全合法性が検証済みという意味ではない**。リプレイログ比較と敵AIの詳細スコアも未実装。

## 検証方法
- `npm.cmd run test:robot-full`：設計モデルと21ステージ統合スモーク。Windowsオンライン時は対象commitで検証し、`tests/unit/robot-full-playtest*.test.ts`と`tests/e2e/robot-full-playtest.spec.ts`によりPC/モバイル操作も確認する。
- GitHub Actionsで`verify`とChromium PC/モバイルE2Eを確認。Windows `ericwalnut`は2026-10-29時点で**オフライン**のため、Windows実機検証は未実施。
- 本格的なバランステストは、未実装の正式移動・武器効果と目標ルールを揃えた後に開始し、Easy/Normal/Hard別にクリアR、目標HP推移、被ダメージ、NPCの機能、デッドロックを記録する。
