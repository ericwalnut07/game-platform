# Inferno敵機：特殊行動とAI価値判断の採用仕様（2026-11-12）

## 適用範囲・保護事項
- 本文はユーザーが正式採用した**Inferno専用ゲームデザイン仕様**。実装済みであることは意味しない。既存Easy/Normal/Hardの敵行動・ボス固有スキル・セーブ互換性を変更しない。
- Inferno敵コアの想定レベルは61〜81（中心70）。Lv41以降のEN成長率は既存確定仕様の基準成長量25%を維持。Inferno専用EN容量増加は未採用。
- 軽量敵はENなし・特殊行動なし。中量敵は通常特殊行動2種類、重量敵は3種類、ボスは通常2種類＋Inferno固有2種類。
- 攻撃・妨害系の特殊行動は原則として**通常攻撃ダメージ＋特殊効果1つ**。強化攻撃は通常攻撃の1.5倍。防御・迎撃・反撃は別途リアクション。ボスの全体攻撃は各対象に通常攻撃ダメージの65%を与える攻撃形態であり、単体通常攻撃を二重加算しない。

## 正式採用：EN消費
通常特殊行動は機体の最大EN・レベルに関係なく固定値。

| 強化攻撃（通常攻撃×1.5） | 45 |
| DEFダウン | 40 |
| EN回復妨害 | 50 |
| SPDダウン | 30 |
| MOVダウン | 30 |
| マス押し出し | 30 |
| 固定継続ダメージ | 40 |
| 迎撃 | 35 |
| 反撃 | 30 |
| 被ダメージカット | 35 |
| ボス：敵軍全体強化 | 80 |
| ボス：プレイヤー軍全体弱体化 | 90 |
| ボス：全体攻撃 | 100 + ceil(最大EN × 0.10) |

ボス固有行動の再使用間隔は3ラウンド。従来難易度のボススキル（指揮号令等）を上書きせず、Inferno専用行動セットとして分離する。

## 通常特殊行動の効果（採用済み設計の整理）
- DEFダウン：対象の元DEFを基準とした低下量 `floor(0.15*DEF + 0.001*DEF^2)`、対象行動2回。DEF下限1。最終的な上限処理は実装時要検証。
- EN回復妨害：回復量−50%、対象行動2回。現在ENは直接減らさない。
- SPDダウン：−25%、対象行動2回。MOVダウン：−1、対象行動2回。
- 押し出し：1マス。移動先が塞がる場合は移動しない。
- 継続ダメージ：対象行動終了時に固定15、対象行動3回。
- 迎撃：通常攻撃ダメージの70%、射程内侵入に反応、1ラウンド1回。
- 反撃：通常攻撃ダメージの60%、被攻撃後に生存し攻撃者が射程内なら反応、1ラウンド1回。
- 被ダメージカット：受けるダメージ−40%、1ラウンド1回。
- ボス敵軍全体強化：生存敵軍のATK/DEF/SPD＋20%、2ラウンド。
- ボスプレイヤー軍全体弱体化：生存プレイヤー機のATK/DEF/SPD−15%、2ラウンド。
- ボス全体攻撃：全プレイヤー機へ通常攻撃ダメージの65%。通常単体攻撃を追加しない。
- 同種弱体化は加算重複させず、強い効果を優先。攻撃1回につき追加特殊効果は1つ。

## 正式採用：AI価値判断
AIは「ENが足りれば特殊攻撃」ではなく、使用可能な通常攻撃、特殊攻撃、防御反応、ボス固有行動を比較し、現在の効果と将来のEN価値から行動を決める。

1. **撃破・実ダメージ**：撃破できる行動を高評価。通常攻撃で撃破できるなら原則ENを節約。ただし温存によって確実な撃破機会を失わない。
2. **弱体化**：対象能力、残HP、残り効果時間を考慮。同種効果が残っていれば更新価値がある場合のみ再付与。短命の対象への長期弱体化を過大評価しない。
3. **EN温存**：次の1〜2ターンで有効な重要行動（特にボス固有行動）を使える見込みなら、通常攻撃を選んでENを貯めることがある。次行動までの回復見込みも評価。
4. **防御反応**：反撃は期待ダメージ・撃破可能性と将来ENを比較。迎撃は射程と攻撃機会の価値を比較。被ダメージカットは予想軽減量と残HPを比較。撃破を防ぐ防御は原則EN温存より優先。各反応の1ラウンド1回制限を維持。
5. **ボス全体強化**：強化対象数と強化後に行動可能な味方数で評価。味方2機以上を通常の優先目安とするが、1機でも戦況を変えるなら使用可能。
6. **ボス全体弱体化**：複数対象への有効性、効果重複、残り時間を評価。
7. **ボス全体攻撃**：単体攻撃との合計期待ダメージと複数撃破可能性を比較。
8. **機体差**：中量は通常攻撃中心、重量は特殊行動を積極評価、ボスは固有行動のためのEN確保を重視。ただし固定の無条件発動規則にはしない。

評価係数・数値閾値は実装時に調整可能な技術詳細であり、上記の判断原則を変えないこと。

## 検証の位置づけ
- Lv61/70/81のEN容量はLv41既存表とLv41以降の25%成長率からの**推計**。Lv41以降の正式整数表、武器・装備補正は未反映。
- 12ターンの簡易モデルで固定EN消費は概ね成立したが、移動・射線・被弾・死亡・実武器ダメージを統合した実戦検証ではない。
- ボス6機の簡易試算は既存Hardの装備前ENを仮使用し、Inferno正式ENではない。M2/M9の固有技が発動しにくいためEN温存AIを採用。
