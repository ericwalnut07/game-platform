## 正式仕様

[機械可読の最終仕様](delayed-fuse-policy-2026-11-04.json)と[追加パーツ正本](addons.json)を更新。M13 Hard初回サブ目標、CAP24、爆撃武器、EN10・1行動を維持する。付着時はダメージなし。**攻撃値は付着時に固定**し、使用武器ID/Lv、コマンド補正も保存する。防御・軽減・配置は起爆時の対象から求める。**味方が再出撃したとき、敵に付着した爆弾もすべて解除**する。今回の追加確定により保留は解消した。

中心は通常攻撃基準100%、周辺は40%。通常爆撃の4近傍／広域榴弾砲の8近傍にいる敵全員を自動判定し、味方・施設は攻撃しない。手動周辺上限や二点起爆の倍率重複制限は適用しない。通常攻撃専用補助・命中EN・武器追加消費は付けない。既存の最低ダメージ、DEF下限、乗算・最終切捨は保持する。

## Core・状態・保存

- `delayedFuse.ts`：装備・生存・射程・射線・EN確認、付着、攻撃値スナップショット、行動終了。
- `fuseResolution.ts`：時限、他味方の直接命中、付着機の撃破、爆風命中から、設置順の起爆キューを解決。各爆弾はダメージ適用前に起爆済みにする。新たに誘爆した爆弾も設置順で選び、1個を再起爆しない。
- 直接攻撃 → 武器付随効果 → 押出/引寄せ → 衝突 → 最終位置 → 誘爆 → 反撃 → 手番末回復/DOT/時限起爆 → 決着を既存の原子的な行動結果に含める。反応命中とDOT等による付着機撃破も接続する。
- 爆弾ID、所有者、対象、武器、攻撃値、順序、対象自身の起爆予定手番、最終位置、起爆状態をCoreに保存。旧チェックポイントの項目省略は爆弾なしとして互換維持。未公開フェーズは保存不可。
- 爆発の撃破は最後にHPを0にした爆弾の所有者。生存していれば手番外もEN+5、所有者の専用ラウンド記録で1R1回。装備の独立効果は既存処理を維持する。
- 失敗した保存ではHP/EN/付着状態を公開しない。CAS、actionId、sequenceを再利用し、再送・再開で二重消費/ダメージを起こさない。リトライ/再出撃/戦闘終了で付着を解除する。
