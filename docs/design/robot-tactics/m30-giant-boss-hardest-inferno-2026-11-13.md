# M30 最終形態・巨大ボス：Hardest / Inferno 採用仕様（2026-11-13）

> 状態：ユーザーとの設計対話で採用済み。**設計仕様の保存のみ**。ゲームCore/UI/セーブ/配布HTMLには未実装。共通Webサイトへ統合・デプロイしない。
> 対象：1人用・完全オフラインの「ターン制タクティクス」。既存Easy/Normal/Hard、M01〜M29、既存セーブの互換性を維持。
> 参照：既存のM30仕様・各武器/連携/追加パーツの正本は引き続き有効。本書はHardest/Infernoの**M30追加第二段階**について優先。

## 1. ミッション構成と勝敗

- 第1段階：16ラウンド以内に敵20機を撃破。軽量12機（4系統×3）、中量4機（4系統×1）、重量3機（3系統×1）、指揮機ボス1機。
- Easy / Normal / Hardは従来どおり第1段階の勝利で終了。**巨大ボスは出現しない**。
- Hardest / Infernoは第1段階の勝利後、第2段階へ移行。自軍3機を初期配置へ戻し、巨大ボスが中央付近に降下・着地する演出を入れる。第2段階は別のラウンドカウント。
- 第2段階：巨大ボスを**第2段階R12終了まで**に撃破すれば勝利。R13開始時の「最終殲滅砲」は回避・防御・再出撃不可で敗北確定。
- 第2段階開始時のHP/EN/状態異常リセット、再出撃待機等の詳細は**未確定**。実装都合で決めない。
- プレイヤー直接操作3機＋友軍AI2機、**最大5機で攻撃可能**。友軍AIの攻撃もボス耐久設計に含める。

## 2. 巨大ボスの本体・行動

| 項目 | Hardest | Inferno |
|---|---:|---:|
| 想定自軍コアLv | 61 | 81 |
| 巨大ボスHP | **5,000** | **7,000** |
| 巨大ボスDEF | **65** | **70** |
| 巨大ボスSPD（第1行動） | 110 | 130 |
| 第2行動SPD | 55 | 65 |
| MOV | 2 | 2 |
| 占有マス | 2×2 | 2×2 |
| 行動 | 1Rに2回 | 1Rに2回 |
| 第2段階制限 | 12R | 12R |

- SPDおよびSPD/2で**通常のSPD行動順にそれぞれ挿入**し、同速時は既存の同速処理を適用。
- ボスは移動するが、**マップ端へ行かず中央付近の制限領域内**に留まる。移動可能領域の正確な座標は未確定。
- 同一ラウンドに**異なる特殊行動を最大2種類**使用可能。**同じ特殊行動を2回使わない**。Hardestは単発・連携を混合、Infernoは連携を優先。
- 「エネルギー全解放」使用後、同ラウンドの残り行動があれば**通常攻撃のみ**（特殊行動不可）。従って「衝撃波→全解放」は可能でも「全解放→衝撃波」は不可。
- 特殊行動の再使用間隔は下表。異なる種類の危険地形・効果は重複可能。同種の重複時の延長/更新ルールは未確定。

- ダメージ方式の検証用割当案：燃焼爆撃弾＝着弾は通常式・燃焼は固定、レーザー＝DEF一部無視、重力＝ダメージなし、衝撃波＝通常式＋追突、掃射＝DEF一部無視、全解放＝固定、最終砲＝即敗北。

## 4. 巨大ボス専用：4マス独立当たり判定（正式採用）

- 巨大ボスの2×2占有マス**A/B/C/Dそれぞれに当たり判定**を置く。ただしHPは1つで共有し、各マスに別HPを持たせない。
- 通常の単体攻撃は1マスへの1ヒット。**範囲攻撃は命中範囲に含まれた各マスで独立してダメージ算出し、合計をボス共有HPから減算**する。
- 拡散射撃（射撃＋射撃の武装コンボ）は、中心を含む3×3の範囲に2×2全体が入れば**4マスすべてに各70%ダメージ**。既存の武装コンボEN50、通常攻撃固有追加効果なし、射程・射線等の条件は維持。
- **デルタ連携は巨大ボスの異なる3マスを選択して3発すべて命中可能**。既存の通常敵への「異なる敵1〜3体」選択制約に対する巨大ボス専用例外。既存のデルタ連携のダメージ倍率（各50%）、EN、L字配置、1R1回制限は維持。
- 通常爆撃、薙ぎ払い、ライン連携、挟撃、その他の範囲攻撃は、**実際に攻撃範囲に入ったボス占有マスのみ**判定。既存の範囲、中心/周辺倍率、対象上限などのルールを無断で拡張せず、巨大ボスに関する対象選択の必要な例外を実装時に整理する。
- 同じ攻撃・同じ占有マスの意図しない二重計上は防止。技自体が正規の多段攻撃なら各段を処理。
- ボスのDEFは4マス共通。**弱点照準によるDEF低下もボス全体へ共通適用**。
- 状態異常の4重付与は未確定。暫定的には「状態異常はボス本体に1回」の設計案として扱い、正式採用前に確認。
- 既存の通常敵、施設、プレイヤーへの範囲攻撃の仕様は変更しない。

## 5. 弱点照準装置：採用した検証数値

既存の弱点照準装置は「常時DEF無視」ではなく、**射程5・通常攻撃と同じ射線の敵1体を対象に、EN10＋1行動を使い、一時的にDEFを下げる能動効果**。次の発動者自身の手番開始まで有効。重複同種は上書き。

```text
weakpointReduction = floor(0.25 * D + 0.30 * max(0, D - 60))
effectiveDef = max(10, D - weakpointReduction - otherApplicableDefReductions)
```

| | Hardest | Inferno |
|---|---:|---:|
| ボスDEF | 65 | 70 |
| 弱点照準DEF低下 | 17 | 20 |
| 弱点照準後のDEF | **48** | **50** |

- ボスの4占有マスすべてに低下後DEFを適用。1行動の準備コストがあるため、その後の集中攻撃・範囲攻撃との連携が有効。
- ATK＋武器威力500での**参考試算**（既存基本式の整数切捨て、倍率を各マスへ適用）：

| 攻撃 | Hardest | Inferno |
|---|---:|---:|
| 通常攻撃 | 76 | 71 |
| 弱点照準後の通常攻撃 | 104 | 100 |
| 拡散射撃4マス（弱点照準なし） | 212 | 196 |
| 拡散射撃4マス（弱点照準あり） | **288** | **280** |
| デルタ連携3マス（弱点照準あり） | **156** | **150** |

- これらは攻撃力500を仮定した比較であり、Lv61/81の実装済み装備構成から求めた実測値ではない。
- **二次式系追加ダメージパーツ＋弱点照準**を有力攻略候補として検討する。二次式パーツの最新版係数、発動条件、4マス各命中ごとか合計後1回かの処理は未確認のため、勝手に確定しない。

## 6. 耐久・火力の検証基準

- 狙いは「**5機の通常攻撃だけでは原則12Rで撃破困難**、武装コンボ・連携技・追加パーツの運用で撃破可能」。HardestでATK＋武器威力600超は通常想定しない。
- 5機×12R＝60回は**上限**。実戦では移動、射程、敵の攻撃、再出撃、EN、AI判断により攻撃成立率が下がる。
- 例：全機のATK＋武器威力500、攻撃成立率70%の場合、通常攻撃のみはHardest 3,192（HPの63.8%）、Inferno 2,982（42.6%）。
- 4マス拡散射撃は通常攻撃換算約2.8倍、3マスデルタ連携は約1.5倍（いずれも倍率/切捨てによる誤差あり）。
- HP5,000/7,000、DEF65/70を**採用基準値**として維持。強力技を含む実際のLv61/81装備と5機AIの検証は今後実施。仮定の12R総火力を実戦シミュレーション済みと扱わない。
