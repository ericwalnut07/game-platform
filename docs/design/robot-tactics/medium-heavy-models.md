# 中量・重量敵のモデルA/B/Cと武器構成（2026-10-29正式採用）

**中量機4系統×3＝12モデル、重量機3系統×3＝9モデル、合計21モデルをユーザー正式採用。**各機体には既存の武器IDを重複なく2種類装備させる。モデルは装備の組合せで区別し、独自のHP・ATK・DEF・SPD倍率や新しい特殊行動を追加しない。機体の基準ステータスと敵コアLvは既存仕様を維持。詳細な機械可読の正本は[medium-heavy-models.json](medium-heavy-models.json)。

## モデルと難易度の考え方

- A：基本装備、B：射程・追加効果等を強化、C：強力な武器を併用する上位型。武器固有の射程制限、移動/速度低下、EN消費、自傷などは維持する。
- EasyはA、Normal序盤はA中心、Normal中盤以降はA/B、Hard M01〜M07はB中心、Hard M08以降はB/C。Hard M08以降にCが必ず出るという意味ではない。**軽量小隊のHard M01〜M07全Bルールとは別**。
- プレイヤー側で未解放の武器も、敵モデルで使用できる。既存のパーツ報酬・クリア条件は変えない。
- **2026-10-29正式採用**：中量／重量の2武器は軽量機と同じ8段階（敵コアLv1-5→武器Lv1、6-10→2、11-15→3、16-20→4、21-25→5、26-30→6、31-35→7、36-41→8）。武器数値は既存Lv1/5/8/10チェックポイント間を線形補間。成長7系統の正式数値は[成長資料](medium-heavy-growth-2026-10-29.md)を参照。
- 指揮機ボス（M02）は独立設計で、モデルA/B/Cに割り当てない。武器や固有技は引き続き未確定。

## 残す検証課題

採用済みの武器Lvと敵コアLvの関係および攻撃/防御/ENのレベル補間を実装へ反映する際の正確性、実際の被ダメージと戦闘バランス、重い武器のMOVペナルティ重複、砲撃CのEN消費、狙撃武器の最低射程、諸刃の剣の自傷などを既存ルールに照らして検証する。**重量砲撃Cの重爆ミサイル砲＋超重レールガンは両方MOV低下を持つ**ため、MOV下限1と重複規則を確認する。数値と勝率は今回決めていない。
