## Phase 1の計算と互換性

- フレーム別のLv21→41差分を20で割った値を1レベル当たりの基準にする。Lv42〜61は75%、Lv62〜81は50%、Lv82〜100は25%。ENは全区間25%。Lv41値から累積して最後に1回だけ四捨五入する。MOVはLv41の値を維持する。#152に残る丸め未定の記述には、後続で採用された最終丸めを適用する。
- CAP上限はLv70=445、Lv81=500、Lv100=595。Lv70で装備Lv17、Lv81で装備Lv19は#162・#165の比較条件として用いる。コアLvに応じた装備制限は追加しない。
- 既存46品目はLv10から#162の個別Lv20表まで補間する。榴弾砲のLv20 CAPは#162本文の式で62、個別表では63となるため、実装は個別表の63を採用する。既存武器の装備補正・射程を維持し、超重レールガンの通常攻撃ENはLv11以降もLv10の30を使う。
- セーブ形式とバージョンを維持し、既存のEXP・所有・強化・戦闘を読み込む。強化費用は既存表の範囲で利用できる。上限までの能力値は性能チェックで試算できる。


## Phase 2の戦闘処理

- Hardest系の新武器6種を戦闘Coreと戦闘画面に接続する。プラズマブレードは既存の3回燃焼を再利用し、通常攻撃・薙ぎ払い・特攻で付与する。リニアスナイパーは通常移動・追加移動の両方をしていない場合に通常攻撃でDEF15%無視を適用する。
- インパクトブレイカー、フェイズランス、パルスアサルト、クラスターキャノンの固有攻撃は既存の攻撃確定処理で消費ENとダメージを1行動にまとめる。クラスターは中心を選び、周辺は最大2対象。パルスは第1撃で撃破した場合に第2撃を省く。
- プラズマの燃焼量には既存の付与者コアLvベースの式を適用する。コアLvを持たない小型機・通常敵への燃焼の強さ、新武器用の敵特殊AIは後続工程で照合する。性能チェックは固有効果を含む攻撃試算を引き続き準備中と表示する。
- Inferno系の新武器6種、追加パーツの戦闘効果、報酬付与は後続。新装備はHardest初回報酬が接続されるまで所持品に追加されない。

### Inferno系6武器

- オーバードライブは初撃で撃破できるときに、射程内の別対象を任意で1体選べる。1行動に追撃を1回だけ含める。デュアルバーストは撃破まで最大3発。エーテルレールはEN30・140%とEN50・170%を別コマンドで選ぶ。
- フォートレスメイスの守勢反撃は防御・シールド・有効なペア防御または防護陣を確認し、射程と射線が成立する場合にEN10で発動する。既存の反応攻撃と別に1ラウンド1回を記録する。
- アクセルランサーは通常移動前の座標を戦闘チェックポイントに保存する。ヒット＆アウェイを選択すると攻撃と帰還を1行動で確定する。普通の通常攻撃では帰還しない。
- メテオバスターは最大ENの半分を切り上げて消費し、対象ごとのDEFでK20の独立基礎ダメージを計算する。中心70%、周辺最大2対象に40%。追加パーツによる独立二次式加算は追加パーツの実装で接続する。
- 報酬付与と追加パーツの効果は後続。性能チェックでの固有効果込みの試算は準備中。

### Phase 2 追加パーツの実装

PR #167 の報酬表と後発仕様、PR #152 の既存仕様を照合し、高効率戦闘回収回路（M02）、重装固定防御機構（M04）、不屈の装甲（M06）、高精度弱点追撃回路（M08）を接続した。獲得ミッションは装備カタログに記録し、初回クリア時の付与はHardestの進行・報酬実装時に接続する。

- 高効率戦闘回収回路の最大EN4%は、既存の割合EN回復と同様に小数点以下を切り捨てる。実ダメージのある自手番の攻撃バッチに1回適用し、旧戦闘回収回路の発動条件を維持する。
- 重装固定防御機構は、既存の移動・手番記録で効果期間を判定する。固定防御機構との併用では軽減率を加算する。
- 高精度弱点追撃回路は敵機ごとに攻撃前HPを参照する。単体通常攻撃の旧回路とは加算する。

追加パーツの第2段階では、緊急修復ユニット（M10）、高速再照準ユニット（M15）、防御反撃補助装置（M21）を接続した。機動型・防御型の装備制限は既存武器と同じフレームグループで判定する。緊急修復は戦闘中1回の使用を保存し、HP回復量の端数は既存のHP回復に合わせて切り捨てる。複数ヒットの同時解決では攻撃バッチのHP減少後に一度判定する。防御反撃補助はフォートレスメイスの守勢反撃だけを強化する。

戦術適応ユニット（Hardest M12、CAP25）は、実際に受けた武器系統を次の自手番開始まで記録する。同系統の2発目以降を20%軽減し、1回の連射にも適用する。連携や拡散射撃は使用武器の系統で判定する。複数系統の記録はそれぞれ保持し、燃焼など武器系統を持たない継続ダメージは対象外。記録のない旧セーブは未適応として読み込む。初回クリアでの付与は進行・報酬の工程で接続する。

戦術指揮モジュール（Hardest M18、CAP40）は、生存して盤面にいる装備機から距離2マス以内にいる他の味方の通常攻撃系にダメージ補正+10%を付与する。距離は武器射程と同じ斜め1マスの距離を使用する。装備機が複数いても、範囲内に1機以上いる場合の補正は一律+10%として扱う。単体通常攻撃、薙ぎ払い、通常爆撃はユニット・施設とも対象。初回クリアでの付与は進行・報酬の工程で接続する。

過充填コンデンサ（Hardest M14、炉心型専用、CAP40）は攻撃開始時のENが最大ENの60%以上なら、固定消費の攻撃の合計コストを20%軽減する。軽減量の端数は切り捨てる。最大EN割合消費、回復・防御・移動および迎撃態勢の準備は通常コスト。報酬の付与はHardest進行・報酬工程で接続する。

反応装甲（M16）、防護共有装置（M17）、高速回避スラスター（M23）を戦闘に接続。隣接は斜めを含め、複数の防護共有装置の範囲が重なる場合は軽減を1回適用する。高速回避は通常・追加移動の実際の経路を数え、強制移動・位置交換は加算しない。反応装甲と高速回避の使用状態は戦闘セーブに保持する。初回クリアでの付与はHardest進行・報酬の工程で接続する。

突撃姿勢制御装置（Hardest M19、攻撃型、CAP35）と弱点解析ユニット（Hardest M27、CAP40）を戦闘に接続。突撃姿勢は自手番の通常・追加移動の経路を数え、2マス到達後に斬撃・打撃・刺突の通常ダメージ成分を15%増やす。特殊攻撃、武装コンボ、攻撃系連携でも各攻撃の武器系統で判定する。弱点解析は直前の攻撃行動で命中した敵機を記録し、今回も命中する敵機ごとに通常ダメージ成分を10%増やす。多段攻撃では行動開始時の履歴を参照し、攻撃行動の終了時に更新する。二次式ダメージは両パーツの増幅対象外。記録は戦闘セーブに保持し、初回クリア時の付与はHardest進行・報酬の工程で接続する。
