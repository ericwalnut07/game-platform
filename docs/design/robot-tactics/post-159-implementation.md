## Phase 1の計算と互換性

- フレーム別のLv21→41差分を20で割った値を1レベル当たりの基準にする。Lv42〜61は75%、Lv62〜81は50%、Lv82〜100は25%。ENは全区間25%。Lv41値から累積して最後に1回だけ四捨五入する。MOVはLv41の値を維持する。#152に残る丸め未定の記述には、後続で採用された最終丸めを適用する。
- CAP上限はLv70=445、Lv81=500、Lv100=595。Lv70で装備Lv17、Lv81で装備Lv19は#162・#165の比較条件として用いる。コアLvに応じた装備制限は追加しない。
- 既存46品目はLv10から#162の個別Lv20表まで補間する。榴弾砲のLv20 CAPは#162本文の式で62、個別表では63となるため、実装は個別表の63を採用する。既存武器の装備補正・射程を維持し、超重レールガンの通常攻撃ENはLv11以降もLv10の30を使う。
- セーブ形式とバージョンを維持し、既存のEXP・所有・強化・戦闘を読み込む。強化費用は既存表の範囲で利用できる。上限までの能力値は性能チェックで試算できる。


## Phase 2の戦闘処理

- Hardest系の新武器6種を戦闘Coreと戦闘画面に接続する。プラズマブレードは既存の3回燃焼を再利用し、通常攻撃・薙ぎ払い・特攻で付与する。リニアスナイパーは通常移動・追加移動の両方をしていない場合に通常攻撃でDEF15%無視を適用する。
- インパクトブレイカー、フェイズランス、パルスアサルト、クラスターキャノンの固有攻撃は既存の攻撃確定処理で消費ENとダメージを1行動にまとめる。クラスターは中心を選び、周辺は最大2対象。パルスは第1撃で撃破した場合に第2撃を省く。
- プラズマの燃焼量には既存の付与者コアLvベースの式を適用する。コアLvを持たない小型機・通常敵への燃焼の強さ、新武器用の敵特殊AIは後続工程で照合する。性能チェックは固有効果を含む攻撃試算を引き続き準備中と表示する。
- Inferno系の新武器6種、追加パーツの戦闘効果、報酬付与は後続。新装備はHardest初回報酬が接続されるまで所持品に追加されない。

### Inferno系6武器

- オーバードライブは初撃で撃破できるときに、射程内の別対象を任意で1体選べる。1行動に追撃を1回だけ含める。デュアルバーストは撃破まで最大3発。エーテルレールはEN30・140%とEN50・170%を別コマンドで選ぶ。
- フォートレスメイスの守勢反撃は防御・シールド・有効なペア防御または防護陣を確認し、射程と射線が成立する場合にEN10で発動する。既存の反応攻撃と別に1ラウンド1回を記録する。
- アクセルランサーは通常移動前の座標を戦闘チェックポイントに保存する。ヒット＆アウェイを選択すると攻撃と帰還を1行動で確定する。普通の通常攻撃では帰還しない。
- メテオバスターは最大ENの半分を切り上げて消費し、対象ごとのDEFでK20の独立基礎ダメージを計算する。中心70%、周辺最大2対象に40%。追加パーツによる独立二次式加算は追加パーツの実装で接続する。
- 報酬付与と追加パーツの効果は後続。性能チェックでの固有効果込みの試算は準備中。

### Phase 2 追加パーツの実装

PR #167 の報酬表と後発仕様、PR #152 の既存仕様を照合し、高効率戦闘回収回路（M02）、重装固定防御機構（M04）、不屈の装甲（M06）、高精度弱点追撃回路（M08）を接続した。獲得ミッションは装備カタログに記録し、初回クリア時の付与はHardestの進行・報酬実装時に接続する。

- 高効率戦闘回収回路の最大EN4%は、既存の割合EN回復と同様に小数点以下を切り捨てる。実ダメージのある自手番の攻撃バッチに1回適用し、旧戦闘回収回路の発動条件を維持する。
- 重装固定防御機構は、既存の移動・手番記録で効果期間を判定する。固定防御機構との併用では軽減率を加算する。
- 高精度弱点追撃回路は敵機ごとに攻撃前HPを参照する。単体通常攻撃の旧回路とは加算する。

追加パーツの第2段階では、緊急修復ユニット（M10）、高速再照準ユニット（M15）、防御反撃補助装置（M21）を接続した。機動型・防御型の装備制限は既存武器と同じフレームグループで判定する。緊急修復は戦闘中1回の使用を保存し、HP回復量の端数は既存のHP回復に合わせて切り捨てる。複数ヒットの同時解決では攻撃バッチのHP減少後に一度判定する。防御反撃補助はフォートレスメイスの守勢反撃だけを強化する。

戦術適応ユニット（Hardest M12、CAP25）は、実際に受けた武器系統を次の自手番開始まで記録する。同系統の2発目以降を20%軽減し、1回の連射にも適用する。連携や拡散射撃は使用武器の系統で判定する。複数系統の記録はそれぞれ保持し、燃焼など武器系統を持たない継続ダメージは対象外。記録のない旧セーブは未適応として読み込む。初回クリアでの付与は進行・報酬の工程で接続する。

戦術指揮モジュール（Hardest M18、CAP40）は、生存して盤面にいる装備機から距離2マス以内にいる他の味方の通常攻撃系にダメージ補正+10%を付与する。距離は武器射程と同じ斜め1マスの距離を使用する。装備機が複数いても、範囲内に1機以上いる場合の補正は一律+10%として扱う。単体通常攻撃、薙ぎ払い、通常爆撃はユニット・施設とも対象。初回クリアでの付与は進行・報酬の工程で接続する。

過充填コンデンサ（Hardest M14、炉心型専用、CAP40）は攻撃開始時のENが最大ENの60%以上なら、固定消費の攻撃の合計コストを20%軽減する。軽減量の端数は切り捨てる。最大EN割合消費、回復・防御・移動および迎撃態勢の準備は通常コスト。報酬の付与はHardest進行・報酬工程で接続する。

反応装甲（M16）、防護共有装置（M17）、高速回避スラスター（M23）を戦闘に接続。隣接は斜めを含め、複数の防護共有装置の範囲が重なる場合は軽減を1回適用する。高速回避は通常・追加移動の実際の経路を数え、強制移動・位置交換は加算しない。反応装甲と高速回避の使用状態は戦闘セーブに保持する。初回クリアでの付与はHardest進行・報酬の工程で接続する。

突撃姿勢制御装置（Hardest M19、攻撃型、CAP35）と弱点解析ユニット（Hardest M27、CAP40）を戦闘に接続。突撃姿勢は自手番の通常・追加移動の経路を数え、2マス到達後に斬撃・打撃・刺突の通常ダメージ成分を15%増やす。特殊攻撃、武装コンボ、攻撃系連携でも各攻撃の武器系統で判定する。弱点解析は直前の攻撃行動で命中した敵機を記録し、今回も命中する敵機ごとに通常ダメージ成分を10%増やす。多段攻撃では行動開始時の履歴を参照し、攻撃行動の終了時に更新する。二次式ダメージは両パーツの増幅対象外。記録は戦闘セーブに保持し、初回クリア時の付与はHardest進行・報酬の工程で接続する。

慣性衝撃ユニット（Hardest M28、K6・CAP65）と闘気増幅ユニット（M29、K2・CAP65）を戦闘に接続。使用武器と対象ごとの有効DEFを参照し、武装コンボ・攻撃系連携では採用済みの配分を適用する。武器固有の同一対象連射では二次式を初撃にまとめ、オーバードライブの撃破追撃には再適用しない。メテオの中心70%・周辺40%を二次式ごとに適用する。二次式ごとに基礎値と配分後の値を切り捨て、通常ダメージ増幅から独立させる。既存の被ダメージ軽減を追加分にも適用する。初回報酬の付与と性能比較画面での試算は後続工程。

被弾蓄積リアクター（Hardest M22、防御型、CAP60）は、防御・シールド・有効なペア防御／防護陣の適用中に敵機の攻撃で失ったHPを共有上限150まで発生順に記録する。次の自手番開始に相手ごとに蓄積量の150%（切り捨て）でEN消費なしの反撃を行う。盤外・撃破済みの相手への蓄積はその時点で消費する。既存の被ダメージ軽減を反撃にも適用する。蓄積中のセーブを再開できる。

炉心全解放ユニット（Hardest M30、CAP75）の特殊攻撃は装備武器を選び、武器の射程・射線で単体を指定する。基礎値は現在EN全量を使用するK25の二次式。選んだ武器の威力は闘気増幅を併用する場合だけ参照する。EN0では発動不可とし、武器固有の命中効果や自傷は追加しない。両パーツの初回報酬付与はHardestの進行・報酬工程で接続する。

追撃制御ユニット（Hardest M13、攻撃型、CAP50）を戦闘に接続。適用範囲は先行仕様の通常攻撃系を引き継ぎ、威力は後発仕様の70%を適用する。通常攻撃系が敵機を直接撃破した時、その撃破打の補正前ダメージを使い、攻撃した位置から武器の射程・射線内にいる別の敵機のうち最も近い1機へ自動追撃する。同距離は戦闘内の機体順を使用する。被追撃機のダメージ軽減は適用する。追加の行動・EN消費および追撃からの連鎖はなく、追撃まで同じ戦闘セーブに記録する。これで新追加パーツ20種が登録済みとなり、初回報酬の付与はHardestの進行・報酬工程で接続する。

## Phase 3：Hardの一般敵機武器更新

PR #163・#164の採用表をHard M08〜M30の新規出撃に接続した。初期配置と増援で共通の置換を適用し、既存の武器Lvと敵機の基礎成長値を使う。中量射撃Aは主武器を腐食ライフル（射程1〜3）に更新し、副武器のライトピストル（射程1〜2）は維持する。射撃系統と近距離の副武器という役割を保ち、腐食ライフルの重複を避ける。小型機はEN0で、通常攻撃の候補・固有効果は既存の武器ルールを参照する。進行中の旧戦闘は、再開後の増援まで旧装備を使う。更新後に開始した戦闘は、適用済みであることをセーブに記録する。

Hard M12の実戦スモークでは、精密ライフルで前線狙撃機を処理し、榴弾砲で輸送車を狙う小隊を抑えてR10に到達できることを確認した。

## Phase 4：裏難易度の一般敵機の成長・武器Lv

PR #161の成長率とPR #163の武器Lv帯を実装。Hard M29の参照コアLv40で同型の機体基礎値を取り、Hardest M01からM30まで複利成長させる。Inferno M01には丸め前のHardest M30を引き継ぎ、難易度・ミッションに対応する最終値を四捨五入する。武器の能力補正は選択された武器の該当Lvから一度適用し、武器威力は共通カタログの値を使う。中量機HPはPR #160に保存された採用済みLv別チェックポイントを既存補間式でLv40へ補間し、裏難易度の起点に使う。既存難易度・既存セーブに影響する中量機HPの差し替えは行わない。小型機はEN0を維持し、ボスはこの計算の対象外。

この関数はミッション側から個別モデルと武器IDを受け取る。33モデルの装備割当、NPCのEN消費特殊攻撃、裏ミッションからの呼び出しは後続工程。

### Phase 4：一般敵の武器割当とNPC特殊攻撃

PR #163の33モデルをHard M29のモデルと照合し、同じ武器系統を維持する割当を実装した。中量射撃AはパルスアサルトとEMPカービンを装備し、連射の火力とEN妨害を使い分ける。重量強襲Cはプラズマブレード、重量砲撃Cはリニアスナイパーを装備する。小型機はEN0で通常攻撃を行い、プラズマブレードの燃焼などEN不要の効果は共通処理を使う。燃焼のレベル参照は成長基準のコアLv40を使用する。

中量・重量機の衝撃打撃・位相貫通・パルス二連射・クラスター爆撃は既存の射程、射線、対象選択、EN消費、ダメージ処理を共有する。AIは移動候補と移動後の両方で、実効ダメージ・撃破・目標優先度・新規の移動低下を評価し、通常攻撃と同点なら通常攻撃を優先する。一般敵生成関数は新規ミッションの初期配置と増援で利用可能。裏ミッションからの呼び出し、ボス固有仕様と解禁・報酬は後続工程。

## Phase 5 裏ミッションの編成・解禁条件・装備報酬データ

PR #160のラウンド上限、M07・14・21の中量3機への増援置換、M23・25・27・29の重量追加枠、M30第1段階の20機構成を取り込んだ。M01〜29のマップと目標・既存の増援トリガーはHardを参照する。追加枠は初期配置で、通常枠は中量機動B、重量枠は指定系統のB。追加位置は既存敵の前線側から、壁・味方配置・復帰地点・増援候補・目標マス・輸送経路を除外して選ぶ。M30では既存の軽量4小隊と登場タイミングを利用し、中量4機と重量3機を初期配置に加える。これらのモデル・位置は接続後の試遊で確認するための配置であり、設計上の確定座標ではない。通常ボスは暫定的にHardの個別データから生成する。

PR #167からHardestの初回装備報酬42種を登録し、通常3難易度の全90クリアを判定する関数を追加した。現段階はカタログ・敵生成・装備表まで。出撃画面、勝敗とセーブ、装備の実付与、M30の全難易度の勝利条件と巨大ボス、原表未照合のEXPは別途接続する。

### Phase 5 M01〜M29 戦闘ランタイム

Hardest／Infernoの敵配置と武器を通常の戦闘処理で生成する内部出撃 API を追加した。地形・通常ボス・施設性能にはHardの個別設定を参照し、裏難易度の指定と敵編成は戦闘チェックポイントで検証する。裏難易度の上限Rをラウンド終了・勝敗・戦闘HUDで共有し、防衛目標の生存判定も裏の終了Rを使用する。M07・14・21の増援3機は同時に出現し、それぞれ独立した手番を持つ。裏M21・24では設計表の取得イベントに従い、データ取得の翌Rに増援を試みる。

通常の出撃とセーブは既存経路を使う。裏の通常ミッションでの副目標報酬は無効とした。ホームからの裏出撃、進行・実報酬付与、M30の勝敗と巨大ボスは別工程。EXPは採用表照合後に接続する。

### Phase 5 裏ミッション選択・セーブ・初回装備報酬

Easy／Normal／Hardの全90クリア後、ホームに「ミッション選択（裏）」を表示する。Hardest／InfernoのM01〜M29は順不同で出撃できる。M30は両難易度の一覧に表示し、専用の進行とボスを実装するまで出撃を保留する。

セーブv2の裏クリア履歴と戦闘の裏難易度指定は省略可能な項目とした。通常のクリア・副目標履歴を分けて維持し、編成・装備Lv・EXPは共有する。Hardestの初回装備報酬は勝利と同じ保存処理で付与し、新規の武器・基本パーツはLv1で共有装備に加える。Infernoおよび周回は装備の重複付与がない。裏の副目標は表示・加算せず、未照合のクリアEXPは表示で準備中と示す。

### Phase 6 M30第1段階の殲滅戦

PR #160の追補を参照し、全5難易度に共通の固定配置とR4・R7・R10開始時の増援を内部戦闘ランタイムに追加した。R16までに初期10機と増援10機を撃破すると第1段階が終了する。施設やデータ取得・送信を勝敗に使わない。正確な増援代替位置は未採用のため、指定先が空くまで該当する小隊または機体の出現を繰り延べる。中量・重量のモデル記号は設計で指定されていないため、先行カタログで使用したBを適用する。指揮機と通常3難易度の敵参照Lvには既存の個別設定を適用する。

新しい戦闘チェックポイントは第1段階の種別と増援の出現記録を検証する。現行の出撃画面は既存M30チェックポイントを引き続き再開できる。新シナリオの出撃と報酬確定は第2段階の巨大ボスおよびラウンド移行と合わせて接続する。

### Phase 6 M30の第2段階への移行

Hardest／Infernoの第1段階勝利を同じ戦闘の継続として処理する。着地時に7枚の壁を除去し、操作機3機・友軍2機を出撃時の配置と最大HP・ENへ戻す。戦闘中の状態効果・再出撃待機を解除し、装備・コアLvは引き継ぐ。第2段階は独立したR1から開始する。戦闘中セーブは移行後をそのまま再開でき、着地時にはリザルトや装備報酬を確定しない。

巨大ボスは1機分のHPと2×2の占有範囲を持つ。2つの手番を各難易度のSPD 110／55または130／65で行動順へ登録した。移動の合法判定はG5〜M10の基準マスと経路上の4マスを確認する。第2段階のHUDでは現在Rのみを表示し、R12の終了まで未撃破の場合はR13開始時に最終殲滅砲で敗北する。現段階は内部ランタイムと画面表示まで。特殊攻撃、4マス独立の命中処理、出撃画面への接続は後続。

### Phase 6 M30の占有マス別ダメージと攻撃予告

巨大ボスの4マスを攻撃座標として選択できる。通常攻撃は1マス、拡散射撃は3×3に含まれる各マスへ70%、デルタ連携は選んだ最大3マスに50%を適用し、すべて本体の共有HPで精算する。爆撃・薙ぎ払い・ライン連携・挟撃連携は既存の範囲、対象上限、射線と配置条件を使う。弱点照準は選んだマスから発動し、DEF低下を本体に共有する。強制移動も2×2全体の合法性を確認する。

戦場分断レーザーと燃焼爆撃弾の予告を保存し、次Rの機体行動前に固定範囲へ発動する。レーザー、爆撃着弾、燃焼地形の順に解決する。燃焼地形の重複ダメージは1回とし、着弾ラウンドを継続期間の初回として数える。対象の同点は再開しても再現できるよう、出撃IDとラウンドを使って決める。重力拘束、巨体衝撃波、地表掃射、全解放、各特殊攻撃の組み合わせと出撃画面への接続は後続。

### Phase 6 M30巨大ボスの残る固有技

重力拘束・衝撃波・地表掃射・全解放を接続した。拘束は発動時に範囲内の機体へ付与し、発動Rを含む2R（Infernoは3R）、通常移動をMOV0まで下げる。衝撃波は最寄りの占有マスから押し出し、衝突した機体には別途固定ダメージを適用する。掃射は盤面中央の縦横候補から命中見込みが最も多い向きを選び、予告の翌Rから2マスずつ進む3回の判定を保存する。同点は候補列挙順で決める。全解放は最寄りの占有マスから半径5とし、発動から次R終了まで本体DEF−20を適用する。既存と同じ斜め1マスの距離を用いる。配置・継続効果に応じた技の組み合わせを考慮し、Infernoは組み合わせをより優先する。

全解放と同Rの残り手番では固有技を選べない。巨大ボスの通常攻撃については正本に個別の基礎威力・射程を確認できなかったため、その手番は待機にしている。出撃画面への接続は後続。クラスターキャノンとメテオバスターは巨大ボスの各マスを中心・周辺に指定でき、従来の周辺2マスまでの上限を維持する。
