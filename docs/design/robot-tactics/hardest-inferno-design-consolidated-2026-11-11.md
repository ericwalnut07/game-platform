## 1. コア育成（**採用済み・重要**）

- コアLv上限 **100**、基本武器・基本パーツLv上限 **20**。
- **段階的成長率を採用済み**：Lv1–41は従来どおり100%、**Lv42–61は基準成長量の75%、Lv62–81は50%、Lv82–100は25%**。基準は従来のLv21–41付近の各ステータスの1レベル当たり成長量。Lv41までの既存値は変更しない。
- **重要：Lv42–100一律75%ではない。** 後続チャットで提示された一律75%案は、既存採用方針を上書きしていない。
- **EN成長速度（正式採用）**：コアLv42–100のENは全区間で従来基準成長量の**25%**。他のステータスの75%→50%→25%とは異なり、ENはLv41以降一律25%。Lv1–41のENは既存値を維持。各フレームのLv60/80/100の整数値および端数処理は**未定**。
- HP、近接攻撃、射撃攻撃、DEF、SPDは上記段階的成長を基準とする。MOVは原則固定（Lv41以降の追加成長は**未定／新たな採用なし**）。フレームごとのLv41基準値と丸め、Lv41以降の個別数値表は**未定**。
- CAP = 100 + 5 × (コアLv − 1)。Lv61=400、Lv70=445、Lv81=500、Lv100=595。
- Inferno主対象はコアLv61–81、中心Lv70。Lv100はやり込み用。Hardest/Inferno敵HPは最終的に完成装備で再調整する。

## 2. ダメージ計算・共通装備規則（採用／暫定採用）

- 通常攻撃系：通常攻撃、薙ぎ払い、特攻、ヒット＆アウェイ等、EN0で通常攻撃枠から実行する攻撃。EN消費特殊攻撃・武装コンボ・連携技は含まない。
- 通常基礎ダメージ = floor(10 × (攻撃ステータス + 武器威力) / 対象DEF)。
- 独立二次式追加ダメージ：対象iごとに `Q_i = floor(K × (X/100)^2 / (DEF_i/100))` を計算し、各対象の攻撃倍率r_iを掛けて `floor(Q_i × r_i)` を加算。**複数対象でDEFが違えばそれぞれのDEFで別計算**。攻撃全体の共通プールを分配する方式は廃止。通常ダメージの各種倍率・バフは二次式部分を増幅しない。端数処理は各対象で切り捨て。
- 通常攻撃の複数%バフは加算（+15%と+30%なら+45%）。被ダメージ軽減は加算で最大70%。追加攻撃から追加攻撃を再発動させない。異なるパーツのEN回復は加算し最大ENで停止。
- **同一追加パーツIDは1個のみ**。**異なる追加パーツはCAP内で自由に同時装備可能**。強化版と旧版も同時装備可。類似効果を理由に装備排他を設けない。
- **未定／要整合**：同じ撃破で複数の別ID追撃効果が成立した場合の処理（「1つ選ぶ」という過去提案は自由併用原則と衝突するため未確定）。隣接する複数味方からの同種支援効果の重複も要確認。二次式の軽減処理・同一攻撃内複数二次式の最終丸めも要テスト。

## 9. 2026-11-11 バランス検討での追加確定事項・未定事項

### 正式採用

- **慣性衝撃ユニット：SPD二次式K6、要求CAP65。** 移動条件・対象行動などの既存設計は維持。
- **闘気増幅ユニット：攻撃ステータス二次式K6、要求CAP70。** 武器固有EN特殊を含む対象行動・独立加算原則は維持。
- **炉心全解放ユニット：K25、CAP75を基準として維持。** 全EN消費の重い代償を踏まえ、繰り返し発動できる上記2パーツも高CAPに設定。
- **撃破後の再出撃ではENを通常の初期値（最大ENの30%、既存端数規則に従う）へリセット。** ENが枯渇していた場合は回復メリットもある。再出撃・移動で平均約1.5ターンを要する条件でバランス比較する。
- **Inferno敵の最終HP/DEFは、二次式追加ダメージがある前提で調整する。** 現行の敵HP/DEF一覧は暫定のままであり、現段階で新数値を確定しない。

### 検証中・未定

- Lv70の比較では機動型K6と闘気K8/K6/K4を比較した。闘気K6/CAP70・慣性K6/CAP65の採用により、旧CAP45を用いた装備例は**再構築が必要**。Lv70 CAP445の例では旧攻撃型構成CAP426→451となり成立しない。旧機動型CAP392→412で成立するが、装備枠・Lv20パーツCAP・追加効果の厳密な照合は未実施。

## 10. 防御型専用「被弾蓄積リアクター」（2026-11-11 正式採用）

**既存の追加パーツ20種とは別に追加する防御型専用パーツ。** 既存の追加パーツを削除・置換しない。

| 項目 | 正式仕様 |
|---|---|
| 名称 | 被弾蓄積リアクター |
| 装備制限 | 防御型専用 |
| 要求CAP | 60 |
| 発動条件 | 防御系行動中に敵の攻撃を受ける |
| 蓄積量 | 防御軽減後に実際に失ったHP |
| 蓄積上限 | 100 |
| 反撃ダメージ | floor(蓄積量 × 1.5) |
| 反撃対象 | **その攻撃を行った敵に限定** |
| 反撃射程 | 装備武器の射程に依存しない |
| 発動回数 | 1ラウンドに1回 |
| EN消費 | なし |
| 蓄積の扱い | 反撃成立時に全消費。反撃できない場合は次ラウンドへ持ち越す |
| 撃破・再出撃 | 蓄積量をリセット |

- **フォートレスメイスなしで単独発動する。** 武器種・武器射程に依存しない、リアクター固有の反撃である。敵が防御型を攻撃したときのみ反撃し、別の敵を選んで攻撃できない。
- フォートレスメイス固有の反撃は、**防御系行動中に射程内から攻撃を受けた場合のEN10・60%・1ラウンド1回**という従来の条件を維持する。リアクターとメイスの両方を装備し、それぞれの条件が成立した場合は両方の反撃ダメージを加算する。メイス装備はリアクター発動の必須条件ではない。
- **攻撃行動と防御行動は同時に行えない。** 以前の机上比較で用いた「防御型が毎ターン通常攻撃しつつ毎ターン反撃する」というモデルは無効。防御型は防御・援護・反撃で貢献する。
- 反撃のタイミングは攻撃被弾直後を基本とし、1ラウンドに複数回被弾してもリアクター反撃は1回まで。反撃が成立した時点の蓄積値を消費する。
- **要実装照合**：既存ゲームの防御系行動の厳密な分類、ラウンド境界、同時攻撃・連続攻撃時の蓄積と反撃順、ダメージ軽減後の端数、攻撃者が既に撃破された場合、反撃不可の状況、保存データ互換性。これらはゲーム体験に影響するため実装前に確認する。
- 本節は正式な**ゲームデザイン仕様**であり、ゲーム本体への実装済み宣言ではない。Inferno敵HP250/420/650/1000は引き続き未確定の検証案。
