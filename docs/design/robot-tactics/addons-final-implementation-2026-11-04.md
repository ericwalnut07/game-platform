# 追加パーツ最終確定仕様の実装

2026-11-04採用。先行の戦闘共通仕様と旧EN値が競合する箇所は、[最終決定JSON](addons-final-policy-2026-11-04.json)と[addons.json](addons.json)を優先する。PR #97の戦闘Core・PR #95のVFX・PR #94のM01を再利用する。

## 仕様反映・実装

- 指定41件のEN設定を専用行動/追加/合計に区別して反映。通常行動・武装コンボ・連携本体のEN、回復式、最大EN、成長・報酬・勝敗は変更しない。EN0の効果を資源不足で拒否しない。
- 全60パーツのCAP・獲得条件・武器種・最低レアリティ・装備制限を変更前の固定資料と比較するUnit Testを追加。
- 超特攻・回復・燃焼・迎撃強化・供給・修復・槍撃・震央・近接狙撃・刃渡り・シールド/薙ぎ払い/連携増幅器等、既存の実戦接続はカタログの新ENを使用する。EN0になった通常攻撃は、既存の命中EN回復条件で処理する。
- AIの通常攻撃候補は曲射の追加EN5を含めて判定する。EN不足の候補は除外し、敵・友軍の既存の評価と移動方針を維持する。新しい爆撃専用の配置形成AIは追加しない。
- 性能チェックは接続済み行動へ新費用を適用し、装備中の最終ENと条件付きENを表示する。二点起爆の配置・重複を仮想敵1体の従来試算に代入しない。

## 爆撃3パーツ

| パーツ | 操作・効果 | EN |
| --- | --- | --- |
| 空地点照準器 | 敵中心を維持。空きマス中心も選べる。壁/盤外/味方/施設は不可。中心に射程・射線、空中心は周辺敵を最低1体手動指定。中心にHP攻撃を生成しない | 追加0 |
| 爆風拡張装置 | 周辺を最大4体まで手動選択。武器の直交4/周囲8形状を維持 | 0〜2体は追加0、3〜4体なら行動全体で追加5を1回 |
| 二点起爆制御装置 | ★3爆撃のみ。異なる2中心と各周辺を選択して「決定」。各中心70%/周辺40%。空中心/拡張との併用可 | 合計25、いずれかで拡張枠使用時は30 |

各地点の選択対象を検証した後、敵IDごとに最大係数を選び、1敵1つのHP/命中/撃破イベントへまとめる。中心+周辺は70%を1回、周辺+周辺は40%を1回。同じ地点内の重複IDは拒否。UIも同一の敵を二重に選択表示しない。

基本ダメージの面積係数段階、DEF/割合軽減、最終切捨・最低1は既存Coreを使用。通常単体100%、従来爆撃、拡散射撃は独立コマンド。連携/コンボ/反応へ新しい追加費用を持ち込まない。

二点の選択組合せを全列挙せず、Coreが合法中心と周辺候補を投影する。UIは1/2地点を編集・選び直し・キャンセルでき、確定前の入力は保存/EN/行動/HPを変更しない。費用不足時は決定不可。実行時にCoreが全条件と費用を再検証する。

通常のCASチェックポイント・再送防止を使用し、2地点の全ダメージとENは1操作/1保存。保存失敗時にHP/EN/VFXを公開しない。空中心は表示専用のblast VFX、周辺の機体/HP/選択表示は従来の保護レイヤーを再利用する。旧v1保存の追加フィールド省略は有効。

## 残作業

追加パーツ全体は44実装済み・3一部接続・13未接続。後続の[残り8種類の接続](remaining-addons-implementation-2026-11-04.md)を含む。[全60件の一覧](common-combat-status-2026-11-04.md)を参照。

今回費用だけ確定した未接続パーツは、能動効果まで実装済みと扱わない。遅延起爆信管は後続の[最終確定仕様](delayed-fuse-implementation-2026-11-04.md)でEN10・中心100%・周辺40%と起爆条件を確定し実装済み。設置物・対象・寿命等の未確定事項や先行PRで保留した反応自傷などは仮決定しない。M02〜M07正式接続は次工程。

## 検証

対象の型チェック・Unit・ビルド、PC横画面/スマートフォン横画面のブラウザを実施し、確定件数・コミット・Windows結果をDraft PRへ記録する。

新M01ブラウザ検証は通常のバックアップ読込から明示した獲得済み高Lvテスト進行状態を使用する。敵HP/EN/配置、ランタイム、AIは変更しない。4周辺敵の選択とEN4境界は明示した戦闘fixtureでも確認する。縦画面操作は正式対象外。共通サイト統合・マージ・本番公開は行わない。
