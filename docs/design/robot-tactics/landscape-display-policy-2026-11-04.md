# ターン制タクティクス：横画面の正式対応方針

2026-11-04ユーザー採用。過去の縦画面対応・検証指示より本方針を優先する。対象は独立オフライン版ターン制タクティクスのみ。

| 対象 | 正式対応 | 検証 |
| --- | --- | --- |
| PC | 横長レイアウト | desktop 1280×800 |
| スマートフォン | 横画面・タッチ操作 | mobile 844×390、狭い横画面640×360も操作部品を確認 |
| スマートフォン縦向き | 横向きへの回転案内 | 案内の表示/非表示と保存不変だけを確認。ゲーム操作・表示回帰・画像確認の正式対象に含めない |

- 縦画面用のゲームUIを新規実装・改修しない。既存の横画面UI・入力・演出・ゲームロジックを維持する。
- 縦向き時の案内は表示専用の短い文言で、操作主体・手番・戦闘状態・保存へ影響しない。横向きへ戻すと消える。
- 横画面ではPCとスマートフォンそれぞれのサイズ、タップ領域、HP/機体/選択状態の視認性を検証する。
- 全6種類のrobot用Playwright設定は `tests/robot-tactics/landscapeProjects.ts` の共通対象を使用する。`mobile` は横画面・タッチ端末を意味する。正式M01に旧縦画面プロジェクトを重複実行しない。
- Unit、Core、AI、保存・再開・重複入力など、方向に依存しない検証は維持する。
- 過去の検証記録にある390×844等は履歴として残す。今後の正式報告はPC横画面/スマートフォン横画面だけを画面対応の検証結果とし、縦画面操作の省略を未検証・実装不足に数えない。
- 共通サイト統合・PRマージ・本番デプロイは本変更に含めない。
