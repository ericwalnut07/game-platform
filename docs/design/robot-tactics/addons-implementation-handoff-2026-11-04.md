## 3. 特に必要なCore/Player View/保存・UIの論点

- **連鎖斬撃炉**：任意攻撃の撃破後に追撃可否→追撃対象を選択するサブフェーズを管理。元の攻撃のHP/自傷/撃破/押出・衝突等を確定してから遷移。EN15の一度だけの決済、1手番1回、追撃自身による再発火禁止。追撃に通常射程・特攻の合法踏み込み・射線/遮蔽を適用。セーブ/ロード/再実行で追撃が重複しない。独立の諸刃20%自傷。
- **転送**：交換を1つの原子的な2機位置変更として扱い、通常移動の経路や迎撃条件を通さない。交換後に所有者依存の目的物取得/送信・地形目標の到達を再評価。途中でアイテム所持が移らない。交換可能な生存味方と合法な最終位置を検証。
- **爆炎**：初撃手動選択（武器固有4/8近傍）と残留3×3の別描画・状態管理。敵ID×行動者手番IDで「1手番1回」を管理し、敵手番での進入＋同ラウンド別味方手番の押出が両方通ること。残留ダメージはDEF無視、割合軽減あり。適用結果・残り期間を保存。
- **弱点照準**：射程/射線の合法性、同一対象への再付与と新しい発動者起点期限、異なる敵の複数維持、他DEF弱体化との加算/下限10。基準DEFのスナップショット/再計算の決定性。
- **妨害延長**：新規付与時に延長後期限を決め、同種再付与では古い値を消す。効果を残す優先判定・強さ比較を入れない。
- **既決定の他パーツ**：各設置物・マーク/バフ・後続移動と既存の移動/射線/反応/特殊攻撃/EN決済/友軍AIを接続。旧セーブは未記録項目を安全な初期値で解釈。ゲーム終了・再出撃・中断/再開・ミッション再挑戦で残留状態の扱いを確認する。
- 発動時にプレイヤー専用の選択情報があればUIに表示するが、実際の合法性/HP/ENの正本はCore。演出は既存VFXパックを流用し、機体・HP・マップを隠さない。

## 4. 実装時の優先テスト（ゲーム固有のみ）

1. **連鎖**：通常/特攻/範囲/コンボ/連携の撃破検知、追撃辞退、EN不足、合法射程・踏込先なし、1手番1回、追撃での再連鎖禁止、諸刃主攻撃+追撃の自傷額、行動中断/復帰の再実行防止。
2. **転送**：目的物運搬中の位置交換後も同一IDが保有、到達/取得/送信の成立・不成立、交換で迎撃や移動EN+3が発動しない、味方AI対象、違法対象/距離。
3. **爆炎**：武器別初撃手動2体・広域8近傍と、固定3×3残留の分離。DEF無視/軽減、押出・引寄、同手番二重発動の防止、異なる手番で同ラウンド複数回発動、保存/読込でクールダウン保持。
4. **弱点/延長**：距離5境界・壁射線・角、DEFの参照時点/複数低下の合算、同対象弱点照準上書き、別対象並行、付与者期限、短期強→長期弱の再付与で新しい弱体化へ上書き、延長+1ターン。
5. **既確定差分**：地雷2個重複起爆・内部順位・押出/引寄、デコイを壁として経路探索、5×5各フィールド、標定最初の1hit、対物DEF10〜45%、後続移動2回・各歩の迎撃等、補給期限、セーブ/再戦。
6. PC横画面・スマホ横画面の対象ゲーム操作と、既存M01/既接続特殊技に対する局所的な回帰テスト。型チェック・対象Unit・smokeをルール変更に応じて実行。共通コード/保存互換などの変更でリスクが高ければ検証を拡大。全ゲームverifyや別ゲーム専用E2Eは本件の標準対象外。

### 5.1 最後の3種類の実装着手条件は解消済み

PR #102 の「未接続の感応地雷/進路妨害/残留爆炎」の仕様上の保留要因は、2026-11-04に正式確定した。

- **地雷**：距離2/LOS不要/通行可能な空きマス。設置Rと次Rの終了まで有効。複数地雷・重複感知・MOV−1の期限は従来仕様どおり。
- **進路妨害**：距離3/LOS不要/通行可能な空きマス中心。設置後はそのマスを通行・停止可。5×5敵MOV−1、設置Rと次Rの終了まで有効。
- **爆炎**：中心は通常爆撃の合法な敵占有マス。初撃は通常の手動対象選択。攻撃後に3×3の通行可能マスへ爆炎を置く。生成時の固定10はなし。後の通常/強制侵入・敵手番末にDEF無視固定10（割合軽減あり）。設置Rと次Rの終了まで有効。

**対象テスト**：R3設置・R4最終手番末処理・R5無効、起爆済み地雷の即消滅、LOSを挟む/挟まない合法性、壁/空き/占有中心の拒否・許可、妨害中心通過、爆炎の初撃と最初の残留tickの分離、リロード/中断再開後の期限保存。PR #102の既存機能（54実装済み・3一部接続）の保護。
