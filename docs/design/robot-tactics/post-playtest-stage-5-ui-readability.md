# ターン制タクティクス：第5段階 試遊後UI視認性改善

2026-11-08試遊確認後の正式決定事項。前提はDraft PR #126〜#130の斜め俯瞰・地形・施設・味方右後方画像・VFXを**保持する**こと。ゲームCore・命中/射線・武器/EN・NPC・セーブ形式・勝敗・ミッション配置は不変更。独立・完全オフラインであり、共通サイト統合/本番deployは対象外。

## 段階1：足元の所属マス補正
- 従来の画像足元は論理マス内 `y=0.81`。表示上だけ `y=0.60` に移し、味方・敵・友軍AIおよび未読込時フォールバックに共通適用。
- `BattleUnitDisplay.ts` の表示専用オフセット `-0.21` を `BattleScreen.ts` のスプライト `translate` に適用。
- 右手武器は既存スプライト内の独立レイヤーのまま一緒に移動。機体画像の大きさや足元のピクセル位置、移動先座標、移動アニメーション、壁・射線・タップの正本は変えない。

## 段階2：通常時のマップ表示を整理
- 味方機・敵機・友軍AIの**常時名前/HPバーのみ非表示**。機体画像、行動機の従来枠、攻撃/範囲、状態変化、VFX・ダメージ、施設・目標HUDは残す。
- `focusedUnitId` は`BattleScreen`内に保持する一時的なUI状態であり、CoreやIndexedDBセーブに入れない。
- 左の味方機一覧は、出現中・生存中の操作機と友軍AIの名前/HPを表示。名前タップで該当セルを発光し、上層の非タップ可能HUDに**その1機のフルネームと現在/最大HPバー**を表示。
- 別機体への切替、同一機体の再タップ、マップのタップ/パン、他の操作ボタン、攻撃/移動/特殊/連携の操作で解除。カメラはUIだけ対象マスへ移動し、ゲームの行動対象・ターン・ENを変更しない。
- 対象のHP変更は最新`RobotBattleViewModel.units`から再描画。対象が撃破/消失すれば解除。NPCの見た目だけの移動中はHUDも移動アニメーションに追従する。

## 段階3：生存中の敵機一覧
- 右戦闘操作レールの**下側**に、左一覧と対応する「敵機一覧」を追加。名前・現在/最大HPのみで敵の未公開情報や推定状態は表示しない。
- **A案：現在出現中の生存敵だけ表示**。未出現の増援はUIに渡されていないため非表示、増援出現時に自動追加、撃破時に自動削除。右一覧の長さは内部スクロールで処理。
- 一覧からの位置確認と解除は味方一覧と同じ。攻撃対象の確定には流用しない。左右全ボタンは横画面で44px以上を維持。
- `BattleUnitDisplay.ts` がリスト/対象の生存チェックをPure TypeScriptで提供。ゲームの敵AI/増援ロジック・勝利条件は変更しない。
