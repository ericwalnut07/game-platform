# ターン制タクティクス 第5段階：オブジェクト配置基準の統一（第1段階）

## 実装範囲
- PR #135（半透明壁・深度描画）の先に重ねる表示専用変更。Core・ミッション配置・攻撃/移動/射線・保存データは変更しない。
- 既存施設アトラスのアンテナ、レーダー、端末、タレット、クレート、拠点ビーコンを対象とする。
- M04/M11の2マス補給施設は、各施設の占有セル集合から**単一の描画足元**を算出する。仮のクレートアートを2マス横断で表示し、正式な通常/破壊後画像への差し替えは第2段階に分離する。
- M05/M12の輸送車の新規画像も第2段階。現段階では「輸」文字のフォールバックを維持する。

## 描画の正本
1. 接地点は占有セルの bounding footprint 中点：`((minX+maxX+1)/2, (minY+maxY+1)/2)`。1マス施設・目標マーカー・複数マス施設で同じ式とし、画像最下端をその点に配置。画像上部だけが接地面からはみ出す。
2. 単マス画像は原則幅0.9論理単位、マーカーは幅0.82論理単位でコンパクトに表示。2マスは最大1.52論理単位まで拡張し、元の1マスクレートを暫定的に横長表示する。長身アンテナは例外として高さを確保し、他の施設は低めを維持する。
3. 描画順はPR #135と同じ `x+y` 奥行きソート。複数マス施設の深度は占有セルの最前面（最大 `x+y`）から決定。オブジェクトはグリッドのヒット領域の兄弟ノードで表示し、タップ判定を増やさない。
4. 壁は従来の opacity .56 を維持。通常の施設は不透明で、奥の生存機体が施設スプライトの画面上推定範囲に隠れる場合のみ施設イラストを opacity .62 とする。非実体の目標マーカー・施設HP/名称・機体は透過しない。
5. 全変更はレンダラ内のViewモデルだけに適用し、後方互換の保存フォーマットを維持。
