### 現在のゲームの骨格

- **オフライン1人用**。直接操作する自機3機＋友軍AI2〜3機、複数敵ユニットとの集団戦。
- 自機の独立育成・CAP・フレーム・基本6スロット装備・特殊行動・EN・連携技の既存の基本仕様は継続。**同じ1機に同一武器IDを2枠とも装備することは禁止**（別の自機同士では同じ武器を使用可能）。
- マップ4サイズ（13×11／17×15／21×17／25×21）、操作中は約9×9マスのフォーカス、俯瞰画面をタップした場所へフォーカス移動。通路と壁のみ。壁は双方の射線を遮る。防御補正付きの遮蔽物は導入しない。
- 通常フレームはMOV3→4、機動フレームはMOV4→5、万能フレームはMOV4→5（コアLv21で補正変化）、現行パーツ構成でMOV7が到達可能な数値例。**システム上のMOV上限はなし**。移動タイプの形状は従来の4種を保ち、MOV6は60マス／MOV7は80マスを設計済み。MOV8以降の範囲は未設計であり、実装前に別途確定する。`frames.json`には実際に加算する`movementModifierAtCoreLevel`を新設し、従来の`totalsAtCoreLevel.mov`は旧コアMOV2込みの参照値と明示した。最終MOVはコア3＋フレーム補正＋装備補正。座標案は`current-group-combat.json`参照。
- 敵は**軽量3機小隊・中量級・重量級・ボス級**。軽量小隊は4×4以内の位置関係を維持し、各機が個別移動・個別ターゲット判断、同一小隊手番の攻撃を同時解決。
- 軽量機は近接・射撃・防御・機動の4種、各モデルA/B/Cの計12モデル。武器1種、特殊行動なし。BはNormal以上、Cの登場はHard M08以降のみ（Hard M01〜M07はBのみ）。武器Lv1〜8、敵基準コアLvに合わせた段階成長。軽量機のLv1・5・11・21・31・41ステータス表は現行仕様JSONに保存。**軽量機小隊は通常2×3〜3×3程度でまとまり、必要なら最大4×4の範囲まで広がれる**。
- 中量・重量級は通常の特殊行動を使用可能。ボスは固有特殊行動。敵の判断は**ミッションの妨害目標×機体タイプの性格×現在の戦況**。Easy/Normal/Hardで判断品質を変える。
- 友軍AIは「自由行動／集中攻撃／味方護衛／地点防衛／地点前進」の5指示。指示変更は行動・EN消費なし。自動ON/OFFを持ち、OFFでは友軍AI手番ごとに実行確認。友軍AIはプレイヤー発動の連携技に行動・EN消費なしで参加できる。3種の友軍AI基礎装備・Lv1ステータスも保存済み。
- **自機3機が同一ラウンド内に全機撃破された場合、即時敗北**。異なるラウンドでの撃破は合算しない。友軍AIの撃破はこの判定から除外。
- 自機・友軍AIは撃破Rの次の1ラウンド待機し**R+2開始時に再出撃**（HP100%、EN30%、状態異常解除）。自陣側の縦2×横4または縦2×横5の優先順位付き出撃エリアに、撃破時刻の早い順で配置。同時撃破なら自機1→2→3、友軍AI1→2→3の順で優先。敵は原則再出撃せず、必要なミッションで増援トリガー成立の**次ラウンド開始時**に新部隊が出現。
- M01〜M07は7種類の異なる主要勝利条件と制限ラウンドが確定。初期配置と敵編成・増援は`early-seven-layouts.json`で具体化済み。サブ目標・バランスは今後調整。

### 採用済みの戦闘UI・演出

- 盤面中心に、敵・友軍AIの**移動先／行動名／対象／ダメージ／HP変化／撃破**を表示。ログだけで済ませない。**行動実行前に予定移動先・行動・対象・算定可能な予想ダメージを確認**でき、実ダメージと区別する。
- 通常のAI行動は1機ごとの手動確認で進める方式を基本とする。**友軍AI自動ON時のみ、その手番を自動実行**（OFFでは友軍AI手番ごとに確認）。友軍AIの自動設定を敵AIに勝手に適用しない。
- 軽量機小隊は**共通1手番・3機の攻撃を同時解決**。被弾回数分のフラッシュと、複数ダメージ数字の並列表示。
- 武器系統ごとに区別できる短いエフェクト、表示目安は**約0.6秒**。
- スマホは約9×9のフォーカス表示、自由パン・ズーム・全盤面俯瞰を備え、俯瞰タップ位置を中心にフォーカスへ戻れる。

## 2026-10-27採用の連携技・追加パーツ改訂（2026-10-28追補）

**重要：前回の設計保存には、以下の採用済み更新が反映されていなかったため修正しました。** 詳細は`offline-formation-policy.json`、`rules.json`、`addons.json`を参照してください。

### 連携技の最新版

- **ライン EN40**：発動機の武器で `floor(10*(A1+W1+A2)/DEF)`。旧「1.4倍」を廃止。
- **ペア EN35**：発動機のみ実効DEF=`DEF1+0.75*DEF2`（被ダメ軽減上限60%）。旧「固定30%軽減」を廃止。
- **デルタ EN75**：3機L字、最大3対象に各`floor(10*(A1+W1+A2+A3)*0.5/DEF)`。旧「発動者攻撃の0.7倍」を廃止。
- **挟撃 EN50**：2機が敵を縦または横から挟む。`floor(10*(A1+W1+A2)*1.25/DEF)`。
- **防護陣 EN55**：L字3機にそれぞれ`DEF_i+0.25*(他2機DEF合計)`（軽減上限50%）を発動者次手番まで適用。
- **自軍全体で同一連携技を同じラウンドに1回まで**。支援参加者は行動・EN消費なしで、異なる連携技には同じラウンド中に再参加可能。
- **連携技拡張**を自軍の1機に装備すると挟撃・防護陣を全味方に解放。**友軍AI連携技**パーツがあると、プレイヤーの許可設定に従い友軍AIも連携技を自発発動可能（発動AI自身が行動・ENを消費）。
- 連携増幅器は**軽量 CAP15／中量 CAP30**を維持し、攻撃連携ダメージ＋10%／＋15%、防御連携の実効DEF＋10%／＋15%、追加EN＋5／＋10へ改訂。併用で＋25%、追加EN＋15。

### 追加パーツ改訂

- **友軍AI強化** CAP24：プレイヤー機体3機の装備数×5%、最大15%。全友軍AIのHP・近攻・射攻・DEF・SPD・EN、MOV除外。
- **友軍AI連携技** CAP14：1個の装備でAI発動を解放。許可ON時のみ。
- **継続燃焼弾** CAP24・EN30：着弾に通常攻撃の50%ダメージ、燃焼3回（DEF無視、1回`5+floor((コアLv-1)/3)`）、重複なし再付与で期間更新。爆撃武器は複数敵へ付与。
- **弱点照準装置** CAP26・EN30・1行動：敵1機のDEFを`floor(0.1DEF+0.3max(0,DEF-60))`低下、発動機の次手番開始まで。
- **戦果共有回路** CAP20：味方撃破で装備機を中心とする距離2以内の自機・友軍AIに各EN5回復。
- **進路妨害フィールド** CAP26・EN30・1行動：指定地点中心3×3に2R、敵MOV−1（最低1）、味方影響なし。
- **補給フィールド**：設置地点中心3×3の自機・友軍AIの各手番終了にEN12、2R持続。
- **戦術転送ビーコン**：EN0、1行動、距離3以内の味方と位置交換、使用回数無制限。
- **衝突破砕装置**：壁衝突で固定20、敵機同士の衝突で双方に固定20（押し出し1回につき単発判定）。旧衝撃偏向装置は廃止。
- **削除した旧パーツ**：薙ぎ払い集中機構、牽引ワイヤー、標的マーキング装置、重心崩し装置、予測狙撃装置、衝撃偏向装置。前述の6種で置換済み。
