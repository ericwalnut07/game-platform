# ターン制タクティクス 次期UI修正・第1段階：施設・輸送車の接地補正

## 対象と境界
- 本変更は正式採用済みのマップ表示専用。PR #138（爆風射線修正）を起点とする積み上げブランチ。
- 操作・バトルCore・移動・壁の射線/遮蔽判定・保存構造・画像資産そのものに変更なし。
- 画像は補給施設/残骸、輸送車、既存のレーダー・アンテナ・端末・タレット・クレート・ビーコンを含む。
- **壁のみ半透明**。その他のオブジェクト・敵味方機は常時不透明。レンダラの depth sort はPR #135方式を維持。

## 接地基準の修正
変更前は画像ビューポートの下端を「施設が占めるマス群の中心」に合わせていたため、画像の底面がマス中央よりさらに上方に浮いていた。

変更後は、各オブジェクトの現存するCore占有マス群（矩形の外接範囲）について次のように計算する。

1. 占有範囲の論理中心 `anchor = ((minX+maxX+1)/2, (minY+maxY+1)/2)` を施設名・HPなどのHUD位置として保持。
2. 幅 `maxX-minX+1`、高さ `maxY-minY+1` を論理セル数として取得。
3. 斜めマップの画面上Xを変えず、画面Yだけを**最前方の菱形頂点**へ合わせるため `delta=(幅+高さ)/4` を両軸に加えた `contact = (anchor.x+delta, anchor.y+delta)` を描画用接地点とする。
4. 内部の透明画素・SVGの `preserveAspectRatio` による上下余白を考慮する。画像の最終不透明画素が `contact` の画面Yに重なるように、SVG viewportのYを補正する。
5. 複数マス施設は1枚のイラストを1回だけ描き、HPの共有・タップ領域・既存の単位幅/高さは維持する。

## 画像内部の透明余白
現存するファイルのalpha>40/255の**最下画素**を確認し、その次の画素座標（exclusive bottom）をローカル表示用定数として管理する。素材を再加工した場合はこの数値も確認する。

| 種類 | 元のタイル/画像高さ | alpha最下端（exclusive） |
|---|---:|---:|
| タレット / 端末 | 96 | 88 |
| アンテナ | 96 | 89 |
| ビーコン | 96 | 75 |
| クレート | 96 | 76 |
| レーダー | 96 | 80 |
| 補給施設（通常/残骸） | 144 | 136 |
| 輸送車 | 152 | 144 |

余白補正は原画像のアスペクト比を考慮してスケーリングし、伸縮する既存2セルアトラス素材では従来の伸縮ルールに従う。
