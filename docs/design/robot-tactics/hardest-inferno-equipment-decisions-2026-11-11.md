## 1. 難易度と育成（採用）

- コアレベル上限：41 → **100**。Lv1–41の成長を変更しない。
- Lv42–61：従来Lv21–41の成長量の75%、Lv62–81：50%、Lv82–100：25%。個別ステータスの丸めは実装前に確定する。
- CAP = `100 + 5 × (コアLv - 1)`。Lv61=400、Lv70=445、Lv81=500、Lv100=595。
- 基本パーツ上限：Lv10 → **Lv20**。Lv11–20の個別成長値は未確定。Lv10の値を最終上限としてバランスを固定しない。
- Infernoの主対象はコアLv61–81（中心Lv70）。Lv100は任意のやり込み。通常の標準剣だけでは勝てない高難度を目指し、装備・戦術・ミッション別勝利条件を重視する。
- 既存フレームの個性・成長を維持し、万能型に専用装備を作らない。

## 2. 新武器12種類の配分（採用）

- 既存6系統（斬撃・打撃・刺突・連射・狙撃・爆撃）に**各2種**、計12武器。
- Hardest：各系統1種ずつ、計6種、**全て汎用**。
- Inferno：計6種。**攻撃型専用2種（近接1・遠隔1）、防御型専用1、炉心型専用1、機動型専用1、汎用爆撃1**。万能型専用なし。
- 追加で基本パーツ約10種、追加パーツ約20種を構想。非万能型の各系統に少なくとも2つの専用装備を確保する方向。個別品目と性能は未確定。

### I5 ヒット&アウェイ（採用）

- 「通常攻撃」の下に表示する、**EN消費なしの通常攻撃系コマンド**。
- 自ターンに移動した直後、選択して攻撃する。通常攻撃と同じダメージを与えた後、**移動前のマスへ自動的に戻る**。
- 追加EN・追加移動コスト・移動距離に応じたダメージ増加はなし。通常の攻撃行動を消費する。
- 移動前のマスはゲーム進行上ほかの機体に占有されない前提で、復帰失敗の代替挙動を作らない。
- 普通の「通常攻撃」を選んでも自動帰還しない。

### I3 守勢反撃（概念採用）

- **防御／シールド／ペア連携／防護陣の防御効果が実際に適用中**に敵から攻撃を受け、攻撃元が射程内の場合に反撃。
- 仮値：反撃倍率60%、EN10、1ラウンド1回。数値は未確定。
- 味方を保護した際の反撃可否、各防御効果の適用主体などは現行ロジック確認後に決める。反撃の連鎖は起こさない方向。

## 3. 通常攻撃系の分類統一（採用）

**「通常攻撃系」とは、通常攻撃と同じ枠に表示される、EN消費なしの攻撃コマンド全て**を指す。例：通常攻撃、薙ぎ払い、特攻、ヒット&アウェイ、範囲爆撃、および将来同条件を満たす攻撃。

- 既存の「通常攻撃時に火力増加」等の追加パーツや通常攻撃限定効果は、**この分類を共通基準**として適用する。コマンド名だけで除外しない。
- 各パーツ固有の近接限定・移動後限定・対象条件などは維持する。
- EN消費型特殊攻撃、武装コンボ、連携技は通常攻撃系に含めない。既存の特殊攻撃・コンボ固有ルールを維持する。
- 複数対象攻撃で、加算効果を各対象へどう配分し、攻撃固有の範囲倍率をどの順序で適用するかは**未確定**。暫定案は「対象ごとに算出し、範囲倍率を反映」。実装時に確認する。

## 4. 通常ダメージ＋独立した二次式追加ダメージ（採用）

武器威力や攻撃ステータスに二次式の倍率を掛ける方式は**廃止**し、通常ダメージと独立したEN/SPD由来ダメージを足す。

```text
D_total = D_normal + D_bonus
D_normal = floor(10 * (attackStat + weaponPower) / targetDEF)
D_bonus  = floor(K * (X / 100)^2 / (targetDEF / 100))
```

- X は「実際の消費EN」または「攻撃時点の最終SPD」。
- EN/SPD追加ダメージは武器威力・攻撃ステータスの上昇で増幅されない。
- 追加ダメージにも対象DEFを適用。攻撃固有の通常倍率・範囲倍率との合成順序は別途確認。
- **係数はバランス検証用の現時点の採用候補値**。Lv11–20と新パーツが未確定なので、将来の調整余地を残す。

### メテオバスター（採用した調整方向）

- 汎用のInferno爆撃武器。ENを**最大ENの50%（端数切り上げ）**消費、現在ENが不足していれば発動不可。
- 二次式追加ダメージ係数 **K=20**（前案40から引き下げ）。通常ダメージ＋EN追加ダメージ。
- 既存Lv10のEN+130装備・コアLv70・最大EN367・消費EN184・敵DEF145なら、追加ダメージ **46**（通常ダメージは別途加算）。
- 爆撃の中心と周囲への追加ダメージ配分、EN消費型特殊攻撃と通常攻撃系のUI分類、固有の追加制約は**未確定**。既存爆撃の選択・射線ルールを無断変更しない。

### 炉心全解放ユニット（追加パーツ構想・係数は暫定）

- 汎用追加パーツ。専用攻撃「フルバースト」を使えるようにする。
- 発動時の**現在EN全量を消費**。最大威力には満タンまで貯める必要がある。
- 通常ダメージ＋EN二次式追加ダメージ。係数 **K=25（暫定）**。
- 単体対象、武装コンボ・連携技・他の特殊攻撃と併用不可という案。武器固有の反動・デメリットを無効化しない方向。
- EN0での発動可否、追加パーツCAP、対象武器の制約、発動コマンド位置、既存武器効果との相互作用は未確定。

### 慣性衝撃ユニット（**採用**）

- Hardest以降の**全フレーム装備可能な追加パーツ**。名称は仮称。
- **自ターンに1マス以上移動した後、近接武器で通常攻撃系の攻撃を実行した場合**、攻撃時点の最終SPDに基づく追加ダメージを加算。
- **K=80**。EN消費なし。移動距離は倍率に影響しない。1回の攻撃で効果発生は1回。
- 薙ぎ払い、特攻、ヒット&アウェイも通常攻撃系なので適用対象（個別の発動条件を満たす場合）。範囲爆撃は通常攻撃系だが**近接武器限定**を満たさず対象外。
- 武装コンボ・連携技・EN消費型特殊攻撃には適用しない。
- 例：SPD162、敵DEF145の場合 `floor(80 × 1.62² / 1.45) = 144`。**注意：過去の試算表には係数80の値を14とする桁違いの計算ミスがある。正しい値は144。** そのため **K=80は現状のままでは強すぎる可能性が高く、実装前に係数を再検証すること**。採用済みなのは「SPD二次式・通常攻撃系・移動後近接限定」という効果構造であり、計算ミスを根拠に係数80を無条件に固定しない。

## 5. 実装前の確認・保留事項

1. **最優先：慣性衝撃ユニットの係数再検証**。SPD162 / DEF145で係数80なら追加144となるため、当初の「小幅な火力増加」という意図と矛盾する。例えば係数8なら追加14。ユーザー確認なしに数値変更しない。
2. 基本パーツLv11–20のEN・SPD・武器威力・CAPの成長値、およびHardest/Inferno新装備を確定し、Lv61/70/81の完成ビルドで検証。
3. 通常攻撃系の全コマンドと既存「通常攻撃時」効果の適用範囲をコード・仕様書で棚卸し。各コマンド固有の倍率、複数対象への適用・丸め、EN回復を維持。
4. EN追加火力の爆撃周辺対象への分配と、フルバーストの武器デメリット（諸刃の剣など）の扱いを確定。
5. 守勢反撃の発動対象・数値、12武器の仮値と新パーツの性能を確定。
6. 実装時は既存セーブ互換性を守り、ゲーム固有の型チェック・Unit・短いsmoke・必要なPC/スマホ横画面確認を実施。共通サイトへの統合・デプロイはしない。
