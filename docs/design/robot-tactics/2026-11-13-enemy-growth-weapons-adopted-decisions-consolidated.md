# ターン制タクティクス：2026-11-13 敵機成長・武器運用の追加採用事項（統合記録）

> **ゲームデザインの確定事項。ゲーム本体への実装済みを意味しない。** PR #161〜#164に分散した決定事項を照合し、既存文書で未確定扱いのままになっている事項を明確化する。個別モデルへの暫定武器割当は正式採用扱いにしない。

## 1. 通常敵機の複利成長・整数処理（正式採用）

- Hard M29の**同型敵機**をHardest M01の起点とし、M01→M30は29回の複利成長。Inferno M01はHardest M30を起点とし、M01→M30は29回の複利成長。
- **途中の各ミッションで整数丸めを繰り返さず、最終値だけ Math.round**。旧文書 `hardest-inferno-normal-enemy-growth-adopted-2026-11-13.md` の「複利か累積加算か未確定／丸め時点未確定」という記述は本採用事項で解決済み。
- 変化率・固定加算値はPR #161の成長表を維持する。Hardest移行：HP/近接/射撃+8%、DEF+2、SPD+2、EN+5%。Hardest各ミッション：HP+1.2%、近接/射撃+0.8%、DEF+0.15%、SPD+0.3%、EN+0.5%。Inferno移行：HP+8%、近接/射撃+5%、DEF+1、SPD+2、EN+3%。Inferno各ミッション：HP+0.7%、近接/射撃+0.5%、DEF+0.08%、SPD+0.2%、EN+0.3%。MOV変更なし。
- 例：Hardest M30のHP = `Math.round(Hard_M29_HP * 1.08 * 1.012 ** 29)`。固定加算のDEF/SPDは移行時に加え、ミッション成長を適用。InfernoはHardest M30の丸め済み確定値を次難易度の起点とする。
- ボス6機は通常敵機の自動成長・自動持ち替え対象外。Easy/Normal/Hardの既存基礎能力は変更しない。

## 2. 武器威力の参照とレベル配分（正式採用）

- 敵機の武器威力は**プレイヤーが装備する同名武器・同レベルの正式な武器威力**を参照する。PR #162のLv1〜20成長仕様に従う。
- 「敵機の武器威力だけを一律25%/30%増やす」案は廃止。PR #161に能力成長表として記載された「武器威力+8%/+0.8%/+5%/+0.5%」は、**同名武器・同Lvの威力へさらに乗算する根拠にしない**。敵の近接・射撃攻撃能力の複利成長と武器Lv成長をそれぞれ適用し、武器威力を二重強化しない。
- Hardest武器Lv：M01〜06=9、M07〜12=10、M13〜18=11、M19〜24=12、M25〜30=13。
- Inferno武器Lv：同じ6ミッション区間で14、15、16、17、18。
- 中量・重量の2武器は原則同じ武器Lv。通常敵機のレベル上限拡張に伴うコード修正・検証は別工程。

## 3. Hardest / Inferno 通常敵機の武器候補（正式採用の方針）

- 既存の同系統★3武器に加え、**Hardest新武器6種**も通常敵機の持ち替え候補に含める。
- **諸刃の剣／超重レールガンは特殊な武器のため、通常敵機の一般装備候補から除外する**。ボス個別仕様は別途維持。
- PR #163の小型12・中量12・重量9の計33モデルの**個別持ち替え表は検証用一次案**。個別モデルの最終武器IDはまだ採用確定していない。新武器固有効果、射程、AI行動、ENを検証して確定する。
- Inferno新武器6種を通常敵機の候補へ自動追加することは、現時点で確定していない。

## 4. 小型敵機のEN（正式採用）

- **小型敵機はENを持たない（EN0）**。武器を変更してもENを付与しない。
- ENを消費する武器固有の特殊攻撃・効果は小型敵機では発動不可。通常攻撃およびEN不要の効果は既存の正式な発動条件に従う。
- 中量・重量は従来のENを保持し、特殊攻撃は必要EN・行動条件・AI実装が整っている場合のみ使用可能。
- 小型は通常攻撃中心、中量・重量は通常攻撃とEN消費行動を分けてバランス検証する。

## 5. Hard M08〜M30 初期武器★2更新（正式採用）

- **Hard M01〜M07は変更なし**。M08〜M30の一般敵機は、★1初期武器を原則同系統★2へ変更する。
- ★2・★3は維持。ヘビーハンマー／制圧メイスは★2拘束ハンマーで威力が下がるため維持。ボスの個別装備は変更しない。
- 具体的な武器IDの置換表はPR #164 `hard-m08-m30-tier2-weapon-upgrade-adopted-2026-11-13.md` を参照。Hardの既存武器Lv・能力成長・セーブ互換を維持する。
- 中量射撃A等で2スロットとも腐食ライフルとなる重複は**未解決のモデル別割当問題**。既存の「異なる2武器」制約を維持し、別の武器への差し替えは設計決定後に行う。
