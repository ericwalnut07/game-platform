## 2. 個別の確定ルール

### 2.1 戦術標定攻撃装置

- 発動機の**次の自身手番開始**までマーク有効。再付与は期限更新のみで重複加算しない。
- 操作機と友軍AIの攻撃を対象とし、範囲・連携・反応等でも、**マーク対象に最初に発生した有ダメージ1hitだけ**に+70%を適用して消費する。
- 多段ヒットでも複数hitへ乗せない。複数の敵が範囲内にいてもマーク対象だけが対象。
- DOTと遅延爆発による継続/誘発ダメージには乗せず、それらではマークを消費しない。

### 2.2 防護投射器

- 自機は対象外。直接操作する**別の味方機**または友軍AIが対象。
- 発動機の次の自身手番開始で消滅。同じ軽減の複数付与は重複せず、再付与は期限を更新する。
- 既存シールドや防御など、他の割合軽減との関係は**独立乗算**。

### 2.3 弱点照準装置

- **対象距離はチェビシェフ距離5マス以内**。通常攻撃と同じ壁・角の射線判定を使う。
- 敵1機にダメージを与えない支援行動（CAP26、EN10、1行動）。対象の一時的DEF弱体化適用前DEFを `D` とし、弱点照準の低下量は `floor(0.25 * D + 0.30 * max(0, D - 60))`。
- **1敵機につき弱点照準は最大1つ**。同じ対象への再付与は新しい使用者・強さ・期限で完全上書きし、加算しない。別の敵それぞれに弱点照準を有効化できる。
- **他の種類のDEF低下とは重複可能**。低下量は一時的なDEF低下前の対象DEFを基準に独立計算し、他のDEF低下量と合算してから全体のDEF下限10を適用する。
- 発動機の**次の自身手番開始**で消滅。再付与された場合は新しい発動機を期限の基準とする。

### 2.4 対物一点収束装置

- DEF無視率は `clamp(0.25 + 0.005 * (D - 80), 0.10, 0.45)`。
- `D` は一時的なDEF低下を適用する**前**の対象DEF。例：D40→10%、D60→15%、D80→25%、D100→35%、D110→40%、D120以上→45%。
- 無視率を決めた後、その率を他の適用済みDEF低下を反映した実効DEFに適用する。DEF下限10・割合軽減・最終切捨の既存ルールを維持する。
- **注意：PR #100の既接続コードは固定25%実装**。本更新は設計JSONだけで、実装更新・Unit Test・スモークは別途必要。

### 2.5 感応地雷

- 装備機からチェビシェフ距離**2以内**の通行可能な空きマスに**射線不要で設置**。壁・機体占有マス・盤外を中心に指定できない。
- センサーは設置マス＋周囲8マスの**3×3**。地雷自体は機体の移動・射線を妨げない。
- **敵の移動がセンサーのマスへ進入した場合**、最初の対象1体に**25＋対象敵コアLv**のダメージを与える。対象DEFを無視し、既存の割合軽減は適用する。
- 通常の移動に加え、**押し出し・引き寄せを含む強制移動**の経路上の感知マスも判定。既に感知範囲内だった敵が別の感知マスに移動した場合も発動。設置直後、移動していない敵には即起爆しない。
- MOV−1（最低MOV1）。対象の**次の自身手番終了時**に解除。同一種類のMOV低下は加算せず、再適用は期限更新。
- **地雷は複数設置可能**。ただし新規の設置マスが既存地雷のセンサー内にある場合は設置できない。センサー範囲同士の部分的な重なりは許可。
- 敵がセンサー重複位置へ侵入した場合、**該当する各地雷がそれぞれ1回ずつ起爆し、それぞれのダメージを適用**。1地雷あたり敵1体、起爆後は消滅。複数地雷由来の同一MOV低下は非加算。
- 同時に複数敵が入った場合、**ゲームの決定的な内部機体順**が若い敵を優先（軽量小隊なら軽量機1→2→3）。再現・保存後の順序も揃える。
- **設置直後から有効。設置したラウンドと次のラウンドに有効で、次のラウンドの終了処理で消滅**。例：R3設置→R4の最後の機体の手番末処理後に消滅→R5は無効。起爆した地雷は即消滅。設置は**射線不要**で、距離2以内の通行可能な空きマスに限る。

### 2.6 戦術デコイ発振器

- 自機からチェビシェフ距離**5以内**、射線不要、通行可能な**空きマス**に設置。**HP60・DEF60**。
- **敵も味方もそのマスへ移動・通過・停止できない**。射線は遮らない。攻撃対象候補だが、拠点の占領・攻撃能力は持たない。
- **装備機体ごとに最大1個、直接操作部隊の最大3個**。同一機体が再設置すれば古いデコイを置き換え、EN10と1行動を通常どおり消費する。
- 設置機体の**次の自身手番開始まで**。設置機体が撃破されたら消滅。
- 敵AIは標的候補として正の優先補正を与えるが攻撃は**強制しない**。施設攻撃やミッション目標を損なわず、進路を塞ぐデコイを破壊する判断も考慮。**補正の具体的数値だけは既存AIの評価構造を見て実装時に調整**。
- 敵増援の出現位置に重なった場合は**増援出現を優先してデコイを消滅**。敵を消したり増援を延期したりしない。

### 2.7 進路妨害フィールド

- 使用機体からチェビシェフ距離**3以内**、射線不要。指定中心から**5×5**の範囲内にいる敵全員のMOV−1（最低MOV1）。味方影響なし。
- 消費EN10、1行動、寿命**2ラウンド**。
- **複数設置・重複範囲を許可**するが、同種フィールド由来のMOV低下は**最大−1で非加算**。
- 設置中心は**通行可能な空きマスのみ**。壁・盤外・機体占有マスを中心に指定できない。フィールド自体は障害物ではなく、**設置後は敵味方とも中心マスを通行・停止できる**。射線も遮断しない。他フィールドの効果範囲内への再設置・重複設置は許可する。
- **設置直後から有効。設置したラウンドと次のラウンドに有効で、次のラウンドの終了処理で消滅**（R3設置→R4終了後消滅、R5は無効）。

### 2.8 補給フィールド発生器

- 使用機体からチェビシェフ距離**3以内**、射線不要。**通行可能な空きマス**を中心に**5×5**の範囲を作る。
- 直接操作機・友軍AIは、**各自の手番終了時**にフィールド内ならEN＋12（上限まで）。設置直後から有効。
- **チーム同時1個**。再設置時は既存フィールドを消して新しいフィールドに置き換える。
- 設置ラウンドとその次のラウンドに有効。**設置ラウンドの次のラウンドの終了時に消滅**。例：R3設置→R4終了処理で消滅、R5は効果なし。

### 2.9 攻撃後移動2パーツ

- 旋回余勢装置は斬撃の通常・特攻・薙ぎ払い後に**命中不要**で任意1マス。
- 斬り抜け駆動装置は近接**通常攻撃の命中後のみ**任意1マス。特攻・薙ぎ払いは不可、1手番1回。
- **両方装備し、条件が成立すればそれぞれを独立して使える**。1マス移動を2回まで、毎回行先を選び、途中で終了してもよい。
- 解決順は主攻撃ダメージ→押し出し/引き寄せ→衝突→撃破→攻撃後移動1/2。各1歩ごとに必要な迎撃・地形侵入を判定。通常の無料移動ではないため移動EN＋3回復は発生しない。

### 2.10 迎え突き制御器

- **変更なし**。CAP28、EN0、刺突の実射程内で距離2以上に敵が移動終了した際に35%の反応攻撃、1ラウンド1回。射程延長を装備している場合は適用する。

## 3. 追加確定：連鎖斬撃炉・転送・爆炎・弱点照準・妨害延長（2026-11-04）

この節は、前回未確定だった**5種類すべてについて、ユーザーが正式採用した最新仕様**。詳細は下記の各項に従い、旧版の「未確定5種類」という扱いは破棄する。

### 3.1 連鎖斬撃炉（`chain-slash-reactor`）

- CAP38、対応★3以上斬撃武器。**通常の特殊攻撃コマンドではなく、撃破時に任意起動する装備効果へ変更**。
- パーツ装備機が**自機の行動手番中**に、装備中の対象斬撃武器を使用するいずれかの攻撃行動で敵を撃破した時に追撃可。通常攻撃、特攻、薙ぎ払い、武装コンボ、攻撃連携技などを含める。敵手番中の迎撃・反撃による撃破は対象外。
- **撃破と元攻撃の結果確定後**、追撃するか辞退するか選び、実行する場合は生存する別の敵1機を選ぶ。対象は装備斬撃武器の合法な射程内、または既存特攻の条件・地形・踏み込み制約を満たす追加到達範囲内。
- 追撃は**通常攻撃相当の100%ダメージ**。別行動は消費せず、追撃を選んで発動する時だけ**EN15**を支払う。起点攻撃側のEN・行動コストは従来どおり。
- **同じ機体は1手番1回だけ**追撃可能。追撃で撃破しても再連鎖しない。使用しない選択も可能。
- 諸刃の剣での起点攻撃は元行動の確定自傷規則に従い、追撃は独立した通常攻撃相当として**追撃で実際に与えたダメージの20%自傷**。端数処理は既存の武器自傷規則に従う。元攻撃の自傷・撃破・状態変化を勝手に巻き戻さない。
- 攻撃後移動、押し出し・衝突・迎撃・撃破EN・特殊攻撃等の従来の確定処理順は守る。未定義の新しい反応割り込みを追加しない。

### 3.2 戦術転送ビーコン（`tactical-teleport-beacon`）

- CAP36、EN0、1行動。チェビシェフ距離3以内の**別の直接操作味方機または友軍AI**と、同時に位置交換。使用回数は無制限。
- **目的物運搬中の機体も交換対象にでき、データ・物資は元の所持機体が持ち続ける**。交換に伴う持ち物の受け渡しは発生しない。
- 交換は通常移動ではない特殊位置変更。途中移動経路は存在せず、壁・中間マス通過判定なし。**迎撃・反撃などの通常移動終了を契機とする反応は発生しない**。通常移動によるEN+3も発生しない。
- 交換後の位置でフィールド等の継続的な位置依存効果を判定する。位置交換のみでターン末EN回復を先取りしない。
- **交換後の地点到達・目的地侵入・データ取得・送信の条件は有効**。所持者とマスの要件を実際に満たした時だけ成立する。
- 味方にしか交換しないため、敵限定の感応地雷は起爆しない。転送を押し出し・引き寄せ等の強制移動へ誤変換しない。

### 3.3 残留爆炎散布装置（`persistent-blast-fire`）

- CAP30、EN15、★2以上爆撃武器。**初撃中心50%・周辺30%**。周辺への攻撃対象は装備武器の**通常爆撃と同じ手動選択・武器固有形状・最大対象数**に従う。
- 爆炎地帯は**武器種類に関係なく、攻撃時に選択した中心マス＋周囲8マスの3×3**に生成。初撃の周辺対象・爆炎地帯の対象マスは別概念。
- 爆炎地帯は**2ラウンド**（従来の寿命維持）。敵が通常移動で侵入した時、押し出し・引き寄せを含む強制移動で侵入した時、または敵が爆炎地帯内で手番を終了した時に**固定10ダメージ**。
- 固定10は**対象DEFを完全無視**し、既存の割合ダメージ軽減を反映する。
- **敵1機につき、各行動者の1手番内で最大1回**発動。例えば敵の手番中に自身の移動で1回、同じラウンドの味方の手番中に押し出しで別の1回が発動可能。ラウンド1回にはしない。同一行動者手番内に複数侵入・手番末判定があっても2回目以降は発動しない。
- 特殊爆撃の中心指定は**通常爆撃と同様に射程・射線内の生存敵がいるマス**。壁・盤外・空きマスは中心に指定できない。攻撃中心の機体占有は認める（攻撃対象だから）。
- 攻撃の結果確定後に残留爆炎を生成。**生成時には固定10の追加ダメージを発生させない**。以降の有効な侵入・対象敵の手番終了で判定する。
- 残留範囲は**攻撃中心3×3内の盤上通行可能マスのみ**。壁・移動不可地形・盤外には残らず、通常の通行や射線を妨げない。
- **攻撃したラウンドと次のラウンドに有効で、次のラウンドの終了処理で消滅**（R3攻撃→R4終了後消滅、R5は無効）。

### 3.4 弱点照準装置（`weakpoint-targeting`）

- 詳細は本書§2.3。**最大距離5、通常攻撃と同じ射線、同じ対象は1個だけ上書き、別対象は並行可、他種DEF低下と重複・加算、最終DEF下限10**が正式確定。
- 防御低下を1回の行動で付与し、HPダメージなし。CAP26・EN10と正式なDEF式・期限は維持。

### 3.5 妨害延長回路（`assault-debuff-extension`）

- CAP18、**追加EN0**。装備機のアサルト武器命中による**継続弱体効果の期限を1ターン延長**。
- 同じ種類の弱体効果が再度付与された場合は、**新しく付与する効果量と持続時間で完全に上書き**。古い効果量・残り時間は加算せず、強い短期/弱い長期を比較して残す処理はしない。
- 妨害延長の+1ターンは、該当する新しい付与効果の期限へ加算してから上書きする。

### 3.7 感応地雷・進路妨害・残留爆炎の設置と消滅境界（2026-11-04 最終採用）

| 感応地雷 | 距離2、通行可能な空きマス | 不要 | センサーは中心3×3、地雷は移動や射線を遮断しない | 設置時に既にいる敵では起爆しない。以後の移動侵入で起爆（起爆後即消滅） |
| 進路妨害フィールド | 距離3、通行可能な空きマス | 不要 | 5×5。中心/範囲とも設置後は敵味方通行・停止可能、射線も遮らない | 設置直後から敵MOV−1、同種非加算 |
| 残留爆炎散布装置 | 装備爆撃武器の通常射程/射線で選んだ**生存敵のマス**。空き・壁・盤外不可 | 通常爆撃と同じ | 初撃範囲は武器準拠、残留は固定3×3の通行可能マスのみ（壁・盤外は除外） | 初撃の攻撃ダメージ後に生成し、生成直後の固定10追加ダメージはなし。後の移動侵入・手番終了で発動 |

- 3種類のCAP/EN/初撃倍率/地雷ダメージ/対象/既存の重複規則は変更しない。
- フィールドおよび爆炎の視覚・判定用中心マスは、移動妨害する障害物として扱わない。**地雷は起爆消費とR終了自然消滅の両方**を判定。
- 爆炎の固定10はDEFを無視し、割合軽減を適用。敵1機につき各行動者の1手番で最大1回、別の手番なら同Rでも再発動。
- 設置可否は中心指定時点だけチェックし、設置後に機体がマスへ進入しても設置物を消去しない（起爆・期限など指定された条件は別）。

- `addons.json`の調整値は**設計上の正本**。ランタイムとの一致・自動反映を意味しない。
