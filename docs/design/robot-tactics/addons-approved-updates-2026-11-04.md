# ターン制タクティクス：追加パーツの最新採用仕様（2026-11-04）

> **優先順位**：ユーザーが2026-11-04のゲーム仕様検討で正式採用した決定を記録する。従来の `addons.json`、`addons-final-policy-2026-11-04.json`、PR #100の実装メモと矛盾する場合、本書の最新採用事項を優先する。
> **範囲**：設計仕様の更新のみ。PR #100で未接続だった追加パーツが実装済みになったことは意味しない。既接続の対物一点収束もランタイムは従来の固定DEF無視率のままで、変更には別途コード・テストが必要。
> **対象**：全60種類のCAP、入手条件、武器・レアリティ装備制限は従来どおり。既存のEN改定、爆撃追加パーツ3種、遅延起爆信管の正式仕様も維持。新しい独立オフライン作品のため、共通Webサイトへの統合・本番デプロイをしない。

## 2. 個別の確定ルール

### 2.1 戦術標定攻撃装置

- 発動機の**次の自身手番開始**までマーク有効。再付与は期限更新のみで重複加算しない。
- 操作機と友軍AIの攻撃を対象とし、範囲・連携・反応等でも、**マーク対象に最初に発生した有ダメージ1hitだけ**に+70%を適用して消費する。
- 多段ヒットでも複数hitへ乗せない。複数の敵が範囲内にいてもマーク対象だけが対象。
- DOTと遅延爆発による継続/誘発ダメージには乗せず、それらではマークを消費しない。

### 2.2 防護投射器

- 自機は対象外。直接操作する**別の味方機**または友軍AIが対象。
- 発動機の次の自身手番開始で消滅。同じ軽減の複数付与は重複せず、再付与は期限を更新する。
- 既存シールドや防御など、他の割合軽減との関係は**独立乗算**。

### 2.3 弱点照準装置

- 敵1機にダメージを与えない支援行動。対象DEFを `D`（この効果を適用する前の値）として、低下量は `floor(0.25 * D + 0.30 * max(0, D - 60))`。
- 発動機の次の自身手番開始で終了。実効DEFの全体下限10は維持する。
- **対象射程・射線、別のDEF低下や同種効果との合成は未確定**。ゲーム体験を変えるため実装者判断で補わない。

### 2.4 対物一点収束装置

- DEF無視率は `clamp(0.25 + 0.005 * (D - 80), 0.10, 0.45)`。
- `D` は一時的なDEF低下を適用する**前**の対象DEF。例：D40→10%、D60→15%、D80→25%、D100→35%、D110→40%、D120以上→45%。
- 無視率を決めた後、その率を他の適用済みDEF低下を反映した実効DEFに適用する。DEF下限10・割合軽減・最終切捨の既存ルールを維持する。
- **注意：PR #100の既接続コードは固定25%実装**。本更新は設計JSONだけで、実装更新・Unit Test・スモークは別途必要。

### 2.5 感応地雷

- 装備機からチェビシェフ距離**2以内**の通行可能な空きマスに設置。射線条件は追加で決められていない（未確定扱い）。
- センサーは設置マス＋周囲8マスの**3×3**。地雷自体は機体の移動・射線を妨げない。
- **敵の移動がセンサーのマスへ進入した場合**、最初の対象1体に**25＋対象敵コアLv**のダメージを与える。対象DEFを無視し、既存の割合軽減は適用する。
- 通常の移動に加え、**押し出し・引き寄せを含む強制移動**の経路上の感知マスも判定。既に感知範囲内だった敵が別の感知マスに移動した場合も発動。設置直後、移動していない敵には即起爆しない。
- MOV−1（最低MOV1）。対象の**次の自身手番終了時**に解除。同一種類のMOV低下は加算せず、再適用は期限更新。
- **地雷は複数設置可能**。ただし新規の設置マスが既存地雷のセンサー内にある場合は設置できない。センサー範囲同士の部分的な重なりは許可。
- 敵がセンサー重複位置へ侵入した場合、**該当する各地雷がそれぞれ1回ずつ起爆し、それぞれのダメージを適用**。1地雷あたり敵1体、起爆後は消滅。複数地雷由来の同一MOV低下は非加算。
- 同時に複数敵が入った場合、**ゲームの決定的な内部機体順**が若い敵を優先（軽量小隊なら軽量機1→2→3）。再現・保存後の順序も揃える。
- **寿命は2ラウンド（維持）**。起算点やラウンド末境界の細部はまだ確定していない。位置交換など起爆判定の未確認特殊移動は後続で整理する。

### 2.6 戦術デコイ発振器

- 自機からチェビシェフ距離**5以内**、射線不要、通行可能な**空きマス**に設置。**HP60・DEF60**。
- **敵も味方もそのマスへ移動・通過・停止できない**。射線は遮らない。攻撃対象候補だが、拠点の占領・攻撃能力は持たない。
- **装備機体ごとに最大1個、直接操作部隊の最大3個**。同一機体が再設置すれば古いデコイを置き換え、EN10と1行動を通常どおり消費する。
- 設置機体の**次の自身手番開始まで**。設置機体が撃破されたら消滅。
- 敵AIは標的候補として正の優先補正を与えるが攻撃は**強制しない**。施設攻撃やミッション目標を損なわず、進路を塞ぐデコイを破壊する判断も考慮。**補正の具体的数値だけは既存AIの評価構造を見て実装時に調整**。
- 敵増援の出現位置に重なった場合は**増援出現を優先してデコイを消滅**。敵を消したり増援を延期したりしない。

### 2.7 進路妨害フィールド

- 使用機体からチェビシェフ距離**3以内**、射線不要。指定中心から**5×5**の範囲内にいる敵全員のMOV−1（最低MOV1）。味方影響なし。
- 消費EN10、1行動、寿命**2ラウンド**。
- **複数設置・重複範囲を許可**するが、同種フィールド由来のMOV低下は**最大−1で非加算**。
- 設置中心マスが占有されている場合の可否・2R消滅の正確な境界は**未確定**。地雷/デコイの空きマス条件を無断適用しない。

### 2.8 補給フィールド発生器

- 使用機体からチェビシェフ距離**3以内**、射線不要。**通行可能な空きマス**を中心に**5×5**の範囲を作る。
- 直接操作機・友軍AIは、**各自の手番終了時**にフィールド内ならEN＋12（上限まで）。設置直後から有効。
- **チーム同時1個**。再設置時は既存フィールドを消して新しいフィールドに置き換える。
- 設置ラウンドとその次のラウンドに有効。**設置ラウンドの次のラウンドの終了時に消滅**。例：R3設置→R4終了処理で消滅、R5は効果なし。

### 2.9 攻撃後移動2パーツ

- 旋回余勢装置は斬撃の通常・特攻・薙ぎ払い後に**命中不要**で任意1マス。
- 斬り抜け駆動装置は近接**通常攻撃の命中後のみ**任意1マス。特攻・薙ぎ払いは不可、1手番1回。
- **両方装備し、条件が成立すればそれぞれを独立して使える**。1マス移動を2回まで、毎回行先を選び、途中で終了してもよい。
- 解決順は主攻撃ダメージ→押し出し/引き寄せ→衝突→撃破→攻撃後移動1/2。各1歩ごとに必要な迎撃・地形侵入を判定。通常の無料移動ではないため移動EN＋3回復は発生しない。

### 2.10 迎え突き制御器

- **変更なし**。CAP28、EN0、刺突の実射程内で距離2以上に敵が移動終了した際に35%の反応攻撃、1ラウンド1回。射程延長を装備している場合は適用する。

## 3. まだ正式な判断が必要な追加パーツ

1. **連鎖斬撃炉**：追撃先の確定/反応順、諸刃の剣の主攻撃・追撃時の自傷計算。
2. **戦術転送ビーコン**：目的物運搬者を交換できるか、交換位置の迎撃・移動進入効果。
3. **残留爆炎散布装置**：着弾の手動周辺対象、残留床の対象マス、強制移動時/ターン末、固定10への割合軽減。
4. **弱点照準装置**：射程・射線、同種/異種DEFデバフの合成（性能式は採用済み）。
5. **妨害延長回路**：同種の短期強効果と長期弱効果の再付与時の強さ/期限合成。

設置型に残る細部（進路妨害フィールド中心占有、同フィールド/地雷の2R期限境界、地雷の交換移動判定）も勝手には決めず、実装前の確認事項として残す。

## 4. 実装・検証への引継ぎ

- `addons.json`の調整値は**設計上の正本**。ランタイムとの一致・自動反映を意味しない。
- **特に対物一点収束装置**はPR #100時点で固定25%の既接続コードがあり、可変式への修正が必要。新しい設置型・後続移動・マーク等も別途Core/UI/保存への接続が必要。
- 独立オフライン、サーバー統合なし、PC・スマホ**横画面**のみ。セーブ/再開/再戦との整合、決定的な地雷起爆順、同種バフ・デバフ、移動と迎撃、友軍AI、装備制限を対象Unit/スモークで確認する。
- **この仕様更新PRは文書/JSONの差分のみ**。アプリコード・保存フォーマット・実際の戦闘挙動・本番環境は変更しない。対象設計JSONの構文・参照整合を確認し、コード検証は実装PRで行う。
