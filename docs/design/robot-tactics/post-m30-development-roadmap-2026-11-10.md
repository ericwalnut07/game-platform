# 『ターン制タクティクス』今後の開発方針（2026-11-10 ユーザー確定）

## 位置付け

M01〜M30が遊べる現行の**1人用・完全オフライン・独立ゲーム**を継続的に改善・拡張する。共通Webゲームサイトへの統合や本番デプロイは行わない。PC・スマートフォンの**横画面**を正式対象とし、個人プレイ用の**単一HTML試遊版**を継続する。

以下は今後の開発方針の確定事項であり、Hardestの数値や新装備の具体的性能まで確定したものではない。

## 1. 不備の修正・UI改善

- 継続的な試遊を通じてUI・操作性・表示・戦闘中の不具合を発見し、修正する。
- NPCの自動行動、勝敗判定、リザルト、セーブ／復帰など、進行不能やデータ損失につながる不具合を優先する。
- PC・スマートフォン横画面で実操作を確認する。
- **不具合修正を理由に、確定済みのゲームルールやバランスを無断変更しない。**

## 2. ゲームバランス調整

- 既存M01〜M30を対象に、**ミッション別・勝利条件別・難易度別**に検証・調整する。
- 敵の能力・配置・AI、ラウンド制限、各勝利条件の達成難度、報酬・EXP・育成速度などを必要に応じて検討する。
- 不具合修正とバランス変更を区別して記録する。数値・ルールを変える場合は既存の確定仕様と照合し、ゲームデザイン上の変更はユーザーと確定してから実装する。
- 大量シミュレーションを一律に実行せず、対象条件に応じたテスト・短い試行から始める。

## 3. 作品の拡張

既存の**30ミッションを維持**したまま、次の拡張を行う。

1. 現行Easy・Normal・Hardの上に、**Hardest**難易度を追加する。
2. **コアレベルの上限**を引き上げる。
3. **武器・パーツの強化レベル上限**を引き上げる。
4. **新しい武器・パーツ**を追加する。

Hardestの解放条件・敵性能・報酬・副目標・育成曲線・各レベル上限の具体値・新装備の性能や入手条件は**未確定**。既存難易度や30ミッションを勝手に置き換えず、個別にゲーム仕様を確定してから実装する。

## 全段階で守る非交渉事項

- **既存セーブデータとの後方互換性を最優先**。過去のミッションクリア記録、育成したコア・経験値、所持武器・パーツ、装備・強化状態、進行中の戦闘を可能な限り保持する。新項目は互換性を考慮して追加し、必要な場合は明示的なデータ移行・旧セーブ読込テストを用意する。既存データの初期化を前提にしない。
- 単一HTMLをAndroid等で別ファイルとして開く場合、ブラウザの保存領域が変わり得るため、バックアップのエクスポート／インポートを維持する。旧データを上書き・削除しない。
- 既存M01〜M30、Easy・Normal・Hard、確定済みの勝敗条件・報酬・育成仕様を、承認なしに変更しない。
- 既存のGitHubリポジトリ `ericwalnut07/game-platform` を正本として利用し、専用ブランチ／PRで変更する。Windows実機検証を利用し、既存のローカルファイルを保護する。
- 変更リスクに応じて関連Unit Test、smoke、PC／スマホ横画面E2E、ビルド、旧セーブ復帰を確認する。未検証の項目を検証済みとは報告しない。
- 本方針の記録自体は**ドキュメントのみ**。新難易度・レベル上限・装備の実装、PRマージ、本番デプロイは含まない。

## 開発順序

基本は **①不具合修正・UI改善 → ②バランス調整 → ③拡張**。ただし試遊中の不具合修正とバランス検討は必要に応じて並行し、拡張後も不具合修正・バランス調整を継続する。
