# Hardest / Inferno 一般敵機の武器更新：採用方針と全モデル割当案（2026-11-13）

## 決定済み事項

- ミッション別能力成長は複利計算。HP、近接、射撃、DEF、SPD、EN等の採用済み成長率を変更しない。
- 武器威力はプレイヤーと同じ武器カタログ・同じレベルの値を参照する。以前の「敵武器威力だけ一律25%/30%上乗せ」案は廃止。
- Hardest武器Lv9〜13、Inferno武器Lv14〜18。両難易度ともM01〜M30で5段階、M01〜M06が初段、M07〜M12が次段、M13〜M18、M19〜M24、M25〜M30が最終段（M30は13/18）。既存Hardは変更しない。
- Hardest以降の一般敵機は、同系統の既存★3またはHardest新武器への持ち替え候補を採用。諸刃の剣・超重レールガンは一般敵機の通常装備候補から除外する。ボスは個別仕様を維持。
- この文書の**個別モデル割当は検証用提案**であり、武器の射程・固有効果・敵AI・EN運用を確認するまで実装確定ではない。

## 要検証事項と例外

1. **射撃型中量A**：旧装備がアサルトライフル＋ライトピストルで、両方を同系統のパルスアサルトにすると「異なる武器2種」の制約に反する。一次案では2本目をEMPカービンへ変更。EN妨害の追加を検証する。
2. **重量砲撃C**：旧装備に超重レールガンがあるが、通常装備から除外するためリニアスナイパーに変更。射程・移動条件・高火力の差を検証する。
3. **重量強襲C**：旧諸刃の剣をプラズマブレードに変更。反動・自傷の除去によるAI挙動を検証する。
4. **射撃／打撃／刺突／爆撃の新武器**：EN消費、複数回攻撃、範囲、移動低下等が現行敵AIの行動仕様に合致するか検証し、未対応なら武器を使えるようにするためのAI改修と、装備候補変更のどちらが適切か別途判断する。
5. **武器のステータス補正**：武器LvによるSPD/MOVなどの補正も同名武器から適用。装備持ち替え前後で能力値が変わるため、Hard M29基準能力に旧武器補正を二重適用しない。
6. **初期武器の低火力問題**：持ち替え後の威力を先に比較し、不足する武器だけ追加補正を検討する。補正値は未決定。
7. **レベル成長の実装**：Lv11〜20の確定仕様はPR #162の設計文書を参照。Hardest/Infernoのステージ・武器Lv・新武器は現行ゲームランタイムには未接続。敵側武器Lv上限8の既存処理を変更する場合は専用テストを必要とする。

## 検証方針

まず同名武器Lv9/13/14/18の威力・武器補正・射程・EN消費を比較。続いて小型12、中量12、重量9の各モデルでM01/M15/M30の攻撃ダメージ、行動可能性、既存Hard互換を確認。ボスは今回の自動持ち替え対象外。独立オフラインゲームのため本番デプロイはしない。
