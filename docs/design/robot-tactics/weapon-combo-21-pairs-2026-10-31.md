# 武装コンボ：6武器系統・全21組み合わせの正式分類（2026-10-31）

> **分類と同系統120%はユーザーが以前に決定済みであることを再確認した正式仕様。** 既存の戦闘バランス・装備制約・未確認の個別効果を新規決定する文書ではない。旧「4種類のその他コンボ」を全体設計と取り違えないこと。

## 全体ルール

- 武器系統は6種類：近接＝**斬撃（slash）／打撃（blunt）／刺突（thrust）**、射撃＝**連射（assault）／狙撃（sniper）／爆撃（blast）**。
- 2武器の**系統**の順序を問わない組み合わせ（同系統を含む）は **21通り**＝異系統15通り＋同系統6通り。
- すべての組み合わせを、**同系統1タイプ／異系統5タイプ＝計6タイプ**に分類する。
- 同系統2武器の武装コンボは**全6系統とも通常攻撃ダメージの120%**。従来の `enhancedSameTypeCombo.damageMultiplier=1.2` を維持。既存の消費EN40も変更しない。
- 装備の「同一武器IDを同じ機体の2枠に重複装備できない」制約は変更しない。「同系統」は同じ**武器ID**を意味しない。
- この分類の再確認を理由に、各コンボ固有の追加効果・消費EN・射程・威力を推測で確定しない。

## 全21組み合わせの分類

| 分類 | 系統の組み合わせ | 数 | 状態 |
| --- | --- | ---: | --- |
| 1. 同系統 | 斬撃×斬撃、打撃×打撃、刺突×刺突、連射×連射、狙撃×狙撃、爆撃×爆撃 | 6 | **通常攻撃120%を採用済み** |
| 2. 異系統：近接同士 | 斬撃×打撃、斬撃×刺突、打撃×刺突 | 3 | **分類採用済み** |
| 3. 異系統：射撃同士 | 連射×狙撃、連射×爆撃、狙撃×爆撃 | 3 | **分類採用済み** |
| 4. 異系統：斬撃＋射撃 | 斬撃×連射、斬撃×狙撃、斬撃×爆撃 | 3 | **分類採用済み** |
| 5. 異系統：刺突＋射撃 | 刺突×連射、刺突×狙撃、刺突×爆撃 | 3 | **分類採用済み** |
| 6. 異系統：打撃＋射撃 | 打撃×連射、打撃×狙撃、打撃×爆撃 | 3 | **分類採用済み** |

**注意：5タイプは異系統15組の分類であり、個別に15個の異なる必殺技があるという意味ではない。**

## 既存ルールとの整合・未決事項

- `rules.json/combat/actions/twoWeaponCombo` には、異なる近接系統の二段攻撃・消費EN50が既存仕様として存在する。これを今回の「近接同士」3組に対応させるか、詳細の再点検が必要。**分類を確認しただけで既存の攻撃式を消去・変更しない。**
- `rules.json/combat/actions/otherCombos` に残る `impact/piercing/spread/dualTarget` の4名称・EN値は、**異系統5タイプの完全な分類ではない**。名前やEN値から5タイプとの1対1対応を作らない。
- 前の検討で示した「衝撃コンボ＝斬撃/刺突＋打撃、2マス押し出し」の案は**未採用**。これを正式値として実装しない。
- **異系統5タイプの具体的な技の効果・倍率・対象・個別消費EN**は、過去の決定が確認できるまでは未確認のまま。既存採用値が存在する部分は優先して保持する。
- 戦闘Core・UIで21組すべての分類は扱えるようにするが、未確認の技効果を黙って補完しない。必要なら設計側へ確認する。
- 基本の通常攻撃式、最低ダメージ、DEF計算、射程・射線、武器固有効果、装備制約は今回の訂正では変更しない。

## 開発引き継ぎ

以前の『4種類の武装コンボから設計する』という整理は撤回する。**正しい対象は全21組を6分類し、同系統は一律120%、異系統は5タイプにまとめる既決定方式**。効果が未確認の分類に一律の仮効果を付けて正式実装したことにしない。

GitHubの未マージ設計PRの上に積んだ訂正資料であり、ゲームCore変更・単体試遊版変更・マージ・公開は含まない。
