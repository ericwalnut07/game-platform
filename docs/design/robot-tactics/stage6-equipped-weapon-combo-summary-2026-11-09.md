# ターン制タクティクス 次期UI修正 第4段階：装備中の武装コンボ表示

## 目的
カスタマイズ画面の「コアの現在性能」に、武器①・武器②の右側で装備組み合わせの武装コンボを確認できるようにする。
表示のみの変更。ゲーム進行・武器性能・EN計算・武器コンボの実行・セーブ形式は変更しない。

## 参照元
- 正式な21組のコンボ判定は `src/games/robot-tactics/weaponActions.ts` の `getRobotWeaponComboPlan` を正本とする。
- コンボの元データは `docs/design/robot-tactics/rules.json` の `weaponFamilyComboMatrix` と `enhancedSameTypeCombo`。
- 武器系統名は第3段階の `RobotWeaponCategories.ts` の6系統名を使用する。表示側で21ペアの別表は持たない。
- 選択武器2つを指定し、名称・系統の組合せ・消費EN・簡潔な効果説明を導出する `RobotComboSummary.ts` を追加。

## 表示仕様
- 装備中の武器①・②から毎回計算。装備変更、コア切替、共有Lvの変更やお気に入りからの装備読込で最新表示にする。
- 横幅があるPCでは武器②の右側。横幅の狭いスマートフォン横画面では武器一覧の下へ折り返し、横スクロールや重なりを防ぐ。
- 6系統無順序の21組すべてに対応。順序を入れ替えてもコンボ名、EN、効果を同一にする。
- 系統の組合せ表示は武器スロット①→②の順なので、入れ替え時には表示順だけ入れ替わる。
- 同系統強化コンボは120%・EN40、二武器連撃は最大2撃・EN50、拡散射撃は周囲8マス自動・70%・EN50、双対象攻撃は100%／70%・EN55、貫通射撃はDEF30超過分半減・EN45、衝撃射撃は100%・2マス押出・EN40。
- 表示文のダメージ係数・押出量・消費EN・コンボ名は既存の `getRobotWeaponComboPlan` の返値を使い、戦闘側の計算は触らない。
- ゲーム内の効果が単体攻撃専用の追加効果に依存することはない。特例として諸刃の剣などの既存自傷を勝手に変更しない。

## テスト
- Unit: 同系統は異なる武器IDを選び、無順序21組すべてで正式Planとの名前・EN一致と、2武器逆順での結果一致を確認。
- PC/スマホ横画面E2E: コアAでの初期「斬撃＋連射：双対象攻撃」から、装備変更により「打撃＋連射：衝撃射撃」へ更新。再読込後の保持、元の武器へ戻した際の再更新、クリックだけではセーブが変わらないことと横スクロール防止。
- 過去のオフラインカスタマイズE2Eを維持。TypeScript/厳格TypeScript、対象Unit、オフライン単体HTMLビルド、PC/スマホ横画面E2Eを実施。
- 他ゲーム、本番DB、Web共通ゲームサイト、Cloudflare本番deployは対象外。
