# ターン制タクティクス 第5段階：対象マーカーのひし形統一と壁の箱形統一

2026-11-09試遊で確定。基準は前段Draft PR #133（ひし形行動枠/統合情報/副目標リザルト）までの成果。独立・完全オフライン、PC/スマホ横画面のみ。ゲームCore、マス占有、移動、壁の射線遮断、武器、NPC、EXP、副目標、セーブ形式、VFXは不変更。

## 1. すべての「マスを指す表示」を床タイルと同じ斜め投影に統一

ユーザー添付のM02/M04実機画像では、攻撃・対象選択時に一部の黄色/赤の破線四角形が機体画像の手前に水平/垂直のまま表示されていた。原因は機体を正立させる `robot-isometric-billboard` 内に、マスの四角いアウトラインまで混入していたこと。

- `BattleScreen.ts` 内に `tileMarker(x,y, class, attrs)` を追加し、論理座標 `x + .055, y + .055, .89 x .89` の枠を統一。**既存の `robot-isometric-world` 行列のみを適用**して床タイルと同じひし形にする。
- 過去行動の発動者・攻撃された敵・施設・撃破済み地点の枠（従来黄色/赤の破線）、現在の移動・攻撃対象、シールド状態、位置確認、水色/赤ハイライト、現在行動機体の黄色い枠を、**機体画像より後ろのマス座標レイヤー**へ配置する。機体・武器の絵・HPバー・情報パネルは正立維持。マーカーはタップ判定を奪わない。
- 斜め投影済みの移動範囲、攻撃範囲、爆撃中心/範囲、危険地形、目標マス、移動経路は既存の座標変換を維持。角を丸くするCSSの `rx` はマス指定マーカーから除去。
- 色の役割：現在行動機 **黄色・実線**、味方機の位置確認 **水色**、敵機の位置確認 **赤**、**攻撃・特殊行動で選ぶ対象と直近被弾した対象はオレンジ・破線**、直近行動の発動者は **紫・破線**。既存の移動候補（青）と位置情報パネルは従来と同じ役割。余分な点滅を増やさない。
- すべての枠はタイルに合わせ、ズーム・カメラ移動・横画面・行動中の座標変更でずれない。戦闘の実際の命中判定・移動先・壁効果には一切影響しない。

## 2. 壁画像を既存の低い箱形へ統一

- `BattleTerrainArt.robotTerrainWall` は **Coreの既存wallCellsに含まれるマスのみ**、既存atlasの `container` （小型の箱形障害物）を返す。
- これまで連続壁に使っていた `wall-x / wall-y / wall-corner`、孤立壁の `barricade / utility` を描画しない。すべて `robotTerrainPlacement("container")` の幅・高さ・足元位置に統一。
- 既存床タイルとグラフィックの同一マス座標・深度順を維持。すでに公開されたWebPアトラスを再利用するため画像の新規生成・置換・ダウンロードは不要。
- 壁のCore配置・当たり判定・射線・移動・障害物数は変更しない。新しい障害物は生成しない。

## 3. 検証

- Unit: 隣接X/Y、角、孤立の **全壁位置が同一の低い箱** を返し、空きマスには壁を生成しない。
- PC/スマホのBattle E2E: 実行中の攻撃の選択枠（オレンジ破線）と、行動履歴の発動機/被弾機の枠が、`getScreenCTM()` で**床面とまったく同じ射影行列**を持つことを確認する。機体Billboard配下にアウトラインを置かない。機体情報・操作・セーブは変えない。
- 壁の描画 E2E: 壁の数＝箱形アート数、他の壁柄0、セーブ・再読込の前後で壁/進捗不変。
- 正式M01の実画像E2E: 味方後方WebP/敵前方PNG、正式武器、壁が全て箱形の表示を確認。
- Windowsローカル変更やSecretを保護し、GitHub専用Draft PRで管理。mainマージ、本番デプロイ、共通Webサイト統合は行わない。
