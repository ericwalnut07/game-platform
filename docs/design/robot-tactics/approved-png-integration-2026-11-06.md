## 配布容量

| ビルド | PNG内包 | HTML実測（初回実装） |
|---|---|---|
| 標準 | 256px本体10枚＋既存VFX21枚。1024pxは0枚 | 6,268,658 bytes（約6.27MB） |
| 高解像度 | 上記＋カスタマイズ可能な5形状の1024px | 11,865,241 bytes（約11.87MB） |

サイズはコードの最終差分により小幅に変動する。友軍・敵マスター5枚はGitHubに保持し、カスタマイズ対象ではないためHTMLへ内包しない。戦闘は両ビルドとも256px。画像はdata URLで自己完結し、外部から取得しない。

```sh
npx vite build --config apps/robot-tactics/vite.config.mts
VITE_ROBOT_ART_PORTRAITS=true npx vite build --config apps/robot-tactics/vite.config.mts --outDir ../../test-results/robot-portrait-app
```

Windowsは `$env:VITE_ROBOT_ART_PORTRAITS="true"` を設定後に `npx.cmd vite build ...`、終了後にその環境変数を解除する。標準版と高解像度版は用途別の明示ビルドであり、実行中に外部画像を追加取得しない。
