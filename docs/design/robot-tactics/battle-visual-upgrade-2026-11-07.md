# ターン制タクティクス：戦闘画面の正式改善方針（2026-11-07）

> ユーザー正式採用。実装は1項目ずつ、独立・オフラインのゲームに限定する。ゲームルール・勝敗・ステータス・報酬・既存画像・セーブ仕様は変更しない。共通サイト統合・本番公開はしない。

## 実装順序

1. **行動サマリーとマップ演出の連動（PR #122）**：最大3件の確定済み非移動行動を表示。機体名は自機・青、敵・赤、友軍AI・緑。ダメージ、回復、撃破、重要結果は太字。マップ上の行動者・対象強調、最新行動強調。移動・待機は履歴に記載せず、座標も表示しない。攻撃・回復・防御・連携・施設操作・データ送信等が対象。移動が続いても3件の行動履歴を保持。PCとスマホ横画面の両方で視認性を確保する。
2. **行動テンポ・演出キュー**：攻撃者の強調約0.2秒、対象の強調約0.2秒、攻撃演出約0.5〜0.8秒、ダメージ・結果表示約0.4秒、次の行動まで約0.15〜0.2秒。通常攻撃は約1.3〜1.6秒を基準に連携・複数対象は必要に応じて調整。演出・表示の完了前に次のAI操作で視認を妨げない。標準／高速／演出スキップを設け、スキップは表示だけに効きCoreの行動を省略しない。端末の動作軽減設定に対応する。
3. **通常移動アニメーション**：出発位置から実際に確定した経路に沿って、機体画像・装備武器・足元マーカーを同期して滑らかに動かす。移動経路を淡く強調、到達時に短い停止演出。1マス約0.4秒、2マス約0.65秒、3マス約0.85秒、4マス以上約1.0〜1.1秒。自機・敵・友軍AIすべて対象。あくまで確定済み結果の再生。アニメーション途中の位置はセーブしない。Coreの確定経路をどの形式で表示側へ渡すかは技術設計で決める。
4. **特殊移動の表現**：追加移動、押し出し、引き寄せ、テレポート等は行動の意味に合う移動演出を分ける。軽量部隊の複数機を正しく表示。リロード、スリープ復帰、再挑戦、スキップ時にも表示破綻・処理重複なし。
5. **マップ画像**：SF軍事施設・工業地帯、セミリアル・3/4俯瞰。床（金属・コンクリート・整備床・警告ライン）→低い遮蔽壁・隔壁（角／接続）→設備・障害物→施設・目標物→ミッション固有素材の順に制作・導入。壁は低くして機体を隠さず、HP・陣営・移動範囲・攻撃範囲・目標を最優先で見えるようにする。装飾物と実際の通行・射線障害物を明確に区別。既存の地形・LOS・効果判定は画像追加で変更しない。

## PC / スマホレイアウト

既存の左：ミッション・味方情報／行動順、中央：マップ、右：操作パネルを基本に維持。直近3行動は左情報欄の見やすい位置へ。スマホ横画面では情報量を圧縮し、マップ操作・横スクロールなし・セーフエリア・タップ領域を優先する。

## 第1段階の技術メモ

- PR #122 は `feature/robot-tactics-m08-formal-20261107`（PR #120）を親とする独立した積み上げDraft PR。
- 行動履歴の数字はCoreの確定ダメージ明細から投影する。任意の表示文章からダメージを算出しない。
- 現段階ではCoreのセーブ形式を変えないため、3件履歴は画面セッション中に保持し、再読み込み直後はセーブ中の最新行動1件のみ再投影する。3件の再読み込み復元が要件になった場合、別途互換性を考慮した設計が必要。
- 第2〜第5段階は未着手。第1段階の実装・検証とは混同しない。

## 第2段階の実装記録：行動演出のテンポ調整

- 作業PR：**#123**（親PR #122）。第1段階の履歴表示を前提とした、独立した段階実装。
- 通常演出では、確定行動を **行動者強調200ms → 攻撃対象強調200ms → 攻撃エフェクト・行動サマリー反映 → 結果表示保持400ms → 次のAI行動まで180ms** の順で再生。既存VFX（着弾・撃破・連携など）の複数パルスが終わるまで表示時間を伸ばす。
- 非攻撃行動は対象強調フェーズを省略し、行動者200ms強調後に履歴を表示する。
- 標準／高速（時間を約55%へ縮小）／スキップ（表示待ち時間を省略）の切替ボタンを、横画面の右側操作欄へ追加。変更はゲーム処理ではなく表示時間にのみ作用する。
- AI自動行動のタイミングを表示専用のタイムラインに連動。**移動は未着手**のため、従来の標準800ms待ちを維持する。後続の移動アニメーション工程で移動の待ちを再設計する。
- ページ非表示・オプション表示・再読み込み・動き軽減では一時表示を破棄し、確定済みの行動ログは維持する。ダメージやCore位置、セーブ形式、勝敗・報酬を変更しない。
- 検証：型チェック、対象Unit Test11件、M01実戦の段階演出／操作／クリア／連携（PC/スマホ）、M14 Easyの実戦E2E（PC/スマホ）、battle UIレイアウト／一時停止／動き軽減（PC/スマホ）、オフラインHTMLビルドを実施。
- 第3段階（通常移動アニメーション）以降は未実装。新たな工程として別PRで扱う。

## 第3段階の実装記録：通常移動アニメーション

- 作業PR：**#124**（PR #123を親とするDraft PR）。第4段階の特殊移動・第5段階のマップ画像素材はまだ実装しない。
- Coreが確定した前後の画面Stateから、既存の合法経路計算器 `getRobotLegalMoves` と移動方向・有効MOV・壁・施設・占有機体を使って実際の合法最短移動経路を復元する。合法なルートが得られなければアニメーションを省略し、確定済みの到着地点のみ表示する。
- 1マス400ms／2マス650ms／3マス850ms／4マス1000ms／5マス以上1100ms。自機・敵機・友軍AIが対象。軽量部隊内の先行メンバーの移動先を反映し、後続メンバーの経路を復元する。
- 既存の正式機体・右手武器・HP・選択枠・爆弾マーカー・状態エフェクトをまとめて移動。通過マスは淡い陣営色で強調。既存の速度切替（標準／高速／スキップ）と動き軽減に対応する。
- NPCが移動後に攻撃する場合、移動完了後に第2段階の攻撃・ログ演出を行う。AI待機と勝利結果表示は移動時間を考慮する。移動自体を行動サマリーへ記録しない。
- 画面表示専用の補間位置を保持し、リロード・一時停止・画面非表示・操作キャンセル時は確定済み座標へ戻す。移動途中の位置を保存しない。ゲームルール・Core状態・セーブ形式・敵AI判断は変更しない。
- 仕様上の次段階である追加移動、押し出し、引き寄せ、テレポートの専用演出は**今回対象外**。
