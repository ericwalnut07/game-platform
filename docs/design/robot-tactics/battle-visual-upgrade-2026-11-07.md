# ターン制タクティクス：戦闘画面の正式改善方針（2026-11-07）

> ユーザー正式採用。実装は1項目ずつ、独立・オフラインのゲームに限定する。ゲームルール・勝敗・ステータス・報酬・既存画像・セーブ仕様は変更しない。共通サイト統合・本番公開はしない。

## 実装順序

1. **行動サマリーとマップ演出の連動（PR #122）**：最大3件の確定済み非移動行動を表示。機体名は自機・青、敵・赤、友軍AI・緑。ダメージ、回復、撃破、重要結果は太字。マップ上の行動者・対象強調、最新行動強調。移動・待機は履歴に記載せず、座標も表示しない。攻撃・回復・防御・連携・施設操作・データ送信等が対象。移動が続いても3件の行動履歴を保持。PCとスマホ横画面の両方で視認性を確保する。
2. **行動テンポ・演出キュー**：攻撃者の強調約0.2秒、対象の強調約0.2秒、攻撃演出約0.5〜0.8秒、ダメージ・結果表示約0.4秒、次の行動まで約0.15〜0.2秒。通常攻撃は約1.3〜1.6秒を基準に連携・複数対象は必要に応じて調整。演出・表示の完了前に次のAI操作で視認を妨げない。標準／高速／演出スキップを設け、スキップは表示だけに効きCoreの行動を省略しない。端末の動作軽減設定に対応する。
3. **通常移動アニメーション**：出発位置から実際に確定した経路に沿って、機体画像・装備武器・足元マーカーを同期して滑らかに動かす。移動経路を淡く強調、到達時に短い停止演出。1マス約0.4秒、2マス約0.65秒、3マス約0.85秒、4マス以上約1.0〜1.1秒。自機・敵・友軍AIすべて対象。あくまで確定済み結果の再生。アニメーション途中の位置はセーブしない。Coreの確定経路をどの形式で表示側へ渡すかは技術設計で決める。
4. **特殊移動の表現**：追加移動、押し出し、引き寄せ、テレポート等は行動の意味に合う移動演出を分ける。軽量部隊の複数機を正しく表示。リロード、スリープ復帰、再挑戦、スキップ時にも表示破綻・処理重複なし。
5. **マップ画像**：SF軍事施設・工業地帯、セミリアル・3/4俯瞰。床（金属・コンクリート・整備床・警告ライン）→低い遮蔽壁・隔壁（角／接続）→設備・障害物→施設・目標物→ミッション固有素材の順に制作・導入。壁は低くして機体を隠さず、HP・陣営・移動範囲・攻撃範囲・目標を最優先で見えるようにする。装飾物と実際の通行・射線障害物を明確に区別。既存の地形・LOS・効果判定は画像追加で変更しない。

## PC / スマホレイアウト

既存の左：ミッション・味方情報／行動順、中央：マップ、右：操作パネルを基本に維持。直近3行動は左情報欄の見やすい位置へ。スマホ横画面では情報量を圧縮し、マップ操作・横スクロールなし・セーフエリア・タップ領域を優先する。
