# ロボット戦術：完全オフライン保存・中断復帰・バックアップの確定仕様

確定日：2026-10-30／状態：採用済みの動作要件。ストレージAPI・実装・配布形式の最終選定は別工程。

## 1. 個人用完全オフライン

- PC／スマートフォンで**インターネットに接続せずプレイ可能**な作品とする。共通Webゲームサイト（game-platform のCloudflare本番URL）への公開・ゲーム登録は行わない。
- 通信を必要とするオンライン対戦、サーバー側の部屋・認証、Durable Objects、D1、WebSocket、クラウドセーブは不要。
- ゲーム本体、進行記録、戦闘中の復帰、育成・装備、性能チェックを端末側で完結させる。
- **最終配布方式は未決定**。初回オンライン導入の必要なインストール型PWA／PC・スマホ用アプリ等を比較する段階で決める。PWAにする場合、必要資産が事前に導入され、オフライン起動を実機で確認できることが条件。単にWebページをブラウザで閲覧できるだけではオフライン完成と扱わない。
- 同じGitHubリポジトリでソース・仕様を管理しても、プラットフォームの公開導線に接続したり本番へデプロイしたりしない。

## 2. 端末内セーブを2系統に分離

| データ | 主な内容 | 主な更新契機 |
| --- | --- | --- |
| **進行データ** | 共有EXP、各コアLv、所持／強化パーツ、装備、クリア／解放状況など | 装備・強化・ミッションのリザルト確定 |
| **戦闘中データ** | ミッション番号／難易度、開始時の編成・パーツ値、ラウンド／手番順、全機体のHP/EN/位置/状態、敵・友軍AI、小隊・増援・ミッション目標・取得物、AI指示と自動／マニュアルモードなど | **自機・友軍AI・敵機の各行動が確定するたび** |

- **手動セーブ操作は不要**。進行データと戦闘中データを端末の永続保存へ自動記録する。
- 端末の画面消灯やブラウザ／アプリ終了の瞬間だけを保存トリガーにしない。操作の確定ごとに保存を進める。
- 進行データと戦闘中データは寿命が異なる。ミッション放棄／再挑戦で戦闘中データを破棄しても、放棄前に正当に確定した進行データは維持する。
- ミッションの勝敗確定・報酬更新は重複処理せず、確定したリザルトに基づいて進行データを更新してから戦闘中の未完了状態を終了扱いにする。
- 保存失敗・復元データの破損は無言で成功扱いしない。データ保護優先でユーザーに短いエラーを示す。

### 実装時の安全要件

- 保存データには形式バージョンを持たせ、最低限の型・値・参照IDの妥当性を検証する。将来アップデート時は互換変換の要否を判断する。
- 行動の**確定状態単位**で保存し、処理途中の中途半端な書き込みで再開しない。書込み中に終了しても最後の整合したチェックポイントを使用し、行動の二重適用を避ける。
- Coreのルール処理と表示演出を分離する。再開時に未完了エフェクトを再生する必要はなく、**確定後の正しい戦闘状態**を復元する。
- 保存方式（例：IndexedDB、ネイティブファイル保存、トランザクション方法）はプラットフォーム確定後に技術判断する。永続性・オフライン性・安全な更新が必須で、特定方式の採用はこの時点で固定しない。

## 3. 中断からの直接復帰：ホームを経由しない

戦闘が未終了のままアプリが閉じられたりスマホがスリープした場合：

1. 次にゲームを起動した際、未完了で有効な**戦闘中データ**を優先検出する。
2. **ホーム画面を表示せず、保存された戦闘画面へ直接戻す**。
3. 手番・ユニット状態・ミッション目標・友軍AI指示／モードを復元し、その続きから操作できるようにする。
4. 保存済みの手番を二重実行しない。AI自動手番で中断した場合は確定済みチェックポイントから安全に進める。

**中断中にホーム、カスタマイズ、パーツ強化、性能チェック、進行データの入出力へ寄り道することはできない。** 戦闘開始時の編成・育成状態を終了まで維持するための制限である。

## 4. 「再挑戦」と「ホーム画面に戻る」

戦闘画面のオプションは次の2種類：

- **再挑戦**：今のミッション／難易度をその戦闘の**出撃時の編成・能力・装備のまま**冒頭から再開始。途中のHP/EN/配置/イベント等は初期化し、旧戦闘中データを新しい戦闘へ置換。
- **ホーム画面に戻る**：**ミッションの放棄**。戦闘中データを破棄しホームへ戻る。進行を保持したままホームへ戻す機能ではない。
- どちらも失われる戦闘進捗があるため、誤タップ防止の確認を挟む。
- **放棄にはクリア判定・報酬EXP・アンロックを発生させない。**
- 戦闘終了後はリザルトを経由し、ホーム側のカスタマイズ等へ戻ることができる。

## 5. バックアップのエクスポート／インポート

- クラウド同期は必須とせず、**セーブデータを書き出す／読み込む**機能を備える。
- バックアップを任意のファイルとして保存し、端末変更や別のPC・スマートフォンへファイルを移して進行状況を復元できるようにする。
- データ管理入口は**非戦闘中のホーム内設定**。メインメニューの4項目は増やさない。
- 読み込むファイルは形式・互換性・必須情報を検証し、既存セーブの上書きを**明示確認**する。検証失敗時は既存のセーブを壊さない。
- ゲーム進行データのバックアップを必須とし、戦闘中データをバックアップへ含む場合も同じ整合性検査・直接復帰制約を適用する。**戦闘中にデータ管理を開くことは許可しない**。
- ローカルの保存データや端末自体を削除・初期化した場合など、バックアップがなければ復元できない可能性をUIで誤解なく説明する。
- 性能チェックの仮装備・仮想敵は**正式進行データに書き込まない**。

## 6. 検証受け入れ条件（後続実装用）

- オフライン状態で起動・出撃・AI自動進行・保存・再開・リザルト・育成が可能。
- PCとスマホの画面消灯／終了・再起動相当で、途中戦闘が**直接戦闘画面へ復帰**し、ホーム／カスタマイズへ迂回できない。
- 自機・友軍AI・敵機の各確定行動、状態異常、手番順、ミッション目標、連携制限等が復元後も一致する。
- 再挑戦は同じ難易度・**出撃時構成**を維持して戦闘のみ初期化。放棄は戦闘保存を消すが、EXPや既存進行データを改変しない。
- 保存済み結果の二重適用、二重報酬、AI手番の二重実行が起きない。
- バックアップ出力→別環境への読み込みで進行状況が復元し、破損ファイル・互換性不一致では現行保存を保護する。
- バックアップUIは非戦闘中のみ。保存処理・通知が操作を妨げない。

この文書は要件の保存であり、上記の検証項目をすでに実施したという意味ではない。
