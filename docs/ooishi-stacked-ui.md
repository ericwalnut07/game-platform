# 大石シリーズ：積層石UI（フェーズ11）

対象は『大石のライン』『大石のキャラバン』。両作で実際に重複した表示だけを `src/client/games/shared/StackedStones.tsx` と `stacked-stones.css` へ集約する。キャラバンからライン専用コンポーネント・CSSへの依存を解消する。

- `StoneBar`：大・中・小の横棒、所有者色、サイズ名。盤上では最上段だけ文字を表示
- `StackView`：下から上の積層、各層の広いタップ領域、選択層と全上層の強調、所有者を含む読み上げラベル
- `PlayerColor`：盤上石と同じ色の所有者マーカー。名前は各ゲーム側で表示
- 共通UIはCoreをimportしない。各ゲームがCore由来の選択可否、選択層、合法移動先、ラベル、操作callbackを渡す。配置／移動条件・石数・勝敗・NPC・通信は変更しない
- 合法移動先になったスタックは選択不可にし、ポインターを下の移動先ボタンへ通す。相手石の上への合法な積層を妨げない
- 見た目より広いタップ領域を維持する。ラインは大きな4×4マス内で十分な高さを確保する。キャラバンは20ポイント10段をスマホ縦画面内へ収めるため、各層を縦に明確に分離した横長タップ領域とし、固定34px高は要求しない。盤面下端がmobile viewport内へ収まることをE2Eで確認する。キャラバンの選択色・枠幅はCSS変数で指定する

検証は両作のソロ／オンラインE2Eをdesktop Chromium・mobile Chromiumで実行。既存の混成塔、途中層からの移動、敵石の運搬、移動元露出、占有済み移動先、確認／取消、終局／再開、reload／reconnectを再利用する。混成塔の上下順・サイズの幅と厚み・最上段だけの文字・所有者マーカーと盤上色の一致も両作で確認する。ゲームルールの変更はないため、新たなバランスsimulationや無関係なゲーム専用テストは追加しない。

共通UI変更時はLine UI verificationとCaravan verificationの両方が起動する。既存CI／Mobile E2Eのゲートは維持する。app versionは0.29.0のまま。migration追加なし。
