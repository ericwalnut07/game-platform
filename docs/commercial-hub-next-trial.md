# 商都開発・新ルール試遊版 — next-trial-1

正式v0.5の採用変更ではありません。PR16の候補データを再利用し、同じオンラインCoreに明示的なNEXTルールセットを追加します。設定がない既存部屋はv0.5を維持。試験版はrulesVersion=next-trial-1、config.rulesVariant=NEXT、testVersion=next-trial-1で識別します。

## 試遊手順

Preview URLはPR16の検証報告に記載します。本番サイトでは試験を行いません。

1. Previewを開き「部屋を作る」→「商都開発」を選択。ホストが部屋を作り、コードを他の3人へ共有します。
2. 他の参加者も同じPreview URLから「部屋に入る」でコード・任意の表示名を入力します。各端末のブラウザが自分の認証情報を持ちます。ログ解析には表示名を保存しません。
3. ホストは開始前に「商都開発・新ルール試遊版」、終了方式A（11〜13R）/B（12〜14R）、大型投資あり/なし、ビッド、監査官を選びます。現行v0.5も比較可能。開始後は設定変更不可。同室再戦でも条件を維持します。
4. 全員が準備し、ホストが開始。確認→トリック→仕入→生産販売→投資2巡→精算を繰り返します。公開市場の購入は投資1回を使い、翌Rの専用選択欄で対象を確定します。
5. スマートフォンは「手番・都市・履歴」タブを利用。手番タブに大型投資市場と対象指定、都市タブに事業・マップがあります。
6. 最終結果後、各自「試遊感想をJSON保存」で試合ID・設定付きの感想を端末へ保存し、運用者へ共有してください。個人情報を感想に入れる必要はありません。4人の結果を集めた後、ホストの「再戦」で同じ部屋・設定で再開できます。

## 試験版暫定仕様（正式決定ではない）

- 既存Coreは仕入→生産販売→投資の順。その順は維持します。
- トリック/監査官確定後・仕入前に購入翌Rのカードを有効化。封鎖と奨励金の対象を同じ公開スナップショットで判定。その後、技術使用料/権益買収/物流独占を購入成立順で選択します。先の効果後の合法状態で次を判定します。
- 技術使用料では数量/輸送方法も選択し、相手の通常稼働と同じ費用・高度化・報酬条件を適用します。通常使用だけを消費し、設備の追加権は残ります。輸送は相手の未精算費用へ計上します。
- 生産終了後、奨励金を支給し、投資前に無料建設・優先契約を購入成立順で選択。無料建設は通常建設と同じ扱いのため、このRの能力使用フェーズは既に終了し、能力は翌Rからです。無料建設の発展+2を維持します。
- 優先契約は商機のDISCOUNT/REBATEを使う拠出にも適用。同事業連続指定不可。合法事業がないRは指定なし、カードは維持。指定なしのRを挟んだ再指定は可能。
- 複合枠の「資源1個削減」は表示先頭の資材を1個削減（商品1は必要）。選択肢追加による正式ルール変更ではなく、比較用に固定した暫定境界です。
- 独占契約に発動時の合法な自社路線がない場合は当R不発、契約は保持し、翌R以降の仕入前に未指定の契約だけ再選択します。一度指定した地区は変更不可。対抗投資の不発・破棄とは区別する暫定境界です。
- 封鎖は自他とも使用不可、独占より優先。独占地区の重複指定を禁止。各種類1枚の通常試合では同一カードの複数契約は発生しません。
- 対抗投資は発動時に合法対象を判定し、なければ不発・破棄。奨励金は対象が存在すれば使用0回でも発動（支給0）、対象なしなら不発。
- 技術使用料で消費した通常能力も対象者の奨励金使用回数へ含めます。追加稼働も1回として含めます。上限は追加しません。
- 無料建設の合法場所がなければ一度の無料建設は不発、総数7効果は維持。各選択は公開履歴に記録します。

価格、終了A/B、発動順、無料建設・特殊拠出・追加使用の境界は未確定。試遊と同一シード比較で評価し、シミュレーションだけで正式採用を決めません。

## 感想の比較

終了後のJSONには試合ID、試験条件、面白かった選択、弱い/強いカード、不快な妨害、終盤の暇、改善点、プレイ時間を含めます。端末内ダウンロードのみで、D1/R2の逐次操作を追加しません。運用者は同試合IDをキーにR2ログ・D1サマリーと結合し、条件別に集計します。参加者へ共有するのは公開の試合条件と感想のみ。private Learningは同意を守り、共有しません。

## Preview隔離と無料枠

専用Worker、専用D1、専用SQLite DO namespaceを利用。本番Worker/D1/DO/Secretは変更しません。R2はgame-platform-private-logs-previewのStandard/private、Learning30日Lifecycleを維持。通常ログに自動削除は追加しません。D1にはconfig_jsonと試合/ラウンドの集約のみ、R2通常キーはrulesVersion=next-trial-1の独立prefix。Learningは既存の同意・撤回・開始から30日期限とCronを維持します。

D1/Workers/DO/R2の無料枠はアカウント全体で共有され、環境を分けても無料枠が増えるわけではありません。R2には自動課金上限がなく、log-storage-policy.mdの80%注意・90%見直しの運用を適用。比較simulationはローカルCoreのみでCloudflare操作を行いません。
