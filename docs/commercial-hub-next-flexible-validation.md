# NEXT自由資源払い：実装・比較検証

新規NEXT対局をnext-trial-3（app 0.19.0）へ更新。進行中next-trial-1/2と正式v0.5のルールを維持する。大型投資・公共事業・指定以外の建物能力を追加変更していない。

## 実装

- 全地区で3系統を建設可。内周同系統建設−1、異系統建設＋1、外周同系統上位化−1は必須資金だけに反映。
- 建設/上位化の基礎は資金3＋自由2枠。開発軽減は地区適用後の必須資金に反映、自由枠を減らさない。監査費は即時・別枠、輸送費は末払い。建設には両費用なし。
- 商館は商品1→3、商品2→5。販促/近代化の加算は維持。
- 明示的な`freePayment`をサーバーが整数・合計・残高と共に検証。UI数量選択・全資金払い・確認/修正・支払い前後の表・地区不可理由・44px数量ボタンを追加。
- NPCは全支払い組合せと建設/上位化を比較。投資後の次R資金・調達/製造/販売、在庫の生産備蓄と失う収入を評価。未検証の2〜3R探索は採用せず、1Rの静的近似に留める。
