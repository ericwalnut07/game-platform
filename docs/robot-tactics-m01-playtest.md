# ロボット戦術 M01・3難易度ブラウザ試遊版

## 起動

- 共通サイトの「1人で遊ぶ」→「ロボット戦術（M01試遊）」→「試遊を開始」
- または開発プレビューで `/robot-tactics-m01.html` に直接アクセス
- `public/robot-tactics-m01.html` は**単体HTML**なので、ファイルをダウンロードしてPC/スマートフォンのブラウザで開くこともできる
- 本番デプロイはこのPRの一部では実施しない

## 試遊できる内容

- Easy: 初期推奨コアLv2 / 初期装備Lv1 （選択可能Lv1–5）
- Normal: 初期推奨コアLv6 / 初期装備Lv2 （選択可能Lv5–6）
- Hard: 初期推奨コアLv18 / 初期装備Lv8 （選択可能Lv17–18）
- 上記の**装備Lvは試遊用の便宜的初期値**。パーツEXP購入制約は再現していない
- 各コアは同じコアLvを使用。独立したコア育成、報酬、ランク/EXP保存はなし
- 初期解放の4フレーム（攻撃/炉心/防御/機動）と初期18パーツのみ、6スロットに装備。CAP超過で出撃不可
- 3対3、9×9、味方B8/D8/F8、敵C2/E2/G2、障害物D5/F5。8ラウンド以内に敵3機を全滅
- 味方2機以上が生存して勝てばサブ目標達成
- SPDによる行動順、移動＋行動、武器切替、通常攻撃、範囲斬り、強化攻撃、異なる近接2武器の連撃、充電、防御、シールド、追加移動を試せる
- 敵は通常攻撃で反撃し、Normal/Hardでは敵のHP/攻撃/DEF/SPD/EN/武器威力を既存の採用難易度倍率で強化し、目標選択を改善
- 戦闘ログのコピー、同編成で再試行、編成変更

## ソース整合

ベースは別Draft PR #63にある `docs/design/robot-tactics/easy-01-proposal.json`, `difficulty-first-seven-proposal.json`, `frames.json`, `basic-parts.json`, `rules.json`（2026-10-27時点の採用基準）を参照して設計した。これらはまだ本PRのmainには未マージなので、単体HTMLに必要な初期18パーツの数値と敵3機の基準値を含めている。

**既知の試遊用近似（未確定を勝手に採用しないための明示）**

- コアLv2/6/18と装備Lv2/8の細かいステータスは確定済みチェックポイント間の線形補間・四捨五入を使用（将来の正式育成曲線とは独立）
- 移動タイプは直線4方向・斜め4方向・全8方向・前進＋左右を試遊用に解釈した。正確な射程距離と視線遮蔽はマンハッタン距離＋壁を遮蔽物とする暫定判定
- enemy AIはEasyの合法攻撃・接近、Normalの集中砲火評価、Hardの予測被ダメージと標的評価を使う**軽量版**。保存済みのHard探索全体を実装したものではない
- 動的な武器状態異常、複雑な三機連携、全ゲーム共有の行動順規則、持ち物による固有効果、独立コア経験値購入はこの比較試遊では対象外
- EN回復とダメージ基礎式は `rules.json` を参照。試遊用の厳密なタイミング差異が残り得る
- まだ敵の勝率・プレイヤー勝率やミッションのクリア可能性を保証していない。意図的に敗北できる

- このプロトタイプ用にサイトへの登録と試遊ページを追加。既存ゲームの共通ゲームロジック/DO/DB/migrationには変更なし

## フィードバック

試遊画面右側の「試遊ログをコピー」を使えば難易度・Lv・パーツ編成・操作履歴・勝敗を記録できる。
難易度比較では「序盤で敵に倒されすぎないか」「8R以内に敵全滅の余地があるか」「Easy/Normal/Hard間で敵AIの判断の違いが見えるか」を優先して観察する。

## 人間による初回試遊フィードバック（2026-10-27）

- 初回のプレイヤー試遊では、フレームごと・武器ごとの戦術上の役割の違いを明確に感じられた。肯定的な定性フィードバックとして記録。
- Hardは現行M01試遊条件の8ラウンド以内に敵3機すべてを撃破するのが難しい印象。**勝率・具体的な勝敗ログの定量記録ではない**。
- ユーザーは、完成版に育成・より豊富なカスタマイズがあることを理由に、**この段階でのHard敵ステータスや8ラウンド制限の即時変更を要求していない**。数値は現状維持し、将来は実際の育成と装備選択を反映した条件で再評価。
- この試遊版では、**複数ロボットの位置関係を要件とする連携技（ライン／ペア／デルタ等）は未実装**。一方、**単独機が異なる近接武器2つを使う「2武器連撃」は実装済み**。両者を混同しない。
