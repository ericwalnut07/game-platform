# 大石のテリトリー2：フェーズ10追加仕様

この文書はフェーズ10で実装する確定仕様。現時点のゲーム動作を変更するものではない。
元のフェーズ10「ソロ導線拡張」に、以下の配置制限ルールを追加する。
従来の「ゲームルール本体は変更しない」という範囲指定は、この配置制限について更新する。

## 目的

自由配置による単純なゴールデンペア妨害を抑え、自石の展開方向と将来の配置範囲、妨害へつながる位置取りを重視する。

## 配置条件

- **各プレイヤーの最初の配置のみ自由配置**。全体の1手目だけという意味ではない。既存の合法配置条件はすべて適用する。
- 自分の2手目以降は、盤上の自分の**大石または小石**の少なくとも1個と、同じ縦列・横列・45度斜め線上にあるマスへだけ配置できる。
- 起点からの距離は問わない。隣接限定ではない。ゴールデンペア／シンクロの標準・ロング接続距離とは別の条件であり、その距離上限を配置範囲に流用しない。
- 起点と配置先の間の自石・相手石は遮断しない。例えばA1が自石ならA2が埋まっていても、A3がその他の配置条件を満たせば配置可能。
- 複数の自石のうち1個でも直線関係を満たせばよい。
- 相手の石だけを起点にはできない。
- 登場する石も起点となる石も**大石・小石のみ**。中石は存在しない。
- 空きマス条件・大石の使用可能手番・残数・最終手の大石禁止など、既存のその他の条件を必ず維持する。直線条件だけを満たしても、それらに反すれば非合法。

実装上は、既存の合法手条件に「初回配置である、または自石との直線関係がある」を加える。
座標差で `dx === 0 || dy === 0 || Math.abs(dx) === Math.abs(dy)` を判定できる。
これは配置先の関係のみの判定で、ライン途中の石を調べる必要はない。

## フェーズ10のソロ導線

TOP → 1人で遊ぶ → 大石のテリトリー2 → 操作方法選択。

- **自分で操作する**：従来の1人で全席を操作する方式。
- **NPCに任せる**：自分の席だけ人間、残りを既存NPCが担当。

「部屋を作る」は既存の人間複数＋不足席NPCを維持する。
全席操作・NPCソロ・オンラインの全てで、同じ新しいCore合法手判定を使用する。
開始プレイヤー指定／ランダム方式も維持し、手番順と配置制限を混同しない。

## UI

サーバー／Coreが現在の盤面から合法配置マスを算出し、UIはその結果を表示する。
スマートフォンでは配置可能マスを明確に強調し、不可マスは通常表示または弱表示にする。
起点となった自石は常時表示しなくてよい。必要ならタップ・ヘルプ等で確認可能にする。
既存の盤面直上の石種選択と2回タップ配置は維持する。

## NPC

人間と同じCore合法手生成を使用し、NPC専用例外を設けない。
既存NPCを利用し、必要に応じて、次に展開できる場所・自分の配置ラインの増加・将来のGP妨害へつながるライン・将来候補を狭めすぎないことを評価へ加える。
ルール上の合法性とNPCの評価係数は分離する。

## 必須対象テスト

- 各プレイヤーの最初の配置は自由。
- 2手目以降の縦・横と4方向の斜め配置。
- どの自石とも直線関係にないマスは拒否。
- 起点と配置先の間に自石／相手石があっても、その先へ配置可能。
- 複数の自石のうち1個と直線関係があれば合法。
- 大石・小石のどちらも起点になること、相手石だけは起点にならないこと。
- NPCも同じ合法手制限を受ける。
- 占有済みマス・大石残数不足・大石の使用禁止手番などは、直線条件を満たしても拒否。

## 検証範囲

typecheck、対象Unit、対象NPCテスト、短いsimulationまたはsmokeを実施。
ソロ全席操作とソロNPC操作、開始者指定・ランダムの動作を確認する。
オンラインも同じCoreを用い、必要な対象操作とサーバー側拒否を確認する。
無関係な他ゲームの専用テストは実行しない。
ルール版・既存状態との取り扱い・ログは、実装着手時の最新コードに合わせて整合させる。
本番deploy・本番D1 migration・Secret変更は別途明示指示があるまで行わない。
