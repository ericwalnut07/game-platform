# 大石のライン：Coreルール1.0

gameId: `ooishi-line`。2人用・4×4、各自大4／中2／小1。
旧A改の小4／中2／大1から、大石と小石の役割・個数・制約を交換した現行仕様。

## フェーズ2の実装

`src/games/ooishi-line/position.ts` は局面・勝利・千日手のPure TypeScript関数。
`src/games/ooishi-line/engine.ts` は合法手生成・操作適用・手番／終局のPure TypeScript関数。
UI・ネットワーク・時刻・乱数への依存はない。

### 新規配置

1手で手持ちから1石だけ置く。大石は空きマス、中石は大石上、小石は中石上にのみ配置できる。
土台の所有者は問わず、相手石にもサイズ条件を満たせば重ねられる。
手持ちが0のサイズは新規配置できない。

### 盤上移動

盤上の自分の石を1個選び、その石と上の全石を所有者に関係なくまとめて運ぶ。
下層は元のマスへ残す。4×4内の任意の合法マスへ直接移動でき、方向・距離・途中のマスは問わない。
同じマスへの移動は行わない。

移動するまとまりの最下段で着地を判定し、大なら空きマス、中なら大石上、小なら中石上のみ。
移動先の土台の所有者は問わない。
移動では手持ちを増減させない。新規配置と盤上移動を同じ手番で両方は行わない。

### 勝敗

全マスの最上段だけを見る。同じ所有者の大中小が1個ずつ、縦または横の連続3マスへ順不同で並べば勝利。
斜め・行の折り返し・飛び飛びの3マスは勝利に数えない。
操作直後に両者のラインを判定する。移動元の露出により相手だけが勝利する場合もある。
両者同時成立なら引き分け。

### 千日手

局面キーは16マスの全層・サイズ・所有者・積層順・両者の手持ち・次手番を含む。
初期局面も1回目に数え、各合法手の完了後に次手番を更新した局面を1度だけ登録する。
同一局面が3回出現した時点で引き分け。繰り返した操作列自体が同じである必要はない。
終局後は合法手を返さず、追加操作も拒否する。

## 内部API

- `createLineState(startingSeat)`：初期局面・履歴・手番を生成。
- `legalLineActions(state)`：現在の手番の新規配置と盤上移動を列挙。NPCも同じ関数を使う。
- `isLegalLineAction(state, actor, action)`：手番・範囲・所有者・手持ち・積層条件を検証。
- `applyLineAction(state, actor, action)`：合法な1操作を適用。元の局面／履歴は変更しない。

MOVEのlayerは下から0始まり。actorは将来のソロまたはサーバーの認証済みプレイヤーから解決する席で、クライアントの自己申告を信用する仕組みではない。
オンラインの入力解析・GameModule登録はフェーズ5で追加する。

## フェーズ3：標準NPC

`src/games/ooishi-line/npc.ts` に標準NPCを実装する。

- 全ての候補は `legalLineActions` から生成し、局面の更新は `applyLineAction` を使用する。NPC独自の合法手・勝敗・千日手ルールは設けない。
- 最初に全合法手の即時勝利を調べ、存在すれば必ず選ぶ。
- 次に全候補に対する相手の全合法応手を調べる。即時敗北と相手の即勝ちを防げる候補があれば、防げない候補を探索対象から外す。この判定は探索予算による枝刈りより先に行う。
- その後は最大3手分（自分→相手→自分）のalpha-beta探索。基本は根8候補・各段6候補・探索で適用する局面数1600以内。根ごとに予算を割り当て、最初の候補だけで予算を使い切らない。
- フォーク候補・選択肢の多い候補も特別枠で残す。枝刈りがあるため完全探索・完全必勝手の保証ではない。
- 全合法手を確認する即時戦術検査の局面数は、上記1600とは別に `tacticalNodes` へ記録する。どちらも盤面サイズと合法手集合で有限。
- 同評価候補だけ、注入された乱数で選択を変える。乱数未指定時は決定論的。
- 実際の探索分岐は次手番・全履歴を保ち、Coreの同時勝利と千日手判定をそのまま使用する。局面だけのキャッシュで履歴を無視しない。

評価項目は自分と相手の差として、大中小ラインへの接近・複数ライン候補（フォークの可能性）・表面石の支配・下層の潜在的な露出・次手の合法選択肢・手持ちを使用する。
配置と盤上移動は同じ候補集合で比較する。相手のライン候補やフォーク可能性も評価へ反映する。
評価係数・探索上限は `LINE_NPC_TUNING` に分離し、ゲームルールは変更しない。
