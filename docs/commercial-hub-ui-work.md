# 商都開発 UI・UX改善（2026-10-14依頼）

正本はGitHub main。基準c1ce5ec（アプリ0.22.0、正式ルール1.0）。UIのみ変更しSUITS、compareCards、得点・費用・効果、サーバーPlayer Viewと合法行動、保存対局を維持する。本番deploy・遠隔D1 migrationは行わない。

## Work 1：共通画面
自社資源・本人限定企業価値・手番と同時操作の完了人数・最終予定を共通ヘッダーに集約。未精算費用と通行料を短い要約と展開式内訳に整理し、赤字見込みを明示。公開商会情報をPCの右列／スマートフォンの都市タブに配置。小さいPC幅は縦並び。重複する進行案内を除去し、直近の出来事は履歴へ、設定と長文補足は参照列の展開項目へ移動。
新しいゲーム情報の生成・公開は行わない。確認済みのView値のみを表示する。

## 続く工程
- Work 2：系統別建物カード、数量・輸送・追加使用、3資源の前後差、投資6入口、確認・確定の無効化。
- Work 3：配置不変の都市マップ、5/6/8商機と手札の近接表示、報酬詳細、公共事業と大型投資の情報整理・操作連携。
- Work 4：TOP/部屋作成/ロビー。旧v0.5・NEXTは通常新規選択肢から隠し、内部と保存互換は保持。

各PRはWindows npm.cmd run verifyとGitHub CI/Mobileの成功後に統合する。検証SHA・結果・マージSHAはPR本文へ記録。後続作業は先行PRの統合済みmainを基準とする。
