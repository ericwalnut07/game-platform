# 商都開発：正式版1.0への更新対象一本化（2026-10-16）

## 適用範囲

今後の『商都開発』の企画・UI改善・NPC調整・ゲームバランス調整・機能追加は、**正式ルール1.0の新規対局**だけを対象とする。新しい変更を旧v0.5やNEXT trial 1〜4に横展開しない。

- **正式1.0（更新対象）**：現在採用済みのルールを基準に追加開発、仕様書、ルールブック、試遊評価を進める。
- **旧v0.5（互換性維持のみ）**：新機能、UIデザイン刷新、ルール調整、NPC強化の対象外。新規対局の選択肢へ戻さない。
- **NEXT trial 1〜4（互換性維持のみ）**：同上。試遊版を再び新規対局の標準や開発対象にしない。

## 互換性・検証上の例外

旧対局の保存データ、ルール版判定、復元、ゲーム終了・再戦に必要な既存の分岐を削除・書換えしない。正式版を変更しても旧状態を自動変換しない。共通コードの修正によって旧対局に不具合が生じた場合は、互換性維持のための修正を許容する。

旧v0.5/NEXTの**回帰テストは削除しない**。検証する理由は過去の対局を保護するためであり、旧版への機能更新を意味しない。テストが通らないからといって旧ルールを正式版仕様に追随させない。過去ログ・D1/R2での版識別も維持する。

実装依頼・PR説明では、原則として「正式1.0のみ変更、旧v0.5/NEXTは互換性と回帰テストのみ」と明記する。共通基盤の修正が旧版にも影響する場合、変更理由と旧版への影響を明記する。

## 将来の削除について

保存済み対局や過去ログの対応を廃止することは、別の明示的な判断事項とする。本方針は旧コードや履歴データの即時削除、旧対局の強制終了を承認するものではない。

なお正式1.0の公共事業・NPC等の変更では開始時のルール・保存状態を尊重すること。
