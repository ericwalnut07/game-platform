# 商都開発：正式版1.0への完全一本化・旧版撤去方針（2026-10-16）

## 決定事項
新規・再戦・実装・試験・UI・ルールブックは正式1.0のみを対象とする。旧v0.5およびNEXT trial 1〜4の進行中・保存済み対局の継続互換性は不要。旧対局が開けなくなってもよい。旧版の継続のためだけの更新・回帰テストは撤去する。

## 撤去対象
- 旧v0.5/NEXTの選択肢、旧ルール画面と旧専用UI・フィードバック、旧再戦起動導線
- v0.5/NEXT専用の状態生成・スコア・商機・建設分岐、旧保存状態の読み込み／復元変換／互換分岐
- 旧版のみのNPC・シミュレーション・テスト・比較ツール、現在の検証スクリプトから旧版依存の検査
- 現行動作の説明内に残る旧版維持の記述

## 必ず残すもの
- 正式1.0が利用するNEXT由来の共通処理・資源支払・大型投資・地区・建物稼働・NPC計算・記録
- 正式1.0の開始時点のルール固定とラウンド進行、サーバー権威・秘匿情報・再接続・二重処理防止
- D1/R2の過去の対局・分析ログと版識別、既存の適用済みmigrationファイル
- 他ゲームと共通基盤のテスト、現在の正式版テスト
- 過去の開発経緯を示すGit履歴。過去資料はアーカイブ扱いとし、正式仕様の正本にしない

## 実装手順・安全境界
最新mainとAGENTS.mdを確認し、正式1.0のコードから参照される共通部品を静的に追跡する。削除前に旧版の入口と旧版専用処理を抽出し、正式1.0を起動・進行・終了するために必要なコードは維持して置き換える。旧対局は意図的に「サポート終了」として安全に拒否する（異なるルールで復元したり、エラー連鎖を起こさない）。

専用ブランチ・PRで作業。npm.cmd run verify（preflight/typecheck/unit/smoke/migration/build/PC・mobile E2E）とGitHub Actionsを確認してからマージする。正式1.0の設定16条件、4人完走、NPC、BOT、再接続、再戦、公共事業B案、UI、他ゲームを検証する。

本番deploy・本番D1 migration・秘密情報変更は本方針の決定だけでは実施しない。削除のためのD1/R2データ消去は行わない。

## 影響・運用
旧版で進行中／保存済みの部屋は、正式1.0のデプロイ後は再開できなくなる。旧部屋のリンクからアクセスした場合は「この旧版の対局はサポートを終了しました。新しい部屋で正式版1.0を開始してください」と案内する。共通の自動期限切れ・削除処理は維持する。過去ログは分析のために残す。
